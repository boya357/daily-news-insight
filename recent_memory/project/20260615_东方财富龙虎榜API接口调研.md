# 东方财富龙虎榜API接口调研

## 一、公开免费API

**主接口**：`http://datacenter-web.eastmoney.com/api/data/v1/get`

**请求方式**：GET，返回JSONP格式

**通用参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| callback | string | 是 | JSONP回调函数名 |
| reportName | string | 是 | 报表名称 |
| columns | string | 是 | 返回列，ALL为全部 |
| pageSize | int | 是 | 每页条数，建议≤100 |
| pageNumber | int | 是 | 页码，从1开始 |
| sortColumns | string | 否 | 排序字段 |
| sortTypes | string | 否 | 1升序/-1降序 |
| source | string | 是 | 固定为 WEB |
| clientl | string | 是 | 固定为 WE |
| filter | string | 否 | 过滤条件 |

**龙虎榜报表类型**：

| reportName | 说明 |
|------------|------|
| RPT_ORGANIZATION_TRADE_DETAILS | 机构买卖明细 |
| RPT_BILLBOARD_DAILYDETAILS | 每日龙虎榜详情 |
| RPT_BILLBOARD_STATISTICS | 龙虎榜统计数据 |

## 二、官方付费API

- **Choice量化接口**：官方授权，数据稳定，年费2-5万
- **东财掘金量化**：`stk_abnor_change_stocks()` 查询龙虎榜

## 三、使用注意事项

### 合规性
- ⚠️ 公开接口为网页数据接口，商业用途可能有法律风险
- 个人研究请控制频率，商业用途请购买官方授权

### 请求限制
- 频率不超过 1 次/秒，避免封禁IP
- pageSize 建议不超过 100 条
- 需设置合理的 User-Agent

### 数据时效
- 盘后更新，16:30-17:00 后可获取当日数据
- 数据可能有修正，建议次日复核
- 注意金额单位（元/万元）

### 常见问题
1. 空数据：非交易日或数据未更新
2. 403错误：请求过频，降低频率或换UA
3. 字段缺失：东财可能调整接口，需关注变化

2. **热门板块挖掘**：基于龙虎榜资金流向识别热门板块及龙头股

## 第二轮迭代：用户反馈修复（2026-06-16 下午）
用户反馈三个问题：
1. 每日新闻洞察列表页被报告页覆盖
2. 盘后速递列表页被报告页覆盖
3. 报告页原来有的模块上有tap按钮，现在都没了

### 修复内容
| 问题 | 原因 | 解决方案 | 状态 |

### 技术细节
- **重要新闻汇总实现**：news-tabs-container + news-tab-btn + news-tab-panel 类名 + switchNewsTab JS函数
- **列表页优化**：修改list_page_pro.py的`_generate_header()`方法和title设置
- **核心题材tab**：原有3个分级tab（S/A/B级）功能正常，之前因data_dir缺失导致不显示

## 技术经验
1. **开发流程**：读旧版实现 → Pro风格重写 → 插入build方法 → 测试生成
2. **命名规范**：add_前缀+模块名，如`add_overseas_market`
3. **heredoc坑**：Python heredoc内f-string易缩进错误，建议先写临时文件
4. **验证流程**：单模块 → 完整报告 → daily_update全流程 → Git部署
5. **用户体验**：列表页与报告页需有明显视觉区分，避免用户混淆
6. **术语理解**：用户说的"tap按钮"=tab标签切换按钮，注意理解用户表达

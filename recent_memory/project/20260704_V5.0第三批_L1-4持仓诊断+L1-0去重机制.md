### L1-0 报告内容去重机制 ✅

**新建模块**：`v3/content_dedup.py`（约400行）

1. **今日事件池**：`data/event_pool/YYYYMMDD.json`，记录当日所有被报告覆盖的事件
2. **四类报告内容边界契约**（REPORT_CONTRACTS）：
   - `s_level`（S级催化）= 单题材深挖：深度分析+交易策略+空方视角+证伪条件（deep）
   - `daily`（日报）= 信息全景：全市场覆盖，每个事件1-2句摘要+S级深度链接（summary）
   - `intraday`（盘中）= 增量异动：只写新增变化，不重复已写内容（delta）
   - `aftermarket`（盘后）= 当日验证+持仓诊断+龙虎榜（verification）
3. **事件指纹匹配**：Jaccard关键词重合(0.65) + 标题相似度(0.35)，阈值0.55判定为同一事件
4. **同义词归一化**：SOX/费城半导体→费半、HBM3/HBM3E/HBM4→HBM、英伟达→NVDA等
5. **去重决策**：DedupDecider.decide() 返回4种action：
   - `write_deep`：S级首发写深度
   - `write_summary_with_link`：日报对已有S级事件写1-2句+🔗详见S级催化链接
   - `write_delta_only`：盘中只写增量+引用之前报告
   - `skip`：重复事件且无变化跳过
6. **交叉引用组件**：`render_cross_ref_section()`生成"📑 今日报告覆盖地图"卡片，展示4类报告的生成状态+事件数，自动生成互链
7. **自动finalize**：报告publish时自动把本报告覆盖的事件写入事件池

**基类集成**：`v3/generators/pro_base.py`
- `init_dedup(report_type, report_file, trade_date)`：初始化去重会话
- `dedup_decide(keywords, title, summary, category, level, has_deep_content, anchor_id)`：事件级决策
- `register_event_anchor(evt_id, anchor_id)`：回填锚点
- `cross_ref_section()`：渲染覆盖地图（报告末尾调用）
- `dedup_contract_reminder()`：报告边界提示小条
- `finalize_dedup()`：发布时自动写入事件池（已在publish()钩子中集成）

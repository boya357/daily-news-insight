## 技术实现

### 核心文件
- `docs/assets/stock-popup.js` - 气泡卡片主逻辑，V2.0重写，支持Tab切换
- `docs/assets/stock-popup.css` - 深色玻璃态样式
- `docs/data/stock_analysis/stock_list.json` - 股票名称→代码映射表
- `generate_stock_data.py` - 批量生成股票分析数据的脚本

### 数据结构
每只股票的JSON数据包含：
- `code` / `name` - 基本信息
- `technical` - 技术面数据（指标、信号、支撑压力位）
- `market` - 行情面数据（今开、最高、最低、昨收、成交额等）
- `themes` - 题材面数据（标签列表，核心题材标记）
- `fundamental` - 基本面数据（PE、PB、ROE等）
- `overall` - 综合评分、评级、权重

### 自动识别机制
- 页面加载后自动扫描文本中的股票名称
- 匹配到股票名称后自动添加`.stock-badge`类名
- 鼠标hover时动态加载股票分析数据并显示气泡卡片
- 支持缓存机制，提升加载速度

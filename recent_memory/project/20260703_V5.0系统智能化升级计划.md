### L1 内容深度（6项，核心升级）

#### L1-1 数据来源标注+置信度+双源验证 ⏳待启动
- **现状**：报告完全无来源标注，数据可信度无法判断
- **改造内容**：
  1. 统一数据标签组件：`[来源: 财联社 | 置信度: 高]` / `[来源: 传闻/网络 | 置信度: 低, 待验证]`
  2. 关键行情数据（指数/股价/涨跌幅/成交量/资金流向）强制双源验证
  3. 置信度三级：🔴高（官方/多源交叉）/🟡中（单一权威源）/⚪低（传闻/未证实）
  4. 未验证传闻必须标注"⚠️未经证实，仅供参考"
- **改造范围**：pro_base.py新增数据标注方法，所有*_pro.py生成器调用

#### L1-0 报告内容去重机制 ⏳待启动
- **现状**：日报/S级/盘中独立生成，同一事件重复写2-3遍
- **改造内容**：
  1. 建立"今日事件池"（JSON），每份报告生成后写入已覆盖事件
  2. 日报：信息全景（全市场覆盖，每个事件1-2句+详情链接到S级）
  3. S级催化：单题材深挖（深度分析+交易策略+空方视角+证伪条件）
  4. 盘中快报：只写增量异动（较日报/S级新增的变化，不重复已写内容）
  5. 盘后速递：当日验证+持仓诊断+龙虎榜分析
  6. 报告间自动交叉引用链接（"详见S级催化→"）
- **改造范围**：新建content_dedup.py工具模块，各pro生成器集成

#### L1-2 预判验证闭环自动化 ⏳待启动（核心中的核心）
- **现状**：predictions.json仅3条记录，6/29后无新增，验证日程未自动跑
- **改造内容**：
  1. 报告生成时自动提取预判（LLM提取：方向/标的/目标/时间窗口/逻辑）
  2. 写入predictions.json统一格式：{id, title, level, category, direction, targets, catalyst, deadline, created_at, status: pending}
  3. T+2验证日程自动跑：搜索验证预判是否兑现
  4. T+3/T+5中期验证
  5. 验证结果更新correct/wrong/partial，附验证依据
  6. 准确率统计实时更新（S/A/B/C/D级）
  7. 错误预判自动归因（逻辑错误/信息变化/黑天鹅/时间判断偏差）
  8. 错误归因→自动写入错误教训库
- **改造范围**：prediction_center_pro.py重写+新增verify_predictions.py脚本+创建验证日程

#### L1-3 强制空方视角/证伪条件 ⏳待启动
- **现状**：风险提示只有一句话免责声明，无真正空方逻辑
- **改造内容**：
  1. S级催化强制包含"🔴 证伪条件/空方逻辑"模块
  2. 每个S级机会必须回答：什么情况会证伪？跌多少止损？什么逻辑被打脸？
  3. 持仓诊断必须包含"风险因素/止损条件/减仓信号"
  4. pro_base.py新增_risk_section()模板方法
- **改造范围**：s_level_catalyst_pro.py+portfolio_dashboard_pro.py

#### L1-4 持仓诊断升级 ⏳待启动
- **现状**：仅显示浮盈浮亏/止损价，无深度诊断
- **改造内容**：
  1. 估值锚：PE/PB分位数（vs 历史/行业），标注高估/合理/低估
  2. 资金流向：近5日主力净流入/流出趋势
  3. 关联标的联动：雅克↔HBM/存储链、英维克↔液冷/算力、铜冠↔铜箔/PCB
  4. 条件预案：什么价格减1/3/减1/2/清仓，什么信号可补仓
  5. 走势研判：支撑位/压力位/均线位置
- **改造范围**：portfolio_dashboard_pro.py重写+新增stock_diagnosis.py

#### L1-5 错误教训库接入生成链路 ⏳待启动
- **现状**：错误教训库470行但生成报告时从不读取
- **改造内容**：
  1. CodeAct脚本启动时自动读取`基础设定/错误教训库.md`
  2. 根据当日关键词/事件/板块匹配相关历史教训
  3. 报告末尾自动加"📚 历史教训回顾"模块
  4. 例：费半-5.44%→自动调出"费半单日暴跌超X%后A股半导体次日表现"历史案例
  5. 新增错误时自动追加到教训库
- **改造范围**：新建lessons_learner.py，各脚本启动时调用

### L2 体验交互（4项）

#### L2-1 TL;DR+锚点导航+信息层级 ⏳待启动
- **现状**：6000字报告无目录无摘要，手机滚10屏
- **改造内容**：
  1. 顶部TL;DR卡片：3条核心结论+今日操作建议（红/绿色标记）
  2. 右侧悬浮锚点目录：持仓诊断/S级催化/热点题材/龙虎榜/风险提示，点击平滑滚动
  3. 关键数据大号加粗高对比（涨跌幅/价格/资金量）
  4. 次要信息/历史回顾折叠（`<details>`标签）
  5. 持仓股金色高亮边框
- **改造范围**：pro_base.py新增TL;DR/TOC组件，CSS扩展

#### L2-2 移动端响应式适配 ⏳待启动
- **现状**：viewport有但无响应式CSS，手机上卡片/字号/间距不优化
- **改造内容**：
  1. @media (max-width: 768px)：单列布局
  2. 字号14px→16px（手机阅读友好）
  3. 卡片间距缩小（gap: 20px→12px）
  4. 底部固定导航栏（方便快速切换栏目）
  5. TOC在手机上改为底部抽屉式
  6. TL;DR卡片更紧凑
- **改造范围**：global-dark.css新增移动端媒体查询

#### L2-3 OG分享卡片 ⏳待启动
- **现状**：链接发到企微/微信无预览卡片
- **改造内容**：
  1. 每份报告自动注入og:title（报告标题）
  2. og:description（TL;DR摘要前100字）
  3. og:image（可生成简单封面图或用默认投资主题图）
  4. twitter:card等兼容标签
- **改造范围**：pro_base.py的HTML head模板扩展

#### L2-4 持仓金色高亮+工具箱智能化 ⏳待启动
- **现状**：持仓股无特殊标识，工具箱各页面静态
- **改造内容**：
  1. 报告中持仓股名字金色高亮+持仓图标
  2. 龙虎榜页增加筛选功能（可按持仓股/主线题材/游资筛选）
  3. 预判验证页可视化（准确率仪表盘/预判时间线/胜率统计）
  4. 题材健康度页面自动更新（每日数据刷新）
  5. 首页"今日必看"动态排序（根据S级催化等级/持仓影响度排序）
- **改造范围**：StockTags组件+多个工具页JS增强+home_page_pro.py

## 🔧 技术约束与铁律（升级时必须遵守）
1. 绝对禁止全量覆盖latest.html和index.html
2. 禁止从零写HTML模板，必须基于Pro生成器基类扩展
3. 全站强制深色玻璃态，禁止白色背景
4. 数据铁律：非交易日不生成虚构行情，股票数据必须搜索真实数据
5. 减仓≥30%必须双重验证
6. 每次修改后运行validate_system.sh，41项必须全通过
7. 生成器只写日期命名文件，latest/index.html由update_list_pages.py维护
8. 高频目录latest=副本直达，低频目录latest=卡片网格列表
9. 全站导航栏统一11按钮
10. 提交代码必须写清晰commit message

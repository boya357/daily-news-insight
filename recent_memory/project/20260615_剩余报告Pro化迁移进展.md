## 🐛 发现的 Bug 与修复

### 已修复
1. **函数定义顺序问题**：`generate_all_reports()` 原定义在 `main()` 之后，调用时报 NameError → 移到 main 之前
2. **PortfolioDashboardProGenerator 参数不匹配**：原用 `data_dir` 参数，实际需 `data_path` → 脚本中特殊处理
3. **TimeMachinePage 类名错误**：原脚本用 `TimeMachineProGenerator`，实际类名是 `TimeMachinePage` → 已修正
4. **TimeMachinePage 缺少 publish 方法**：继承 ProPage 无 publish 方法导致 daily_update.py 调用失败 → 已添加标准 publish 方法
5. **PortfolioDashboardProGenerator 百分比转换错误**：`'-52.3%'` 字符串无法直接转 float → 压力测试模块已修复去 % 号逻辑
6. **publish 返回格式不统一**：PortfolioDashboardProGenerator 原返回字符串路径 → 已改为标准字典格式 `{success, file_size, error, output_path}`

## 📝 重要经验教训

1. **Pro版报告必须先 build 再 render**
   - 直接实例化后调用 render() 会得到空页面
   - 必须先调用 `build_standard_report()` 填充内容

2. **生成器体系不统一**
   - 大部分继承 ProGenerator / ReportProGenerator
   - PortfolioDashboardProGenerator 是独立实现
   - TimeMachinePage 继承 ProPage
   - ⚠️ 批量处理时需注意特殊情况

3. **Python 脚本结构**
   - 函数必须在调用前定义
   - 大型脚本建议用类封装或按依赖顺序排列函数

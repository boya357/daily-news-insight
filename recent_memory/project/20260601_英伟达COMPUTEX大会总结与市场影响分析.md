- **地点**：台北国际电脑展

## 核心发布产品

### 1. RTX Spark超级芯片
- **定位**：正式进军PC市场，AIPC核心引擎
- **市场影响**：开启智能体PC新时代，PC产业迎来新一轮AI升级周期
- **受益标的**：工业富联、沪电股份、智微智能

### 2. Vera CPU
- **性能**：比x86快1.8倍
- **战略意义**：英伟达从GPU向CPU延伸，完整AI计算栈布局
- **市场影响**：重塑服务器CPU市场格局，x86传统厂商面临挑战

### 3. Vera Rubin AI平台
- **定位**：下一代AI超级计算平台
- **核心配置**：N1X芯片 + 金刚石散热解决方案
- **价值量升级**：单机柜PCB价值+233%，MLCC价值+182%
- **散热标配**：金刚石散热（热导率是铜的5倍）
- **受益标的**：黄河旋风、力量钻石、中兵红箭、沪电股份

### 4. Cosmos 3全能模型
- **能力**：多模态大模型升级，支持更复杂的推理任务
- **意义**：软件生态进一步完善，巩固英伟达AI护城河

### 5. Isaac GR00T人形机器人参考设计
- **发布方**：英伟达 + 宇树科技联合发布
- **意义**：人形机器人标准化加速，行业拐点临近
- **受益标的**：绿的谐波、拓普集团、步科股份、宇树科技（拟上市）

## 市场反应分析

### 当日市场表现
- **科技硬件板块**：PCB/CPO/光模块等集体回调5-8%
- **AI PC新题材**：逆势上涨，成为新的市场主线
- **风格切换**：高低切换明显，资金从高位硬件转向新题材

### 核心逻辑
1. **利好兑现**：前期涨幅较大的硬件板块借利好兑现
2. **新题材崛起**：AIPC/智能体PC成为新的市场主线
3. **产业链重构**：金刚石散热等新环节价值量重估

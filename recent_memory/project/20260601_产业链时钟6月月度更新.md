## 一、核心产业链状态更新

### 1. 存储芯片产业链 ⬆️ 升级
- **阶段调整**：成长期早期 → **成长期中期**
- **周期位置**：30% → 45%
- **核心逻辑**：
  - HBM占AI芯片BOM成本达63%，HBM4开始量产
  - 摩根大通上调2026-2028年市场规模预测53%
  - 长鑫科技Q1净利润暴增1688%，验证超级周期
- **建议仓位**：30% → **35%**

### 2. 英伟达产业链 ⬆️ 升级
- **阶段调整**：成长期中期 → **成长期后期**
- **周期位置**：55% → 75%
- **核心逻辑**：
  - Vera Rubin平台6月1日宣布全面投产，Q3出货
  - 单机柜PCB价值量+233%，MLCC+182%，金刚石散热成为唯一解
  - 配置重心从GPU转向配套环节
- **建议仓位**：30%（维持）

### 3. PCB/HVLP铜箔 ⬆️ 大幅升级
- **阶段调整**：成熟期早期 → **成长期后期**
- **周期位置**：25% → 65%
- **核心逻辑**：
  - HVLP4供需缺口666吨/月，缺口持续3年新常态
  - 行业年复合增速122%，定价模式从成本驱动转向价值驱动
  - 毛利率可达40-60%，三井产能不足客户外溢
- **建议仓位**：新增 **5%**

### 4. 先进封装 ✨ 新增重点产业链
- **阶段定位**：**成长期早期**
- **周期位置**：30%
- **核心逻辑**：
  - CoWoS产能缺口超50%，交付周期超18个月
  - 台积电首次主动引导客户向外部分封装厂转移
  - 国产替代3-5年历史性机遇窗口开启
- **建议仓位**：新增 **5%**

### 5. 人形机器人 ⬆️ 升级
- **阶段调整**：导入期后期 → **导入期末期**
- **周期位置**：75% → 85%
- **核心逻辑**：
  - 宇树科技73天闪电过会，估值420亿，出货量全球第一
  - 英伟达+宇树联合发布Isaac GR00T参考平台
  - 行业从"技术军备竞赛"转向"财报数字"，交付力成为核心
- **建议仓位**：15%（维持）

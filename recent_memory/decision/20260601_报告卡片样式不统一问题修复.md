# 2026年6月1日 报告卡片样式不统一问题修复

## 问题描述
2026年6月1日，在产业链总览页面添加新报告（英伟达COMPUTEX深度研究报告、AIPC产业链深度研究报告）时，使用了大卡片样式（rounded-3xl shadow-xl h-40 text-6xl），导致与原有小卡片样式不一致，破坏了页面整体视觉统一性。

## 问题影响
- 产业链总览页面视觉风格不一致，影响用户体验
- 新报告卡片过大，与历史报告卡片形成明显对比
- 页面布局失衡

## 根本原因
1. 没有统一的卡片样式规范
2. 添加新报告时没有参照原有样式
3. 缺少样式统一检查环节

## 解决方案
1. 将所有新报告卡片改回原有小卡片样式（p-5 bg-white border border-gray-100 rounded-xl text-center）
2. 在MEMORY.md中新增「报告卡片样式统一铁律」
3. 所有新卡片必须严格参照原有卡片DOM结构复制修改

## 修复后的卡片标准
```html
<a href="报告文件名.html" class="report-card block p-5 bg-white border border-gray-100 rounded-xl text-center group hover:shadow-lg transition-all">
    <div class="text-3xl mb-2">图标</div>
    <div class="font-semibold text-gray-800 text-sm mb-1 group-hover:text-indigo-600 transition-colors line-clamp-2">报告标题</div>
    <span class="inline-block px-2 py-1 text-xs font-bold bg-颜色-100 text-颜色-700 rounded">标签</span>
</a>
```

## 预防措施
1. 添加新卡片前，必须先复制一个历史卡片的完整DOM
2. 只修改href、图标、标题、标签颜色和文字
3. 禁止修改任何CSS类名
4. 提交前验证所有卡片视觉一致

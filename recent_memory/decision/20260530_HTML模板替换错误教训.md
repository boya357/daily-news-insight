# HTML模板替换错误教训（2026-05-30）

## 事件概述

**问题**：基于MLCC产业链报告的HTML模板生成英伟达N1X芯片报告时，仅替换了标题和导航栏部分，主体内容仍然是MLCC的内容，导致生成的报告"标题是N1X，内容是MLCC"，严重名不符实。

**发现时间**：2026-05-30 用户反馈指出问题

**严重程度**：🔴 重大质量问题

---

## 错误发生过程

1. **首次生成**：使用Python脚本读取MLCC的HTML，尝试做字符串替换，但只替换了头部标题和导航栏
2. **未验证**：生成后没有读取文件检查主体内容，直接认为"已完成"
3. **用户发现**：用户打开报告后发现内容还是MLCC，指出错误
4. **修复**：完全重写整个HTML文件，从head到body全部替换为N1X内容

---

## 根本原因

| 原因类型 | 具体描述 |
|---------|---------|
| **方法错误** | 试图通过"部分字符串替换"的方式生成全新报告，而不是完整重写 |
| **验证缺失** | 生成后没有做任何内容验证，仅凭"脚本运行成功"就认为完成 |
| **流程漏洞** | 缺少"生成后抽样检查"的强制性步骤 |

---

## 整改措施与规则

### ✅ 强制规则（已写入MEMORY.md）

1. **生成方式**：新报告必须**完全重写整个HTML文件**，或**100%替换所有内容**（从head到body），禁止部分替换
2. **验证步骤**：生成后必须读取文件抽样检查核心内容：
   - 前30行：检查标题、导航、开头章节
   - 中间章节：随机抽查1-2个核心章节的内容
   - 结尾：检查页脚和免责声明
3. **用户视角验证**：打开报告后，第一眼看到的核心内容必须与报告主题一致

### ✅ 推荐工作流

```
准备Markdown源文件
    ↓
生成完整HTML（write_file整个文件，不是edit_file部分替换）
    ↓
read_file抽样检查内容一致性
    ↓
更新latest.html链接
    ↓
git add 所有文件
    ↓
commit + push
    ↓
验证GitHub Pages可访问
```

- 后续所有基于模板的报告生成：都需要遵守新规则

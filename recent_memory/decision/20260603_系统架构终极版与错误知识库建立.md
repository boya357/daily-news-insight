# 系统架构终极版与错误知识库建立（2026-06-03）

## 一、决策背景

今日（2026年6月3日）发现并修复了多个严重的系统性问题，包括：

1. **报告内容缺失**：英伟达GTC与COMPUTEX催化超深度挖掘报告只写了第1章和第6章，中间核心分析章节全部缺失
2. **文件被错误覆盖**：修复导航栏时偷懒直接复制整个人形机器人报告文件，导致内容被完全覆盖
3. **导航栏样式不统一**：多个报告的导航栏按钮数量、标题、图标、样式不一致
4. **目录放错问题**：S级催化扫描和明日催化剂报告多次被错误地放到已废弃的"催化日历"目录
5. **模块边界混乱**：skill_daily-news-report技能生成报告时直接写latest.html，导致列表页被破坏

这些问题暴露了系统缺乏完整的架构规范和错误预防机制。

## 二、决策内容

### 1. 目录架构终极调整

**删除"催化日历"目录**，彻底解决目录混淆问题：
- ✅ S级催化扫描报告 → 统一存放到 `s级催化扫描/` 目录
- ✅ 明日催化剂报告 → 统一存放到 `明日催化剂/` 目录
- ❌ "催化日历"目录 → 永久删除，禁止再创建或写入

**最终11个报告类目录**：
daily、intraday、aftermarket、weekly_review、weekly_outlook、monthly、industry_chain、s级催化扫描、周末速递、明日催化剂

### 2. 导航栏样式100%统一

**全站标准玻璃态导航栏规范**：
- 标题统一："投资研究中心"
- 图标统一：📊 蓝紫渐变背景
- 按钮数量：11个（首页、日报、盘中、盘后、产业链、周复盘、周三前瞻、周末速递、明日催化、S级催化、月报）
- 链接路径：统一使用 `/daily-news-insight/xxx/latest.html` 格式
- 样式标准：glass-nav毛玻璃效果，禁止使用旧版bg-gradient类或自定义颜色

### 3. 两大核心文档建立

**《系统架构规范文档》SYSTEM_ARCHITECTURE.md**
- 16个目录完整分类与边界定义
- 标准导航栏HTML模板
- 7天稳定观察期执行计划
- 完整的目录映射表

**《错误知识库》ERROR_KNOWLEDGE_BASE.md**
- 记录6个典型错误（#001-#006）
- 每个错误包含：现象描述、根本原因、修复方案、预防措施
- 错误类型分布统计
- 改进措施跟踪表

### 4. 三层防护体系强化

**第一层：物理目录隔离**
- 11个报告类目录边界清晰
- 每周三前瞻与周复盘100%物理隔离
- S级催化扫描与明日催化剂目录分离

**第二层：15项自动化校验**
- 运行 `./validate_system.sh` 全量校验
- 目录存在性检查
- 文件一致性检查
- 链接有效性检查

**第三层：文档化规则 + 错误知识库**
- 所有规则写入 MEMORY.md 和 TOOLS.md
- 每个错误都记录到错误知识库
- 每次修复都补充预防措施

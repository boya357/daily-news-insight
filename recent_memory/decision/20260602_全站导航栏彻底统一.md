# 全站导航栏彻底统一决策记录

## 决策背景

**时间**：2026年6月2日

**问题**：全站导航栏存在多个不一致的问题
1. 导航链接数量不一致（首页12个，列表页12个，报告页12个，但链接顺序和样式不一致
2. 导航栏容器宽度不一致（max-w-7xl vs max-w-6xl）
3. z-index不一致导致某些页面导航栏点击失效
4. 存在"催化日历"导航链接，但该模块已停止更新

---

## 统一方案

### 1. 导航链接统一（11个）
```
首页 → 日报 → 盘中 → 盘后 → 产业链 → 周复盘 → 周前瞻 → 周末速递 → 明日催化 → S级催化 → 月报
```

### 2. 统一删除"催化日历"链接（因为模块已删除

### 3. 导航栏点击问题四层防护方案
```
1. body::before { pointer-events: none; }   // 全屏伪元素不拦截点击
2. .glass-nav { z-index: 2147483647 !important; }  // 最高层叠优先级
3. .glass-nav { isolation: isolate !important; }  // 创建新的层叠上下文
4. .glass-nav * { pointer-events: auto !important; }  // 导航内元素恢复点击
```

### 4. 统一所有页面导航栏样式
- 统一HTML结构
- 统一样式类
- 统一容器宽度

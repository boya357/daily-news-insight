# 首页与列表页覆盖问题永久解决方案

**日期：2026年6月1日**
**系统版本：V3.9**

---

## 🔴 问题背景

### 问题1：首页被覆盖
- 现象：`docs/index.html` 被错误地覆盖成了一个简单的报告列表页面
- 原因：报告生成脚本直接写入了首页文件，没有保护机制
- 影响：用户看到的首页不是原来的"市场洞察中心"玻璃态版本

### 问题2：产业链列表页被覆盖
- 现象：`industry_chain/latest.html` 被错误地覆盖成了一个全新的页面
- 标题变成了"产业链总览"，原来的"产业链全景追踪"丢失
- 布局从4列网格卡片变成了竖排大卡片
- 导航栏、CSS样式都变了
- 原因：没有先读取现有内容，直接用 `write_file` 整个覆盖

### 问题3：新报告页面不统一
- 新生成的报告没有使用统一的MLCC Pro v2.0模板
- 没有玻璃态导航栏
- 没有右下角三个悬浮按钮（打印/导出PDF、分享链接、返回顶部）
- CSS样式不统一

---

## ✅ 永久解决方案

### 一、首页保护规则（最高优先级）

1. `docs/index.html` 是特殊文件，禁止任何报告生成脚本直接覆盖
2. 产业链报告卡片只能添加到首页已有列表中，不能整体重写
3. 首页只能手动更新，或使用专门的 `update_homepage.py` 脚本（如无则必须手动编辑）
4. 每次修改首页前必须先git commit当前状态，确保可回滚
5. 禁止将latest.html跳转页逻辑应用到首页

---

### 二、报告页面统一规则（最高优先级）

1. **所有模块所有新生成的报告**都必须统一使用MLCC Pro v2.0标准模板
   - 统一的玻璃态导航栏
   - 统一的MLCC Pro v2.0 CSS样式
   - 统一的右下角三个悬浮按钮（打印/导出PDF、分享链接、返回顶部）
   - 统一的JS脚本

2. **绝对禁止自己从头写HTML模板！必须基于系统现有标准报告复制修改**

3. **标准模板来源**：从 `industry_chain` 模块找一个最近生成的标准报告（如 `20260531_人形机器人产业链深度研究报告.html`），完整复制一份

4. 复制标准模板后，**只允许修改：HTML标题、banner标题、正文内容**，**绝对不能动导航栏、CSS样式、悬浮按钮、JS脚本**

5. **标准验证清单**：生成报告后必须检查：
   - ✅ 标题栏是否有 "MLCC Pro v2.0" 标识
   - ✅ 右下角是否有三个悬浮按钮
   - ✅ 导航栏是否有完整10+个链接
   - ✅ CSS样式是否是紫色渐变玻璃态

---

### 三、列表页保护规则（最高优先级）

1. **绝对禁止**用 `write_file` 覆盖任何 `latest.html` 列表页
2. **绝对禁止**重新生成列表页的整体结构、导航栏、CSS样式
3. **绝对禁止**删除列表中已有的任何报告卡片
4. **列表页唯一允许的修改**：在报告列表最前面插入新报告卡片，格式必须和现有卡片完全一致

---

### 四、添加新报告的标准8步SOP（必须严格执行，一步都不能少）

| 步骤 | 操作 | 验证 |
|------|------|------|
| **第1步** | **复制标准报告模板** - 从 `industry_chain` 模块找一个最近生成的标准报告（如 `20260531_人形机器人产业链深度研究报告.html`），**完整复制一份**作为新报告的基础 | 确认文件完整，包含所有导航栏、CSS、悬浮按钮、JS |
| **第2步** | **修改新报告文件** - 只改HTML标题、banner标题、正文内容，**绝对不能动导航栏、CSS样式、悬浮按钮、JS脚本** | diff检查，只改了内容部分 |
| **第3步** | **验证报告页面** - 检查4项：标题栏有"MLCC Pro v2.0"、右下角有三个悬浮按钮、导航栏完整、样式正确 | 手动检查，必须全部通过 |
| **第4步** | `read_file` 读取现有latest.html完整内容 | 确认是正确的列表页结构 |
| **第5步** | 找到报告列表第一个卡片的插入位置 | 确认位置正确，不会破坏结构 |
| **第6步** | 用 `edit_file` + `replace_one` 只插入新卡片，其他不动 | 只插入卡片，不修改其他任何内容 |
| **第7步** | 本地验证列表页（head命令检查标题、导航栏没变） | 确认整体结构没有变化 |
| **第8步** | Git提交推送 → 访问链接做最后检查 | 确认GitHub Pages显示正确 |

此规则适用于所有列表页：industry_chain/latest.html、daily/latest.html、催化日历/latest.html等所有模块的列表页

# DeepWiki 第1章：系统架构总览

## 章节概述

投资研究系统是一个面向A股市场的自动化投研内容生成平台，采用分层架构设计，从底层数据到上层展现形成了完整的价值链路。系统每日自动生成盘前早报、午间速递、收盘深度洞察三份核心报告，并提供持仓预警、板块热力图、龙虎榜透视、题材分析等十余个工具页面。

系统架构经历了从V1单体脚本到V2模块化、V3插件化、再到V4组件化的多次演进，逐步形成了"数据层-引擎层-生成层-组件层-展现层"的五层经典架构。其核心设计理念是"内容与展现分离、数据与逻辑分离、工具与报告分离"，通过分层解耦实现了快速迭代和高质量输出的平衡。

## 子主题规划

### 1.1 系统定位与核心价值
- 面向个人投资者的AI投研助手
- 7×24小时自动化内容生产
- 从数据到洞察的全链路覆盖
- 多维度投资决策辅助

### 1.2 架构演进历程
- V1 时代：单文件脚本，功能耦合
- V2 时代：模块化拆分，生成器模式出现
- V3 时代：插件化架构，工具页面爆发式增长
- V4 时代：组件化设计，统一设计语言

### 1.3 五层架构全景
- 第一层：数据层（Data Layer）- 行情、新闻、财务数据获取与清洗
- 第二层：核心引擎层（Core Engine）- 配置、模板、发布引擎
- 第三层：内容分析层（Content Engine）- 持仓、市场、题材、新闻分析
- 第四层：生成器层（Generators）- 各类型报告与工具页面生成
- 第五层：组件库层（Components）- UI组件与交互元素

### 1.4 核心设计原则
- 单一数据源原则：杜绝数据不一致
- 内容与展现分离：分析逻辑与UI解耦
- 渐进式降级：局部故障不影响整体
- 质量优先：宁慢勿错，数据准确第一
- 可观测性：全链路状态可追踪

### 1.5 技术栈总览
- 后端语言：Python（核心生成逻辑）
- 前端框架：原生HTML + Tailwind CSS + JavaScript
- 数据源：腾讯财经、东方财富、韭研公社等
- 部署平台：GitHub Pages
- 自动化：GitHub Actions + 定时任务

### 1.6 系统能力版图
- 报告类：日报/午报/晚报/周末刊/周复盘
- 工具类：持仓预警/板块热力/龙虎榜/数据时光机
- 题材类：题材健康度/题材深度/S级催化/智能选题
- 个股类：100+只个股深度分析
- 验证类：预判验证中心/周度进化报告

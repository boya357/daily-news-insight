# DeepWiki 第5章：数据层 - 系统的数据基石

## 章节概述

数据层是整个投资研究系统的基石，负责所有市场数据的获取、清洗、校验和统一管理。系统遵循"单一数据源"原则，所有报告和工具页面都从统一数据层加载数据，从根本上杜绝了数据不一致的问题。

数据层采用分层架构设计，从底层的行情获取到上层的业务数据封装，形成了完整的数据供应链路。其核心设计哲学是"稳定优先、质量兜底"——即使外部接口不稳定，也能通过多数据源冗余、失败保护等机制保证系统基本运行。

## 核心技术亮点

1. **多数据源冗余**：主备数据源自动切换，单接口故障不影响系统运行
2. **失败不覆盖**：接口失败时保留上一次成功数据，宁旧不错
3. **三级数据质量**：L1基础信息 / L2技术分析 / L3深度研究，分级保证
4. **单一数据源**：所有生成器从统一数据层读取，杜绝数据不一致
5. **增量更新机制**：智能判断哪些股票需要更新，减少不必要的接口调用

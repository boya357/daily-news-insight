# DeepWiki 第6章：内容分析引擎 - 智能分析的大脑

## 章节概述

内容分析引擎是系统的"大脑"，负责将原始数据转化为有洞察力的投资分析内容。它采用模块化设计，每个分析引擎专注于一个特定领域，通过统一的内容模型接口输出结构化分析结果，再由生成器层决定如何呈现。

这一层遵循"内容与展现分离"的设计原则——分析引擎只负责产出高质量的结构化分析结论，不包含任何HTML或UI代码。这种架构使得同一分析结果可以被多种展现形式复用（日报、专题报告、工具页面等），同时也便于单独优化分析质量。

## 核心技术亮点

1. **内容与展现彻底分离**：分析引擎纯逻辑，不掺任何UI代码，实现真正的架构解耦
2. **多维度加权评分**：每个分析维度独立评分，按权重聚合为整体质量分，量化内容质量
3. **统一内容模型**：所有引擎输出格式一致，便于组合、复用和对比
4. **自校验机制**：每个分析结果都能自我验证质量，低于门槛直接标记异常
5. **模块化可扩展**：新增分析领域只需继承基类实现analyze方法，快速扩展

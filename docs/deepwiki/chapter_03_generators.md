# DeepWiki 第3章：生成器体系 - 内容生产的流水线

## 章节概述

生成器体系是系统的内容生产流水线，负责将数据和分析结果转化为最终的HTML页面。系统拥有十余个不同类型的生成器，涵盖日报系列、工具页面、题材分析、个股研究等多个领域，每个生成器专注于一类内容的生产。

这一层采用"每个生成器一个文件"的组织方式，保持了高度的独立性和可扩展性。新的报告类型或工具页面可以通过新增一个生成器快速实现，而不需要改动核心框架。V3时代生成器数量爆发式增长到73+个，也验证了这种架构的可扩展性。

## 核心技术亮点

1. **单体独立**：每个生成器一个文件，职责单一，便于维护和测试
2. **增量演进**：新老版本生成器并存，逐步迁移，不搞休克式重构
3. **分层复用**：通用逻辑下沉到基类和工具层，生成器只关注业务逻辑
4. **可观测**：每个生成器都有独立的状态监控和错误日志
5. **批量能力**：支持100+只个股的批量并行生成，效率与质量并重

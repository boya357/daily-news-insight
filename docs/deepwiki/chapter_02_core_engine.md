# DeepWiki 第2章：核心引擎层 - 系统的动力心脏

## 章节概述

核心引擎层是整个系统的动力心脏，提供了配置管理、模板渲染、发布调度等基础能力。它是连接数据层和生成器层的中间枢纽，为所有上层应用提供统一的基础设施服务。

这一层的设计体现了"机制与策略分离"的原则——引擎只提供基础机制（如何加载配置、如何渲染模板、如何发布内容），而具体的业务策略（生成什么内容、用什么模板、什么时候发布）由上层生成器决定。这种架构使得核心引擎可以保持稳定，而上层业务可以快速迭代。

## 核心技术亮点

1. **分层配置**：三级配置合并机制，既保证默认值合理又支持灵活定制
2. **统一生成器接口**：所有生成器遵循同一规范，便于管理和扩展
3. **工作流编排**：支持复杂的依赖关系和并行执行，提升生成效率
4. **模板继承体系**：布局与内容分离，减少重复代码，保证风格一致
5. **生命周期管理**：每个报告都有完整的状态追踪，可回溯、可重放

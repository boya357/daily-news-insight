三、每日情报

3.1 政策催化

  • 国产替代: 半导体先进封装被列为重点突破方向
  • 大基金支持: 国家集成电路产业基金持续支持封装企业扩产
  • 税收优惠: 先进封装企业享受所得税优惠
  • 技术攻关: 02专项持续支持先进封装技术研发

3.2 产业动态

  • 英伟达: 锁定台积电70% CoWoS产能，用于H100/B100/GB200
  • AMD: MI300X需求旺盛，抢购CoWoS封装产能
  • 谷歌: TPU v5持续放量，加码封装产能
  • 字节跳动: 自研AI芯片，布局先进封装
  • 台积电: CoWoS扩产计划，但产能释放需时间
  • 国产突破: 通富微电、长电科技先进封装产能扩张
  • TSV技术: 3D堆叠封装成为HBM和AI芯片的核心支撑

3.3 资金动向

  • 板块资金: 先进封装板块持续获得资金关注
  • 机构调研: 通富微电、长电科技等获得机构密集调研
  • 融资动态: 多家封装企业定增扩产
  • 减持风险: 关注部分标的原始股东减持压力

3.4 供需格局

时期供需状态价格走势

5.2 风险提示

  1. 设备风险: 先进封装设备依赖进口，国产化率低
  2. 材料风险: ABF载板、PSPI等关键材料被海外垄断
  3. 竞争风险: 台积电等海外厂商竞争压力
  4. 需求风险: AI芯片需求周期性波动
  5. 技术风险: 封装技术路线不确定性
  6. 地缘风险: 海外设备出口管制影响扩产
  7. 估值风险: 部分标的估值偏高

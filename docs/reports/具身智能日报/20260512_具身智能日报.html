三、每日情报

3.1 政策催化

  • 国家战略: 政府工作报告首次将具身智能列为重点发展领域，与集成电路、航空航天并列
  • 标准体系: 《具身智能标准体系建设指南》正式发布，明确技术标准、安全标准、应用标准
  • 产业基金: 多地设立具身智能产业基金，总规模超500亿元
  • 补贴政策: 人形机器人采购补贴政策即将出台，最高补贴30%
  • 试点推进: 北京、上海、深圳率先开展人形机器人应用试点

3.2 产业动态

  • 宇树科技: 人形机器人H1全球出货量第一，四足机器人市占率60%+
  • Figure: Figure 02人形机器人即将进入量产阶段
  • 特斯拉: Optimus人形机器人2026年目标量产1万台
  • 智元机器人: 远征A1实现量产，聚焦工业场景
  • 傅利叶智能: GR-1通用人形机器人商业化落地
  • 小米: CyberOne持续迭代，进军工业场景
  • 华为: 盘古具身智能大模型发布，切入机器人领域
  • 比亚迪: 积极布局人形机器人，用于汽车制造

3.3 资金动向

  • 板块资金: 具身智能板块今日净流入约8亿元
  • 融资动态: 智元机器人新一轮估值达80亿元
  • 机构关注: 中大力德、绿的谐波获得多家机构调研
  • 减持风险: 关注部分标的原始股东解禁压力

3.4 技术进展

  • AI大模型: 具身智能大模型能力持续提升，泛化能力增强
  • 灵巧手: 灵巧手自由度提升，成本大幅下降
  • 传感器: 力传感器、视觉传感器精度持续提升
  • 运动控制: 双足行走稳定性显著改善

5.2 风险提示

  1. 技术风险: 人形机器人技术成熟度仍待提升，成本居高不下
  2. 量产风险: 量产节奏可能低于预期
  3. 竞争风险: 国内外企业加速布局，竞争趋于激烈
  4. 替代风险: 其他形态机器人可能形成替代
  5. 估值风险: 部分标的估值偏高，需等待回调
  6. 政策风险: 补贴政策落地节奏存在不确定性

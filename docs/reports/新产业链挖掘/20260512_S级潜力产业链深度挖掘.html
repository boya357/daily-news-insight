🎯 投资策略总结

S级核心主线（重仓参与）

1. AI Agent / 企业级AI - 政策+业绩双击，三部门文件是国家级背书
2. 先进封装（CoWoS） - AI芯片最窄瓶颈，国产替代最确定方向
3. 军工外贸 - 实战验证改变认知，大订单催化密集

A级弹性方向（重点配置）

4. 人形机器人供应链 - 量产元年，减速器/电机订单爆发
5. 固态电池（细分场景） - 低空经济带动，eVTOL/无人机先落地
6. AI手机/PC换机 - 苹果折叠屏+AI功能双重催化

操作节奏

- 龙空龙策略核心：等待催化确认后追入最强标的，快速止损
- 最佳介入时机：政策文件发布次日、重大订单公告、财报超预期后

三、每日情报

3.1 政策催化

  • 三部门联合发文: 工业和信息化部、中央网信办、国家发展改革委联合发布《人工智能agent应用普及行动计划（2026-2027年）》，明确要求到2027年实现AI Agent在重点行业和领域的普及率达到70%
  • 北京政策: 发布人工智能+行动年度计划，支持企业在办公、制造、金融等领域部署Agent
  • 上海政策: 推动大模型创新发展，Agent应用场景加速落地
  • 企业激励: 首批中小企业AI Agent应用补贴，最高500万元

3.2 产业动态

  • 微软重磅: Copilot Agent 365正式发布，支持自动化工作流程，企业效率提升15倍
  • OpenAI: 企业级Agent平台上线，支持自定义Agent构建和部署
  • 埃森哲: 宣布74万员工全面部署微软Copilot，成为全球最大规模企业AI应用案例
  • 钉钉: "悟空"AI Agent正式发布，聚焦企业协同办公场景
  • 飞书: 多维表格AI功能升级，支持智能数据分析和自动化
  • Salesforce: Einstein Agent平台新增多Agent协作功能

3.3 资金动向

  • 板块资金: AI Agent概念板块今日净流入资金约15亿元
  • 重点标的: 汉得信息、金山办公、用友网络等核心标的获得机构资金关注
  • 融资动态: 多家人工智能Agent初创公司获得新一轮融资
  • 减持风险: 关注部分标的原始股东减持压力

3.4 海外动态

  • 微软: Copilot产品线全面升级，Agent能力大幅提升
  • Google: Gemini 2.0发布，强化Agent能力
  • Amazon: AWS推出AI Agent服务，切入企业市场

五、投资策略与风险提示

5.1 投资建议

标的当前状态建议

5.2 风险提示

  1. 技术风险: Agent能力仍存在幻觉、推理不稳定等问题
  2. 商业化风险: 企业付费意愿和能力存在不确定性
  3. 竞争风险: 互联网巨头入局，竞争格局可能剧变
  4. 政策风险: AI监管政策可能影响应用落地进度
  5. 估值风险: 部分标的估值偏高，需等待合适买点

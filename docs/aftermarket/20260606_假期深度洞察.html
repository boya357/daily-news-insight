🔄 风格切换核心特征
01 极致分化：指数普跌但超六成个股上涨，"一九行情"特征明显，资金从高位抱团向低位扩散
02 高低切换：AI算力、半导体等前期强势板块深度回调，银行、商贸零售、化工等低位板块逆势走强

📰 周末重要资讯

国际
🇺🇸 美国5月非农数据大超预期，加息预期升温
美国5月非农就业新增17.2万人，远超市场预期的8.8万人；失业率维持在4.2%。
影响：市场推迟降息预期，甚至开始定价12月加息可能性。美债收益率跳升，美元走强，黄金暴跌2.88%失守4350美元。
对A股影响：科技股或受情绪压制，北向资金短期可能流出，关注低开后企稳情况。
市场
📉 美股科技股集体暴跌，纳指跌超4%
受非农数据影响，美股三大指数全线大跌。纳斯达克指数下跌4.18%，费城半导体指数暴跌超10%，创2020年以来最大单日跌幅。
英伟达跌超6%，AMD跌近11%，博通跌近8%。科技股整体市值蒸发超万亿美元。
产业
🤖 人形机器人产业加速落地，量产元年开启
宇树科技IPO过会，累计下线超1.1万台，2025年营收16.99亿元，三年涨10倍。
特斯拉Optimus V3预计2026年7-8月启动量产，已向国内供应商下发采购订单。
核心零部件国产化率突破70%，整机价格下探至万元级，B端采购需求集中释放。
投资主线：减速器、伺服电机、传感器、灵巧手等核心环节。
政策
🏛️ 国常会部署新产业，多领域政策利好
商业航天、低空经济、AI+制造被列为重点发展方向，产业支持政策有望陆续出台。
工信部组织开展6G创新发展部省协同试点，2029年前形成自主创新技术方案。
央行维持流动性合理充裕，DR001持续处在1.2%低位，市场资金面稳定。

🔮 下周行情展望

📅 整体判断：震荡磨底，结构分化
预计下周大盘延续区间震荡整理格局，沪指围绕4000点反复拉锯。高位科技板块仍需消化抛压，低位价值与成长有望持续获得资金青睐。
一 周一：外围情绪消化，低开概率大
受美股科技大跌影响，A股大概率低开。高位AI、半导体集中补跌，创业板、科创50承压；内资长线资金流入低位消费、高股息板块，指数跌幅收窄。
二 周二-周三：利空消化，延续分化
经过周一情绪释放，北向资金停止大额净流出，市场进入多空拉锯。高位科技震荡磨底，低位主线稳步走强，指数在4000-4060点区间震荡。
三 周四-周五：抛压出清，逐步企稳
全周高位获利抛压充分释放，内资回流带动大盘重心抬升，低位板块全线走强拉动指数回升，周线有望探底回升收出十字星。

💎 下周核心主线

🤖 人形机器人 / 智能制造
核心逻辑：产业催化密集 + 政策支持 + 量产元年。特斯拉Optimus量产临近，宇树科技IPO带动板块情绪，核心零部件国产替代加速。
关注方向：减速器（绿的谐波、双环传动）、伺服电机（汇川技术）、传感器、执行器、整机制造。
🏦 高股息 / 防御性板块
核心逻辑：市场震荡期防御属性凸显，高低切换资金避风港。股息率吸引力提升，保险、银行、公用事业等板块获资金青睐。
关注方向：国有大行、股份制银行、火电运营商、煤炭龙头。
🧪 化工 / 周期品涨价
核心逻辑：供给侧收缩 + 需求复苏共振，部分化工品价格持续上涨。机构高低切换背景下，低估值周期板块获资金加仓。
关注方向：玻璃基板、化纤、钛白粉、氟化工等细分品种。

📝 操作策略建议

减
重仓高位科技（7成以上）
分批降仓、腾挪低位。冲高乏力先减3成，午后反弹再减2成，总仓位控制在3成以内。空出资金逢指数回调布局低位板块。深度被套标的，等待技术性反弹再降仓。
持
持有低位蓝筹（3-5成）
持股躺平、闲钱分批加仓。不跟随短期波动止损，盘面急跌时用闲置资金小幅加仓，以中长期持有为主，享受风格切换带来的估值修复。
观
空仓或轻仓（2成以下）
不急于重仓抄底，耐心等待支撑位确认。指数回踩4000点、恐慌盘释放后，从低位消费、高股息、创新药三个方向分批建仓，单日买入不超过闲置资金1/3。

3. 半年末流动性扰动：6月末银行半年度考核，市场资金面可能出现阶段性紧张
4. 半年报业绩风险：业绩预告窗口期，部分高位题材股可能面临业绩证伪

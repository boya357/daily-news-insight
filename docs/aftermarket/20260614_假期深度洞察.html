🎯 核心观点

市场呈现典型的指数搭台、题材唱戏格局。上证指数放量站稳4000点，3.21万亿的历史天量显示资金分歧极大，但也意味着接盘力量充足。周末两大利好（6000亿流动性+指数样本调整）有望催化下周一进一步上攻。 结构上，资金从高位科技向低位周期、金融、军工扩散，高低切换明显。存储芯片、先进封装等主线逻辑未破，但短期需消化获利盘。建议保持均衡配置，关注低位补涨机会的同时，逢低吸纳主线回调后的优质标的。 下周一重点关注：1）量能能否维持在3万亿以上；2）4050点压力位突破情况；3）北向资金流向；4）指数调整成分股的表现。

🎯 明日操作计划

整体策略：周末两大利好加持，预计下周一高开概率大。但3.21万亿天量后资金分歧加剧，不宜盲目追高，建议逢低加仓为主。仓位建议6-7成。

关注方向：
1. 有色金属/小金属：当前最强主线，量价齐升，可关注铜箔、钨、稀土等细分领域，铜冠铜箔可继续持有，若回调至5日线附近可加仓。
2. 券商/大金融：市场活跃度提升直接受益，估值处于历史低位，可逢低配置。
3. 存储芯片/先进封装：长鑫科技IPO注册生效，产业链关注度提升，回调后可低吸，雅克科技可持有观察。
4. 低空经济/军工：政策催化不断，事件驱动型行情，可适当参与。

持仓操作：
- 铜冠铜箔：创历史新高，趋势强劲，持有为主。若高开过多（>5%）可适当减仓锁定利润，回踩5日线再接回。
- 英维克：继续调整，暂时观望，等待企稳信号（如站上5日线）再考虑操作。止损位60元，若跌破需果断减仓。
- 雅克科技：存储产业链核心标的，持有为主，可逢低加仓。
- *ST建艺：摘帽预期仍在，继续持有等待消息落地。

风险控制：下周一若高开低走收放量阴线，需警惕短期见顶风险，可适当降低仓位。端午节前注意控制仓位，避免持仓过重过节。

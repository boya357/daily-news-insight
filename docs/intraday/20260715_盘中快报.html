盘中快报

2026年7月15日 · 午盘速递 · 三大指数窄幅震荡科创50大跌3.67%，创新药/CXO爆发领涨，半导体产业链集体重挫，央行1.4万亿买断式逆回购托底流动性

午盘焦点
7月15日（周三）A股走出「权重托底+科创杀跌+高低切换极致分化」的震荡行情。受央行1.4万亿买断式逆回购（净投放5000亿）托底流动性影响，沪指权重表现稳健；但科技成长股遭遇剧烈调整，科创50大跌3.67%领跌全场。截至午盘，上证指数跌0.08%报3963.90点，深证成指跌0.38%报14868.23点，创业板指跌0.36%报3837.23点，科创50暴跌3.67%报1936.06点，北证50跌0.65%。半日成交1.72万亿，较上一交易日放量约900亿，全市场3682只个股上涨、1772只下跌，涨跌比约2:1，64只涨停、51只跌停。核心特征：①创新药/CXO板块全面爆发（博瑞医药、迪哲医药、睿智医药20CM涨停，昭衍新药涨停，康龙化成/美迪西涨超10%）——创新药对外授权81笔/1100亿美元创历史新高；②白酒/零售大消费回暖（金种子酒涨停，古井贡酒涨超8%，宁波中百/新华百货涨停）——扩大消费「十五五」规划落地；③半导体产业链集体重挫（德明利一字跌停，华天科技跌停，沐曦股份/佰维存储跌超10%，雅克科技跌超6%）——德明利中报Q2环比下滑引爆存储业绩担忧；④算力硬件全线回调（PCB、先进封装、GPU、存储器跌幅居前）——长鑫科技IPO明日申购分流预期+中报业绩验证期高位兑现。本质是「中报业绩验证期+高低切换+流动性宽松托底」的组合：央行1.4万亿中长期流动性投放给市场打底，但科技成长股在业绩验证期遭遇高位获利兑现，资金从高位算力硬件流向低位医药消费防御。沪指3950点附近支撑明确，科创50短期调整压力较大。

7月15日（周三）A股呈现极致分化行情——沪指微跌0.08%报3963点权重托底，科创50暴跌3.67%科技重挫，半日成交1.72万亿放量约900亿，3682涨/1772跌（涨跌比2:1），64涨停/51跌停。创新药/CXO、白酒消费领涨，半导体全产业链领跌。
核心特征：央行1.4万亿流动性托底+中报业绩验证期+高低切换极致分化。央行开展1.4万亿6个月期买断式逆回购（净投放5000亿+本月合计净投放7000亿），为市场提供充足流动性安全垫，权重股因此表现稳健；但科技成长股在7月15日中报预告截止日遭遇业绩验证+高位兑现双重压力，科创50暴跌3.67%。这是典型的「流动性底+结构熊」格局——指数不会大跌，但内部结构剧烈调整。沪指3950点附近支撑明确，上方压力在4000点整数关；科创50短期调整压力大，需等待企稳信号。

· *ST建艺（-1.91%）：坚决清仓，绝不留恋！基本面持续恶化，退市风险高悬；
2. 方向把握：①创新药/CXO——今日最强主线，政策+业绩+资金三重驱动，趋势性走强信号明确，回调可关注CXO龙头与差异化创新药品种；②白酒/大消费——政策催化+估值修复+资金避险，短期有反弹动能，关注高端白酒龙头；③影视院线——暑期档催化，事件驱动型机会，关注头部内容公司；④规避方向：高位纯题材科技股（存储/算力/PCB短期获利兑现压力大）、半导体设备材料（调整未结束）、ST股；
3. 仓位建议：市场极致分化+科技调整期，建议总仓位5-6成，从高位科技向低位医药消费适度切换，保持攻守平衡。不抄底下跌趋势中的科技股，不追高涨起来的医药消费股。
4. 午后关注点：①科创50是否继续探底（半导体板块企稳信号）；②沪指能否守住3950点支撑；③跌停家数是否扩大（51→60+则情绪恶化）；④创新药/CXO板块持续性（能否延续到下午）；⑤北向资金流向（外资态度）；⑥成交量变化（放量下跌则需警惕）。

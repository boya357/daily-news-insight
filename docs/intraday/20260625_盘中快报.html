盘中快报

2026年6月25日 · 午盘速递

午盘焦点
今日A股三大指数集体上涨，沪指涨0.36%，深成指涨1.46%，创业板指涨2.01%，科创50指数涨超4%领涨市场。市场呈现明显的结构性行情特征，权重股表现强势，个股跌多涨少，超4200只个股下跌。 截至午间收盘，上证指数报4125.76点，涨0.36%；深证成指报16285.83点，涨1.46%；创业板指报4336.74点，涨2.01%；科创50指数涨超4%，盘中再创历史新高。 两市半日成交额约2.42万亿元，较昨日同期放量约3370亿元。上涨个股不足1000只，下跌个股超4200只，市场分化极为明显，资金集中抱团科技龙头与大金融权重。 消息面上，美光科技披露2026财年第三财季业绩大幅超市场预期，营收、毛利率均创行业新高，带动存储芯片板块集体走强；券商板块迎来业绩、估值、产业趋势三重共振，成为指数上涨核心动力。

🔥 市场热点解析

券商/大金融 券商板块集体走强，中信建投、长江证券连板
🔥 热门
券商板块今日再度强势拉升，中信建投、长江证券走出连板行情，财达证券、方正证券涨超6%，中国银河、东方财富等跟涨。催化因素：证券板块当前处于业绩高增、估值低位、产业趋势加速三者共振窗口期。中报业绩预告显示券商业绩普遍高增，同时资本市场改革持续推进，ETF规模快速扩张、做市业务、科创板并购重组等利好不断。在科技板块交易拥挤度攀升背景下，资金高低切换偏好低估值蓝筹，券商板块兼具弹性与估值修复空间。

存储芯片/先进封装 美光财报超预期，存储芯片板块集体爆发
🔥 热门
存储芯片板块今日大幅高开，太极实业一字涨停创历史新高，长电科技涨停，雅克科技涨超3%，芯原股份涨超15%。消息面上，美光科技披露2026财年第三财季业绩大幅超市场预期，经调整营收达414.6亿美元、调整后每股收益25.11美元，均创历史新高；同时公司给出的第四财季营收指引490-510亿美元，同样显著超出市场预期。美光CEO表示，受全产业链AI需求叠加供给端结构性约束影响，预计供需紧张格局将延续至2027自然年之后。此外，SK海力士计划登陆纳斯达克募资，进一步提振板块情绪。
相关标的
太极实业 长电科技 雅克科技 芯原股份

机场航运板块今日表现活跃，民用航空板块涨幅超4%。催化因素：暑期出行旺季临近，民航需求持续复苏，多家航空公司公布的暑运计划显示运力投放大幅增长。同时，国际航线恢复进程加快，国际客流持续回升，航空公司盈利改善预期增强。行业供需格局优化，叠加消费升级趋势，民航板块中期修复逻辑清晰。

🎯 午盘操作策略

一、市场判断
今日A股三大指数集体上涨，创业板指、科创50表现强势，市场呈现明显的结构性行情特征。权重股与科技龙头表现亮眼，但个股跌多涨少，超4200只个股下跌，资金集中抱团效应显著。两市半日成交2.42万亿，较昨日放量，市场活跃度仍处高位。

二、核心逻辑
1. 美光财报超预期：存储芯片龙头业绩大超预期，验证AI存储需求持续爆发，供需紧张格局延续至2027年，科技成长主线逻辑强化。
2. 高低切换进行时：半年末机构调仓持续，资金从高位题材向低估值蓝筹（券商、大金融）和硬核科技龙头转移，市场风格再平衡。
3. 流动性支撑：央行维持流动性合理充裕，市场整体下行空间有限，结构性行情延续。
4. 风险点：美联储鹰派信号、半年末流动性波动、个股业绩分化加剧。

三、操作策略
1. 持仓策略：英维克液冷逻辑强化，继续持有逢低加仓；铜冠铜箔短期波动加大，建议控制仓位，回调后可逢低布局；雅克科技趋势向上，持有为主；*ST建艺建议减仓规避风险。
2. 方向把握：聚焦AI算力、存储芯片、先进封装等科技成长核心赛道，关注业绩确定性强的龙头标的；可适度配置券商、大金融等低估值蓝筹对冲波动。
3. 风险控制：半年末时点流动性波动加大，切忌追涨杀跌。严格执行止损纪律，保持合理仓位，留有现金应对可能的市场调整。
4. 关注要点：午后关注沪指4150点压力位、创业板指能否延续强势、北向资金流向变化，以及量能是否持续放大。

四、后市展望
短期市场处于风格再平衡阶段，指数震荡上行概率较大，但个股分化将持续。中期来看，AI产业浪潮、流动性宽松、政策支持三大核心支撑逻辑依然存在，科技成长仍是主线。建议利用市场波动优化持仓结构，聚焦业绩确定性强、产业趋势明确的核心标的，同时适度配置低估值蓝筹对冲组合波动。

📝 市场逻辑总结

今日市场核心特征：指数齐涨、结构分化、科技领跑、金融助攻。三大指数集体上涨，科创50领涨并创历史新高，但个股跌多涨少，超4200只个股下跌，资金集中抱团效应明显。 盘面上，美光财报超预期带动存储芯片、先进封装板块走强；券商板块业绩+估值+产业趋势三重共振，成为指数上涨重要推手；液冷、PCB等AI算力产业链延续活跃。贵金属、ST板块、互联网等板块领跌。 操作上，建议顺应市场节奏，聚焦AI算力、存储芯片等科技成长核心赛道龙头，同时适度配置低估值蓝筹对冲波动。控制仓位、保持耐心，把握结构性机会。

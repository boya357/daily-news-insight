🎯 午盘操作策略

【整体策略】震荡分化，聚焦主线，严控仓位

1. 大盘判断：沪指低开高走涨0.76%，全市场近4500只个股上涨，半日成交2.17万亿放量4700亿，市场情绪回暖。但创业板指和科创50下跌，结构分化明显，权重搭台题材唱戏格局。沪指4100点附近有压力，注意冲高回落风险。

2. 持仓操作：
• 雅克科技（+4.53%）：创新高后回落，220元以上分批止盈，215-225减1/3，趋势未破留底仓
• 英维克（+1.58%）：反弹减仓良机，75-78元区间坚决减仓至1/3以下
• 铜冠铜箔（-1.40%）：高位震荡，140-145减仓锁利，跌破135止盈离场
• *ST建艺（平盘）：立即清仓，退市风险股不抱幻想

3. 方向选择：
• 医药（CRO/创新药/减肥药）：政策催化+BD放量，短期爆发力强，关注首板机会
• 人形机器人：中期主线，回调低吸核心零部件龙头
• 半导体设备：长鑫IPO催化+国产替代，设备端确定性最高
• 存储产业链：高位分化，去弱留强，雅克科技等龙头趋势未破可持有

4. 仓位管理：当前整体仓位建议控制在5-6成，高位股逢高减仓，低位题材可小仓位试探。严格执行止损纪律。

📝 市场逻辑总结

今日午盘市场呈现指数分化、个股普涨格局：沪指震荡拉升涨0.76%，创业板指和科创50冲高回落。市场主线从科技硬件（存储、半导体）向医药、AI应用、机器人等方向扩散，板块轮动加速。 核心逻辑： 1. 政策面：医药零售政策、创新药BD大爆发催化医药板块全面走强，成为今日最强主线 2. 资金面：半日成交2.17万亿放量4700亿，市场流动性充裕，近4500只个股上涨 3. 题材面：AI应用端（欢瑞世纪7天4板）、人形机器人、半导体设备多点开花 4. 分化面：前期强势的电子特气、半导体材料回调，存储板块内部分化 下午关注：沪指能否站稳4050点、创业板指能否止跌、医药板块持续性、存储产业链龙头走势。

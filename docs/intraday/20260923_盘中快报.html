午盘焦点
⚡ 三大指数高开低走集体收跌，PET铜箔/玻璃基板/CRO/地产逆势走强，传媒影视/煤炭/油气大幅调整，超3500股下跌，铜冠铜箔涨超2%创阶段新高

🎯 午盘操作策略

【整体策略】缩量调整市谨慎防守，聚焦业绩确定性强的铜箔链等方向

一、大盘判断：缩量震荡调整，市场情绪偏弱
周三早盘三大指数高开低走集体收跌，半日成交缩量至1.17万亿（较昨日少2,696亿），超3,500只个股下跌，市场情绪偏弱。缩量下跌说明抛压不大但买盘也不积极，资金在板块间快速轮动。预计午后指数继续维持窄幅震荡，下行空间有限但上攻动力不足，整体以结构性行情为主。

二、操作策略：聚焦业绩主线，控制仓位灵活应对
1. 仓位控制：整体仓位维持5-6成，缩量调整市不宜盲目追高，耐心等待更好的入场时机；
2. 持仓操作：
  • 英维克：61-62元区间观望，跌破60元减仓，反弹至66-68元减机动仓；
  • 铜冠铜箔：底仓坚定持有，回踩112-115元可加机动仓，冲高至120元以上分批止盈机动仓；
  • 雅克科技：底仓持有观望，120-125元区间考虑加仓，反弹至140+减仓；
  • *ST建艺：投机仓位持有，止损位12.0元，反弹至14元附近止盈；
3. 方向选择：当前市场主线从泛科技向有业绩支撑的细分赛道集中，铜箔链（AI需求+业绩暴增）、CRO（政策改善+需求复苏）确定性较强；地产脉冲式行情持续性存疑，不宜追高；
4. 关注方向：铜箔/PCB产业链（业绩验证最强）、CRO/创新药（政策催化）、半导体材料（国产替代长期逻辑）。

三、午后关注
• 关注成交量能否维持，若午后进一步缩量则调整时间可能延长；
• 关注创业板指3,350点支撑位得失；
• 关注铜箔板块午后能否继续走强，若持续则可能成为新的阶段性主线；
• 关注地产板块万科A能否回封，判断地产行情持续性。

📝 市场逻辑总结

核心逻辑：缩量震荡调整中聚焦业绩主线，铜箔链成为最强确定性方向

今日市场呈现三大特征：
1. 缩量调整、情绪偏弱：半日成交缩量近2,700亿至1.17万亿，超3,500只个股下跌，说明买盘力量不足，市场处于缩量整固阶段。但下跌幅度不大，说明抛压也有限，整体仍是震荡格局；
2. 业绩线走强，题材线退潮：铜箔链（上半年业绩暴增5-9倍）、CRO（需求复苏+业绩改善）等有业绩支撑的方向领涨，而传媒/影视/AI视频等纯题材概念大幅调整，说明市场定价逻辑正在从情绪驱动向业绩验证切换；
3. 地产脉冲，持续性存疑：万科A一度涨停带动地产板块冲高，但随后快速炸板，说明资金对地产行情的持续性仍有分歧，更多是超跌反弹性质而非趋势反转。

后市展望：华安证券认为四季度有望出现"吃饭行情"，AI算力硬件仍是首选。当前处于节前（中秋国庆临近）+业绩真空期后的震荡整固阶段，缩量调整空间有限。操作上建议控制仓位、择优布局，重点关注有业绩支撑的铜箔、CRO、半导体材料等方向，回避高位纯题材股。科技主线的中长期逻辑未变，调整后仍是布局机会。

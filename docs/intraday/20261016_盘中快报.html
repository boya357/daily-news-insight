🎯 午盘操作策略

【整体策略】市场缩量普涨情绪修复，军工+存储双主线领涨，把握科技反弹节奏+谨慎追高

一、大盘判断：连续调整后迎来普涨修复，量能不足制约上行空间
周五早盘三大指数集体高开高走，经历连续四日调整后迎来强修复，沪指涨0.95%、深成指涨1.19%、创业板指涨0.96%，全市场超4800只个股上涨，零跌停。但半日成交仅9626亿较昨日缩量192亿，显示增量资金入场意愿有限，反弹主要来自情绪修复而非资金面驱动。军工（珠海航展催化）和存储芯片（技术突破+业绩验证）成为两大最强主线，地产、创新药、低空经济助攻。预计午后指数维持震荡偏强格局，重点关注量能能否放大和军工/存储板块持续性。

二、操作策略：控制仓位，聚焦主线，不追高
1. 仓位控制：整体仓位维持5-6成，反弹初期不急于满仓，保留3-4成现金应对波动；
2. 持仓操作：
  • 英维克：底仓持有，今日跟随科技反弹，45元以上持有，反弹至50-52元减机动仓，跌破43元减仓；
  • 铜冠铜箔：底仓坚定持有，今日受PCB回调影响小幅下跌属正常调整，85元以下可加机动仓做T，反弹至95元以上止盈机动仓；
  • 雅克科技：底仓持有，存储芯片反弹带动情绪修复，站上100元可持有，反弹至110-115元减机动仓，跌破95元减仓；
  • *ST建艺：投机仓位持有，今日大涨3.31%接近前期高点，15元以上谨慎持有，15-16元分批止盈，止损位12.5元；
3. 方向选择：重点关注两大主线——①军工（珠海航展催化+中兵系改革预期，关注航天军工细分龙头）；②存储芯片（技术突破+业绩验证+AI需求确认，关注HBM/先进封装材料方向）；辅助方向——低空经济、创新药、地产链；
4. 节奏把握：不追高已连续涨停的军工股，关注有业绩支撑+位置相对低的标的；科技板块反弹初期可适量参与但控制仓位；PCB板块回调后若企稳可关注低吸机会。

三、午后关注
• 关注量能变化，若午后量能持续萎缩则反弹高度有限；
• 关注军工板块封板强度和持续性，是今日情绪核心；
• 关注存储芯片板块能否延续反弹，长鑫科技走势是风向标；
• 关注沪指3750-3800点压力区突破情况。

📝 市场逻辑总结

核心逻辑：连续调整后缩量普涨，军工+存储双主线领涨，情绪修复但量能不足

今日市场呈现三大核心特征：
1. 缩量普涨，情绪修复但量能不足：经历连续四日调整后，A股周五迎来普涨反弹，三大指数均涨近1%，全市场超4800只个股上涨、零跌停，短线情绪得到较大程度修复。但半日成交仅9626亿较昨日缩量192亿，显示增量资金入场意愿有限，反弹更多来自超跌后的情绪修复而非增量资金驱动。量能不足意味着反弹高度可能受限，需关注午后量能变化；
2. 军工爆发成最强主线，多重催化共振：军工板块今日集体爆发，十余股涨停（含20CM/30CM涨停），成为最强主线。催化逻辑包括：①珠海航展12月举办，新型装备亮相预期；②中兵系概念活跃，国企改革预期升温；③成飞概念走强；④前期调整充分估值低位。军工板块的爆发不仅是主题炒作，更反映了市场对国防装备升级和地缘政治的双重预期；
3. 存储芯片强反弹，技术+业绩+需求三重验证：昨日重挫的存储芯片今日迎来强修复，长鑫科技涨超6%重返3万亿市值第一，复旦微电20CM涨停。催化来自三重验证：①技术突破（长鑫4F² DRAM架构关键进展）；②业绩兑现（江波龙前三季净利预增1864%-1990%）；③需求确认（台积电Q3净利增69%，确认AI需求强劲）。这验证了存储芯片产业链的高景气度，是科技板块反弹的核心动力。

后市展望：市场连续调整后迎来普涨修复，短线情绪有所回暖，但量能不足制约上行空间，反弹持续性需观察。操作上建议控制仓位在5-6成，聚焦军工（珠海航展催化）和存储芯片（业绩+技术双驱动）两大主线，同时关注低空经济、创新药、地产链的辅助机会。科技板块的反弹能否延续是决定市场风格的关键，若存储芯片持续走强，有望带动整个半导体/AI板块回暖。下周重点关注三季报披露进度和宏观经济数据。

2026年7月13日 · 午盘速递 · 三大指数集体跳水沪指跌1.54%失守3950，超4500股下跌，氦气出口管制引爆工业气体板块，中药逆势走强

午盘焦点
7月13日（周一）A股走出「外围承压—集体低开—加速下探—普跌冰点」的弱势调整行情。受隔夜美股科技股杀估值、亚太市场全线走低影响，三大指数开盘即承压，随后加速下行无抵抗。截至午盘，上证指数跌1.54%报3934.74点，失守3950关键位；深证成指大跌2.61%报14654.49点；创业板指跌2.38%报3751.33点；科创50跌1.84%（相对抗跌）；北证50跌3.9%。半日成交1.85万亿，较上一交易日缩量约3200亿（缩量幅度约15%），全市场超4500只个股下跌，仅869只上涨，涨跌比约1:5，25只涨停、45只跌停，跌停数超过涨停，市场情绪降至冰点。核心杀跌力量：①存储芯片/光纤/MLCC高位科技股集体重挫（烽火通信、特发信息跌停，德明利跌停，香农芯创逼近20CM跌停，风华高科跌停）；②新能源/光伏/锂电继续探底；③商业航天、军工电子获利兑现（航天电子净流出10亿+居首）。逆势方向：①工业气体/氦气概念爆发（水发燃气一字板、九丰能源2连板、杭氧股份涨停，华特气体/金宏气体涨超10%）——商务部7/10公告氦气临时禁止出口；②中药板块逆势领涨（陇神戎发20CM涨停、天目药业涨停，生物谷/上海凯宝涨超10%）——「十五五」中医药规划+基药目录调整+新冠疫情抬头三重催化；③银行/石油/煤炭等权重避险（苏州银行涨超6%，工行建行中行涨超2%）。本质是「高位科技获利兑现+中报业绩雷释放+外围科技股回调共振」的集中调整，缩量下跌反映恐慌盘未大规模出逃但买盘观望，沪指3900-3930为强支撑区间。

一、市场判断
7月13日（周一）A股三大指数集体低开低走，沪指-1.54%失守3950点，深成指-2.61%，创业板指-2.38%，科创50-1.84%（相对抗跌）。半日成交1.85万亿缩量约3200亿，全市场超4500只个股下跌（涨跌比1:5），25只涨停/45只跌停，跌停数超过涨停，市场情绪降至冰点。
核心特征：高位科技获利兑现+中报业绩雷+外围回调三重共振，缩量普跌反映买盘观望而非大规模出逃。杀跌主力是前期涨幅较大的科技成长板块（存储、光纤、航天、MLCC），避险板块（中药、银行、油气）逆势走强。这不是系统性崩盘，而是「高低切换+获利洗盘」的典型调整——资金从高位成长流向低位价值避险。沪指3900-3930点是年线+前期箱体底部双重支撑，若能守住则调整空间有限；若有效跌破需警惕进一步下探。

· *ST建艺（平盘）：坚决清仓，绝不留恋！ST股无基本面支撑，风险极大；
2. 方向把握：①工业气体/氦气——今日最强主线（S级催化），水发燃气一字+九丰能源2连板，短期情绪高涨不追高，回调后关注有真实氦气业务的龙头；②中药/品牌OTC——政策+基本面双驱动，逆市走强验证防御属性，可持续关注品牌中药与独家基药品种；③银行/高股息——避险配置，大盘企稳后资金可能回流成长；④规避方向：高位纯题材科技股（光纤/航天/存储短期获利兑现）、新能源（产能过剩）、ST股；
3. 仓位建议：市场普跌情绪冰点，建议总仓位4-5成，以防御为主，等待企稳信号（放量反弹+站上3950）后再加仓。不抄底、不割肉优质筹码、不追高避险板块。
4. 午后关注点：①沪指能否守住3900点（年线关键支撑）；②跌停家数是否扩大（45→60+则情绪进一步恶化）；③半导体/算力板块是否有企稳迹象（市场风向标）；④成交量是否继续萎缩（缩量企稳信号）；⑤北向资金流向（外资态度）；⑥氦气概念是否冲高回落（情绪持续性）。

🎯 午盘操作策略

一、市场判断
今日A股呈现典型指数抗跌、个股普跌、风格剧烈切换格局。沪指回补3987点缺口后获支撑，深成指、创业板指受权重算力硬件拖累明显下挫，科创50冲高回落显示高位科技股筹码松动。半日成交2.5万亿放量，说明低位承接力量存在，但分歧巨大。

二、核心逻辑
1. 风格再平衡加速：半年末机构调仓+美联储鹰派+美股科技股调整，三重压力下资金从高位算力硬件（PCB/CPO/铜箔/液冷）流向低位医药、消费、核聚变等方向，属于健康轮动而非趋势反转。
2. AI大主线未破：申万宏源、中信建投等机构观点一致认为大波段行情没结束、科技领涨行情没结束，短期波动后中报季A股可能再出发，但需回避无业绩纯题材小票。
3. 医药政策利好催化：医保+商保双目录落地超预期，创新药板块迎来政策与估值双击机会，可作为阶段性配置方向。
4. 风险点：北向资金半日净流出44亿元，半年末流动性波动仍在，高位股回调压力未完全释放。

三、操作策略
1. 持仓应对：雅克科技逆势涨停是最强持仓，持有为主，开板可减仓1/3锁利；铜冠铜箔高位回调但浮盈仍厚，守好78.44元止损，反弹分批止盈；英维克恐慌杀跌不建议割肉，等反弹再看，若跌破76元需警惕；*ST建艺已破止损区域，建议逢反弹减仓规避风险。
2. 方向把握：①不追高纯题材算力小票，仅保留存储/先进封装/半导体材料等中报预增硬核龙头；②可适度配置创新药/CRO、白酒、煤炭等低位防御板块对冲波动；③关注可控核聚变、AI软件应用端等新分支机会。
3. 仓位建议：市场处于风格切换震荡期，建议总仓位控制在5成左右，留有现金应对波动，切忌追涨杀跌。
4. 午后关注点：沪指能否站稳4045点、创业板指回补缺口后能否企稳、雅克科技能否封住涨停、北向资金流向变化。

四、后市展望
短期市场正处于半年末风格剧烈切换阶段，算力硬件高位调整仍需时间消化，但AI产业大周期未变，中报业绩将成为下一轮行情的分水岭。建议不盲目割肉核心持仓，但要果断减仓走弱的非核心标的，利用震荡优化结构。

⚠️ 风险提示
算力硬件高位回调风险：PCB/CPO/液冷等前期涨幅巨大，调整可能尚未结束；半年末流动性波动：6月末机构调仓+北向资金流出，市场波动加大；美联储鹰派风险：美国5月PCE同比4.1%，加息预期升温，压制全球风险资产；业绩兑现风险：中报季临近，纯题材无业绩小票面临杀估值压力；风格切换踏空风险：若风格快速切回科技，过早重仓防御板块可能错失反弹

📝 市场逻辑总结

今日市场核心特征：冲高回落、极致分化、医药爆发、科技杀跌。沪指微涨守住4000点，深成指、创业板指跌超1%，科创50盘中创历史新高后大幅回落，超3500只个股下跌，半日成交2.5万亿放量。盘面上，创新药/CRO在医保商保双目录催化下全线爆发，可控核聚变接力活跃，白酒、猪肉、零售逆势走强；PCB、CPO、铜箔、液冷等前期强势算力硬件方向集体重挫，多股跌停，主力资金大幅流出。操作上，不恐慌、不追涨、守纪律。持仓中雅克科技逆势涨停最强，持有为主；铜冠铜箔守好止损、反弹止盈；英维克等反弹再处理；*ST建艺建议逢反弹减仓。方向上从纯题材小票向业绩硬核龙头集中，同时适度配置医药消费对冲。

🎯 午盘操作策略

一、市场判断
下半年首个交易日，A股走出"指数搭台、题材高低切、权重撑场子、成长股分化"的典型震荡攀升格局。沪指涨1.08%站稳4138点，但黄白线显著分化、中小盘强于高位权重，科创50/创业板指翻绿，是典型的存量资金内部腾挪而非全面增量入场。半日成交2.42万亿放量3151亿，4500+股上涨、近200股涨停，情绪并不差，但资金流向发生质变。

二、核心逻辑
1. 高低切换全面加速：公募半年业绩考核结束+基金风格漂移整改（消费/医药主题基金需回归合同赛道）+估值极值分化（高位科技PE80-600倍 vs 低位金融/周期/消费处于近5年20%分位以下），三重驱动下资金从高位算力硬件（CPO/PCB/液冷/逆变器）批量流向低位大金融、养殖、化工、中字头。
2. AI大主线未破，但内部高切低：资金没有离开AI，只是从纯题材小票、涨幅透支的中游硬件，切到订单落地、涨价兑现、估值合理的上游材料（电子特气/氟化工/铜箔）和半导体设备。雅克科技今日再涨近8%创新高、多氟多3连板、北方华创破7000亿，说明硬核科技龙头仍被抱团。
3. 券商/保险/养殖低位修复：属于阶段性轮动补涨而非新主线，持续性需观察量能和政策催化，券商持续性往往需要成交持续放大+政策催化共振。
4. 关键风险信号：央行单日净回笼11625亿元（逆回购到期12625亿vs投放1000亿），半年末宽松后流动性边际收敛；阳光电源半日主力净流出32亿、天孚通信-24亿，高位抱团瓦解迹象明显。

三、操作策略
1. 持仓应对（重中之重）：
· 英维克：今日80.49元再次精准验证80元减仓窗口（已连续2日验证），午后反弹至78-80元区间继续减仓≥1/2降风险，不恐慌在77元附近割肉，保留底仓观察；
· 铜冠铜箔：存储涨价+HVLP铜箔主升浪未破，底仓持有，170元上方可减1/3锁利，移动止盈上移至165元，不追高；
· 雅克科技：今日再涨近8%创历史新高245.83，彻底验证昨日"风险公告是监管模板非见顶"判断，底仓继续持有，不追高加仓、不杀跌卖出，回踩5日线215-220区间再决策，已减仓不追高买回；
· *ST建艺：今日盘中反弹是最后离场窗口之一，7月6日起ST涨跌幅扩至10%，风险加大，逢反弹果断离场。
2. 方向把握：①高位纯题材算力小票（CPO/PCB/逆变器/光模块散户抱团股）坚决回避，机构兑现仍在继续；②AI主线内部聚焦上游材料（电子特气/氟化工/铜箔/前驱体）和半导体设备等业绩兑现+涨价逻辑硬的龙头，但已大涨的不追高；③可适度配置大金融（券商/保险）、中字头基建、养殖等低位方向做对冲；④中报预增（益生股份+4287%为代表）将成为7月最强选股主线。
3. 仓位建议：市场处于风格剧烈切换期，建议总仓位控制在5成左右，留足现金应对波动，切忌追涨杀跌、不要追今日暴涨的金融/猪肉后排小票。
4. 午后关注点：①券商板块能否维持涨停潮（决定指数能否站稳4150）；②电子特气/氟化工主线分歧后能否回流（决定雅克科技能否继续创新高）；③高位算力硬件杀跌是否会引发尾盘踩踏；④北向资金全天流向。

四、后市展望
7月开门行情确认了"风格切换+AI内部高低切"两大主线，高位算力中游硬件兑现压力仍需时间消化，但AI上游材料（特气/铜箔/氟化液/前驱体）+半导体设备涨价兑现行情正进入主升浪，中报季业绩将是最重要的分水岭。纪律提醒：减仓≥30%的重大建议必须双重验证，不被单一信号（龙虎榜/风险公告/技术超买）带节奏。

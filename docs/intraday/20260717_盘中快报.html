🎯 午盘操作策略

📊 午盘研判：黑周五恐慌杀跌，现金为王不抄底

一、大盘判断：趋势性调整而非短期回调
今日放量大跌不是普通洗盘，是多重利空叠加的趋势性调整：外围科技股崩盘+IPO抽血+交割日+周末避险+获利盘兑现。沪指跌破3800点后短期难以快速收复，创业板指、科创50更是创出3个月新低。

二、操作总原则：防守反击，先保命后赚钱
1. 不抄底：下跌趋势中不猜底，底部是走出来的不是猜出来的；
2. 减高位：持仓中高位科技股（英维克）利用反弹减仓；
3. 保利润：铜冠铜箔逆势走强，分批止盈锁定利润；
4. 留现金：至少保留50%以上现金仓位，等待恐慌释放完毕后的低吸机会。

三、持仓股具体操作指引
• 英维克(002837)：跌破65元支撑，减仓至1/4仓位，跌破60元无条件清仓，绝不能让亏损继续扩大；
• 铜冠铜箔(301217)：逆势走强是减仓良机而非加仓理由，反弹至130元以上分批止盈，锁定利润优先；
• 雅克科技(002409)：相对抗跌，中长期逻辑不变，底仓持有不动，150元以下可少量加仓做T；
• *ST建艺(002789)：ST股受大盘影响较小，继续持有观察重组进展，跌破9.5元止损。

四、下午关注要点
1. 13:30-14:00：观察是否有抄底资金进场，量能是否萎缩；
2. 14:00-14:30：股指期货交割日结算价博弈期，注意空头打压；
3. 14:30-15:00：尾盘资金动向，决定下周一开盘情绪。

📝 市场逻辑总结

今日市场核心逻辑：全球科技股恐慌+流动性收紧，A股高位赛道集中杀跌

1. 外围导火索（直接原因）：韩国股市暴跌6.37%触发熔断，SK海力士跌15%、三星跌10%，全球半导体产业链恐慌情绪蔓延。叠加美联储官员鹰派表态，美股纳指跌1.47%、费城半导体指数暴跌4.29%。

2. 内部流动性收紧（根本原因）：长鑫科技科创板IPO冻结资金约1.7万亿，为年内最大规模IPO。机构为参与打新配售集中抛售高位科技股回笼资金，叠加半年报业绩披露期"利好落地即兑现"效应，形成多杀多踩踏。

3. 技术面破位（加速因素）：沪指失守3900点后加速下探，创业板指、科创50双双跌破关键支撑，量化止损单批量触发，放大跌幅。

4. 资金风格切换（中长期信号）：资金从半导体、AI硬件等高估值成长股大规模流出，涌入电力、银行等高股息防御板块。这不是简单的高低切换，而是市场主线逻辑的阶段性转向——从"炒预期"转向"看业绩"。

后市展望：短期恐慌情绪释放尚未结束，下周初仍有惯性下探压力。但中期来看，急跌之后必有反弹，关注3700-3750点区间支撑力度。操作上不盲目抄底，等待恐慌情绪企稳、量能萎缩后的右侧机会。

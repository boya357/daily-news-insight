✅ 本周核心总结

本周（6/30-7/3）A股完成了一轮完整的「科技冲高-风格切换-恐慌杀跌-缩量修复」剧本，4个交易日走势如过山车：
周一（6/30）半年收官日科技全线反攻，科创50+3.85%创新高，半导体、CPO齐飞；
周二（7/1）大金融/养殖/创新药爆发，高位科技初现疲态，沪指一度冲4138点周内高点；
周三（7/2）隔夜费半暴跌-6%+Meta出租算力引发"AI过剩"恐慌，科创50单日-7.70%创年内最大单日跌幅，半导体单日主力净流出454亿，两市普跌；
周四（7/3）美国6月非农仅5.7万人大幅不及预期，加息预期推迟至12月，黄金、机器人、军工、创新药等低位板块集体反攻，超3800股上涨，但AI半导体延续弱势。

核心特征：全周成交额持续维持3万亿以上（4日累计13.6万亿），资金完成了一轮极致的高低切——从上半年累计涨幅巨大的AI算力/半导体/CPO，流向机器人、黄金、军工、大金融、创新药等低位方向。上证周跌-1.24%守住4000点，深成指-3.75%，创业板-7.43%，科创50-10.52%高位大幅回吐，成长风格显著跑输价值。

🎯 下周核心判断：震荡消化期 + 中报预演，结构性机会为主

本周的高低切属于周度级别的风格再平衡，不是全面风格切换。4020点附近支撑已初步验证，但均线空头排列未打破，缩量反抽后仍有二次回踩需求。下周关键变量：①7/6 ST新规落地对垃圾股的冲击；②中报业绩预告进入密集披露期（7/10-7/20高峰），业绩验证将成为分化核心；③美股周一独立日休市后复盘，芯片股能否企稳；④Meta"算力出租"事件是否进一步发酵。


📈 机会方向（关注优先级）

  1. 人形机器人：本周最强主线，产业催化密集（宇树IPO、特斯拉Optimus、英伟达招聘），下周分歧后仍有二波机会，关注丝杠/减速器/电机核心零部件龙头

  2. 半导体设备/材料（错杀反弹）：急跌后存在技术性修复需求，大基金三期70%投向设备材料+十五五集成电路加码，关注有中报业绩支撑的国产设备龙头，但高位股只低吸不追高

  3. 黄金/有色：非农爆冷+加息预期降温+全球央行购金，黄金中期逻辑持续

  4. 创新药：防御+底部反转+减肥药催化，可作为组合对冲配置

  5. 军工/船舶：低位+业绩确定性+事件催化（建军节/海军建设）




⚠️ 回避方向

  • ST/*ST股：7/6起涨跌幅扩至10%，连环跌停风险，一律回避

  • 纯题材无业绩的高位AI概念股：中报披露期业绩证伪风险大

  • 外销占比过高的半导体标的：费半波动+AI资本开支担忧仍在消化

  • 前期涨幅过大的CPO/光模块高位股：机构兑现压力未释放完毕




🎚️ 仓位建议：5成以下防守仓位，等待方向明确。4只持仓必须在周一完成减仓/清仓动作（*ST建艺集合竞价清仓最优先、英维克73-75减仓、雅克科技200-205企稳观察、铜冠铜箔150止盈线严守），释放仓位后再根据盘面选择新方向。

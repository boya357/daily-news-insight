🔍 市场影响分析

一、美国6月CPI + 沃什证词：90分钟双重冲击，全球资产迎变盘点

7月14日是本周全球资本市场最关键的一天，甚至可能是7月最重要的变盘日。原因很简单：美国6月CPI数据公布后仅90分钟，美联储主席沃什就要在国会开启上任后的首次货币政策听证会。二者时间间隔极短，市场将经历"数据冲击→快速定价→政策表态→二次定价"的两轮波动，对A股、港股、黄金、美债都将产生连锁反应。

1. CPI数据预期与三种情景：

市场主流预期是6月名义CPI同比从5月的4.2%回落至3.8%-3.9%，环比甚至可能转负（-0.1%），主要得益于近期原油价格从高位回落。但这里存在一个巨大的认知陷阱——整体CPI回落只是能源价格下跌带来的短期红利，核心CPI（剔除食品能源）预计仍将维持在2.9%的高位，与前值持平。房租、医疗、餐饮、个人服务等"粘性通胀"并未出现明显降温，距离美联储2%的目标仍有近1个百分点的差距。

更值得警惕的是，FOMC内部目前在加息问题上是9:9的势均力敌局面——9位官员倾向年内加息，9位倾向按兵不动。这意味着单月CPI数据可能直接打破平衡，成为"决定性一票"。

乐观情景（概率30%）：CPI低于预期（同比＜3.7%且核心CPI＜2.8%）→ 美联储加息概率骤降 → 美债收益率下行 → 美元走弱 → 北向资金回流A股成长股（半导体、AI算力、光模块） → 黄金上涨。对持仓利好排序：雅克科技(半导体材料) > 英维克(液冷/算力) > 铜冠铜箔(锂电/PCB铜箔)。

中性情景（概率45%）：CPI符合预期（同比3.8%-3.9%）→ 市场维持当前定价 → 美元指数震荡 → A股延续结构性行情，内部主线轮动。重点关注国内经济数据与产业催化能否接力。

悲观情景（概率25%）：CPI超预期（同比＞4.0%或核心CPI＞3.0%）→ 加息预期升温 → 美债收益率上行 → 成长股估值承压 → 北向资金流出 → 黄金短线回调。风险标的：高位AI算力、半导体小票；防御方向：黄金、高股息、公用事业。

2. 沃什证词的"放大效应"：

CPI数据本身很重要，但更值得关注的是沃什在数据公布后的表态。沃什上任以来以"少说多做"著称，拒绝提供前瞻指引，但在国会听证会上他无法回避议员的直接质询。如果他强调"通胀仍然过高，需要保持警惕"，市场将解读为偏鹰；如果他承认"通胀在朝正确方向发展"，市场将解读为偏鸽。考虑到CPI数据与证词的时间间隔只有90分钟，沃什很可能会引用刚出炉的CPI数据来阐述他的政策立场，这将产生"数据+表态"的共振效应，放大市场波动。

操作建议：对于持有科技成长股的投资者，周二晚间是关键观测窗口。建议：① 不建议在CPI前大幅加仓或减仓，保持中性仓位观望；② 如果CPI低于预期且沃什偏鸽，可适当加仓半导体设备/材料方向（雅克科技逻辑强化）；③ 如果CPI超预期且沃什偏鹰，需警惕周三A股科技股开盘承压，可考虑高位股止盈部分仓位，待情绪企稳后再回补。

二、长鑫科技IPO倒计时：存储主线进入"事件密集催化期"

本周A股最大的产业事件，无疑是国产DRAM龙头长鑫科技的科创板IPO进程。7月13日已启动网下初步询价，7月15日将刊登发行公告并确定发行价，7月16日全网申购（申购代码787825）。拟募资295亿元，是2026年以来A股最大IPO，也是科创板历史上仅次于中芯国际的第二大IPO。

1. 为什么长鑫科技IPO如此重要？

长鑫科技是我国规模最大、技术最先进的DRAM一体化企业，已实现DDR4、DDR5、LPDDR4X、LPDDR5/5X全系列量产，核心技术达国际先进水平。上半年预计营收1100-1200亿元，同比增长超600%；归母净利润500-570亿元，同比增长超22倍。这个业绩增速和盈利水平，在整个半导体行业都是现象级的。

更具标志性意义的是，长鑫科技董事长承诺上市后十年内不减持，并将自持7.68亿股用于员工股权激励。这在A股IPO历史上极为罕见，传递出对公司长期价值的极强信心，也有利于稳定上市后的筹码结构。

2. 存储产业链投资机会梳理：

长鑫科技IPO不是单一事件，而是整个存储产业链的催化剂。从历史经验看，中芯国际上市带动了整个半导体设备/材料板块的估值重估，长鑫科技上市有望复制这一路径。受益方向包括：

• 上游材料：电子特气（华特气体、金宏气体）、光刻胶（南大光电、晶瑞电材）、湿电子化学品（江化微）——雅克科技(002409)直接受益，公司半导体化学材料业务（光刻胶、前驱体、电子特气）覆盖存储芯片制造核心环节，深度绑定国内存储大厂。

• 半导体设备：刻蚀机（中微公司）、薄膜沉积（北方华创）、检测设备（中科飞测、精测电子）、清洗设备（盛美上海）。

• 先进封装：长电科技、通富微电、华天科技——存储芯片对封装技术要求不断提高，HBM带动2.5D/3D封装需求。

• PCB/铜箔：存储芯片模组需要高端PCB和电解铜箔——铜冠铜箔(301217)的PCB铜箔业务间接受益于国内存储产能扩张。

3. 短期风险提示：

需要注意的是，长鑫科技IPO规模高达295亿，短期可能对市场资金产生分流效应，尤其是打新资金会从二级市场腾挪。此外，"利好出尽"效应也需要警惕——存储板块自4月以来已累计较大涨幅，部分资金可能借申购日前后的情绪高点兑现利润。建议不追高，关注回调后的低吸机会。

三、WAIC世界人工智能大会倒计时：AI算力板块进入"埋伏窗口"

7月17日，2026世界人工智能大会（WAIC）将在上海开幕，持续至20日。这是今年下半年AI行业的第一个顶级催化事件。展览面积首次突破10万平方米，1100余家企业参展，3000余项展品集中亮相，多个大模型、国产AI芯片、具身智能新品将实现全球首发。

1. 往年WAIC的行情规律：

复盘历年WAIC大会的A股AI板块走势，可以总结出"会前涨、会中震、会后分化"的规律：

• 会前1-2周：资金开始提前布局，板块整体上涨，主题投资活跃；

• 会前1-2天：情绪达到高点，部分资金开始提前兑现；

• 会议期间：利好密集释放但股价震荡，"利好兑现"效应明显；

• 会后：有基本面支撑的龙头继续走强，纯题材股回落。

按照这个规律，7月14日-15日正处于"会前埋伏→情绪高点"的过渡阶段，AI算力、液冷散热、光模块等方向可能出现脉冲式行情。

2. 今年WAIC的核心看点：

• 国产AI芯片新品：华为昇腾、寒武纪、海光信息等有望发布新一代算力芯片，性能对标海外最新产品；

• 具身智能/人形机器人：特斯拉Optimus、宇树科技、智元机器人等将亮相，机器人+AI是今年的大热方向；

• 液冷散热技术：AI算力密度指数级提升，液冷成为刚需——英维克(002837)是液冷散热龙头，直接受益于智算中心建设浪潮；

• 大模型应用落地：从"比参数"转向"比应用"，关注工业、医疗、教育等垂直领域的落地进展。

3. 操作策略：

• 当前位置（会前3天）：适合轻仓埋伏，重点关注液冷（英维克）、算力芯片、高速互连等方向；

• 会议期间：不建议追高，逢高可分批减仓兑现，尤其是纯题材、无业绩支撑的小票；

• 会后：关注业绩确定性强的龙头回调后的加仓机会，中期逻辑未变。

四、半年报预告进入冲刺期：业绩雷与业绩超预期并存

7月15日（周三）是沪深主板上市公司半年报业绩预告的强制披露截止日。按照交易所规定，主板上市公司预计半年报出现亏损、扭亏为盈、净利润同比变动50%以上的，应当在7月15日前披露业绩预告。

截至7月11日，已有371家公司披露了2026年半年度业绩预告，其中282家业绩预增，占比超七成。但需要注意的是，越接近截止日，"雷"可能越多——业绩好的公司倾向于提前披露，业绩差的往往拖到最后。

避雷要点：

1. 警惕高位题材股业绩不及预期：AI、机器人等热门赛道中，部分公司只有概念没有业绩，一旦中报不及预期，容易出现大幅回调；

2. 避开一次性收益推高的"伪增长"：变卖资产、政府补贴、投资收益等非经常性损益带来的增长不可持续；

3. 关注低基数陷阱：去年基数极低导致的同比高增长，不代表基本面实质性改善；

4. 优先选择扣非净利润持续高增长、毛利率稳定或提升、现金流健康的公司。

持仓业绩展望：

• 英维克(002837)：液冷散热需求爆发，AI数据中心订单饱满，中报大概率高增长，市场预期50%-80%；

• 雅克科技(002409)：半导体材料业务受益于国产替代加速，光刻胶、前驱体量价齐升，预计中报增长强劲；

• 铜冠铜箔(301217)：锂电铜箔价格底部企稳，PCB铜箔受益于AI服务器需求，中报有望环比改善；

• *ST建艺(002789)：ST股需密切关注摘帽进展和债务重组进度，中报业绩是重要观察窗口。

🔍 市场影响分析

【市场影响研判】 1. **苹果AI链关注**：WWDC大会是消费电子板块重要催化剂，重点关注AI手机端应用落地、端侧AI算力需求。若Siri升级超预期，有望带动消费电子、AI硬件板块情绪修复。 2. **进出口数据验证外需**：5月进出口数据是判断外需恢复的重要指标。若出口降幅收窄，将利好港口、航运、出口制造产业链；若不及预期，可能进一步强化稳增长政策预期。 3. **大额解禁承压**：阿特斯263亿元解禁为当日最大变量，叠加光伏板块近期调整，需警惕解禁带来的抛压。但公司储能业务增长较快（一季度储能销售2.6GWh，同比+200%），基本面有支撑。 4. **整体市场环境**：上周A股科技板块高位回调，创业板指失守4000点。本周处于"超级事件周"，内外数据密集发布，预计市场以震荡消化为主，建议控制仓位，回避高位纯题材炒作标的。

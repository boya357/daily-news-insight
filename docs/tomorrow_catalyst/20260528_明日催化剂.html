🔥 S级催化（IMPS≥15）
🚗 比亚迪智能化战略发布会
S级 5月28日 周四 影响：智能驾驶 / 汽车电子 / 比亚迪产业链
  • 发布会主题：比亚迪智能化战略全面升级，聚焦"全场景智能驾驶"
  • 核心看点：新一代高阶智驾系统、车机OS升级、智能座舱3.0、车载AI大模型
  • 产业链受益：德赛西威（智驾域控制器）、经纬恒润（智驾算法）、中科创达（OS）
  • 市场预期：比亚迪智驾方案落地将打破特斯拉垄断，重塑自主品牌智能化格局
  • 催化强度：作为新能源龙头，比亚迪智能化战略对整个汽车产业链具有风向标意义
🥇 A级催化（IMPS 8-15）
🤖 2026世界智能产业博览会 天津召开

  • 核心展品：中科曙光超十万卡超集群系统、信创海河实验室RISC-V整机产品
  • 机器人天团：伽利略四足机器人、云圣智能无人机、深之蓝深海机器人等
  • 成果发布：百项创新成果集中发布，覆盖智能制造、低空经济、智能终端等
  • 政策预期：天津市智能产业扶持政策可能同期发布，利好本地产业集群
💊 ASCO美国临床肿瘤学会年会 芝加哥开幕
A级 5月29日-6月2日 影响：创新药 / ADC / 生物医药 / CXO
  • 中国力量：94项中国研究入选口头报告，13项入选LBA，1项Plenary Session

  • 百利天恒：EGFR×HER3双抗ADC BL-B01D1两项关键III期研究进入核心环节

  • 行业影响：ASCO数据催化下，创新药板块有望迎来结构性行情，头部资产重估
📊 美国一季度GDP修正值 + 4月核心PCE
A级 5月28日 晚间 影响：全球市场 / 美联储政策 / 人民币汇率
  • GDP修正值：市场预期从初值下修，关注消费和投资分项变化
  • 核心PCE：美联储最看重的通胀指标，若超预期可能强化加息预期
  • 市场影响：数据将直接影响美股、美债收益率和美元指数走势
  • A股传导：通过北向资金和风险偏好传导，科技成长股敏感性更高
  • 对冲因素：美伊谈和导致油价下跌，可能缓解通胀压力
🏭 中国5月官方制造业PMI
A级 5月31日 周日 影响：周期板块 / 宏观经济 / 政策预期
  • 市场预期：5月PMI预计维持在50荣枯线以上，经济复苏态势延续
  • 结构看点：关注高端制造业、新动能产业PMI表现，以及出口订单变化
  • 政策联动：若PMI低于预期，可能引发市场对稳增长政策加码的预期
  • 板块影响：工业金属、化工、建材、机械等周期品种直接受益
  • 时间窗口：数据发布后恰逢6月开门红，可能影响月初市场情绪

  • 长期意义：提升市场成熟度，为期权等衍生品扩容奠定基础

🧪 住友电木环氧树脂涨价10-20%
A级 6月1日 周日 影响：封装材料 / 半导体材料 / 电子化学品
  • 涨价原因：AI芯片封装需求爆发，高端环氧树脂供应紧张
  • 国产替代：华海诚科、德邦科技等国内封装材料厂商迎来量价齐升机遇
  • 产业链传导：封装成本上升可能传导至下游芯片定价，关注毛利率变化
  • 行业趋势：先进封装（CoWoS、3D Stacking）带动材料升级换代

📉 本周超300亿元限售股解禁

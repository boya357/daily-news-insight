《求是》杂志发表习近平总书记重要文章，明确六大未来产业主攻方向

❤️ S级催化 2026-06-01 发布
📋 事件概述

6月1日出版的第11期《求是》杂志发表国家主席习近平的重要文章《前瞻布局和发展未来产业》。这是国家级顶层战略对未来产业发展的明确指引。

🔍 核心内容
  • 明确量子科技、生物制造、氢能/核聚变能、脑机接口、具身智能、6G六大未来产业主攻方向
  • 指出未来产业具有前瞻性、战略性、颠覆性等特点，需要科学谋划、全局统筹
  • 强调未来产业培育周期长、市场风险大，政策上要大力支持，政府要做好服务，完善财税等政策，加大对未来产业的投入
📈 市场影响
国家级顶层战略定调，为科技产业发展指明清晰路线图，六大未来产业将成为贯穿"十五五"的投资主线，相关产业链将迎来长期政策红利，市场风险偏好显著提升。
相关受益标的
中芯国际 寒武纪 科大讯飞 中国电信 中科创达

英伟达黄仁勋今日发表COMPUTEX主题演讲，AI产业链迎重磅催化

❤️ S级催化 2026-06-01 11:00
📋 事件概述

英伟达CEO黄仁勋将于6月1日上午11点在COMPUTEX 2026大会发表主题演讲，预计发布新一代AI算力架构和AIPC芯片，这是AI产业年度重磅盛会。

🔍 核心看点
  • 预计正式发布Vera Rubin平台（VR200机架），接棒Blackwell成为新一代AI算力核心
  • 英伟达与联发科合作研发的N1X Arm架构AIPC芯片或将正式亮相，采用台积电3纳米制程，集成Blackwell架构GPU，拥有180-200 TOPS本地推理算力
  • 预计展示液冷散热、GPU互联技术(CPO)等关键技术突破
  • 据摩根士丹利测算，VR200机架内存成本占比从GB300的9%跃升至26%，PCB、MLCC等组件物料成本分别上涨233%和182%
📈 市场影响
AI产业年度重磅盛会，巨头技术突破将推动产业链向纵深发展，液冷散热、先进封装、高速互联、AIPC等细分领域将迎来爆发式增长，算力产业链量价齐升格局进一步强化。

工业富联 中际旭创 英维克 沪电股份 胜宏科技 铜冠铜箔 生益科技

《关于进一步深化国资国企改革的方案(2026—2029年)》正式下发

💜 A级催化 2026-05-31 发布
📋 事件概述

新一轮国资国企改革方案已正式下发，山东、河南、湖北等多省份及中国电气装备集团等央企已启动部署，标志着国企改革进入新阶段。

🔍 核心内容
  • 要求提升国企上市公司质量，强化分红回报，推动改革高质量开局
  • 战略性重组与新兴产业布局将成为两大主线
  • 多省份和央企已召开专题会议，研究部署本省/本集团深化改革工作
📈 市场影响
国企改革进入新阶段，具备改革预期、资产整合空间的央企及地方国企有望迎来估值修复，国企分红比例提升将增强A股核心资产的长期投资价值。

沪深交易所核心指数大规模重构，A股全面转向科技硬赛道

💜 A级催化 2026-06-15 生效
📋 事件概述

6月中旬，沪深交易所同步落地年度最大规模指数样本股调整，涵盖沪深300、上证50、科创50、深证成指、创业板指等所有主流核心指数。

🔍 核心调整
  • 创业板指调入香农芯创、国科微、铜冠铜箔等10只个股，调出传统消费、医药老旧标的
  • 科创50指数调入华虹公司、源杰科技、摩尔线程、沐曦股份4只半导体龙头
  • 沪深300新增19只硬科技标的，进一步优化核心指数成长属性
  • 指数调整直接牵动千亿级被动跟踪资金调仓布局
📈 市场影响
政策明确定调A股未来核心主线牢牢绑定硬科技与新质生产力，市场长期估值体系正在重构，科技成长赛道将获得持续资金托底。

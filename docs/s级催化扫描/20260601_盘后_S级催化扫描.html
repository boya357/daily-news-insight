英伟达COMPUTEX 2026黄仁勋炸场演讲：发布RTX Spark超级芯片，正式进军PC市场

❤️ S级催化 2026-06-01 台北
📋 事件概述

6月1日，英伟达CEO黄仁勋在台北国际电脑展(COMPUTEX 2026)发表主题演讲，发布多款重磅产品，正式宣告"智能体时代"已经到来。演讲定调："Agentic AI has arrived. That useful AI has arrived."（智能体AI已经到来，有用的AI已经到来）。

🎯 核心发布清单

1. RTX Spark超级芯片 - 面向Windows PC的AI处理器

• 搭载Blackwell RTX GPU，FP4 AI性能达到1 petaflop

• CPU部分：与联发科合作定制的20核Grace CPU

• 内存：128 GB统一内存，NVLink C2C提供600 GB/s带宽

• 产品形态：14mm厚度、3磅重量的笔记本，覆盖14-16英寸

• 合作伙伴：联想、戴尔、惠普、微软等秋季首发

2. Vera CPU - 专为智能体时代打造的中央处理器

• 代理型任务完成速度比x86 CPU快80%(1.8倍)

• 驱动AI工厂背后的CPU密集型工作：智能体AI、强化学习、数据处理、任务编排

• 首批客户：OpenAI、Anthropic、SpaceX

• 目标市场：开拓价值2000亿美元的新市场

3. Vera Rubin AI超级芯片平台

• 已进入全面投产阶段，秋季开始发货

• 英伟达迄今规模最大的POD级平台之一

• 专为Agentic AI设计的新一代AI工厂核心系统

4. Cosmos 3物理AI世界模型

• 全球首个完全开源的全能模型(Omni-Model)

• 原生理解和生成文本、图像、视频、环境声音和动作

5. Isaac GR00T人形机器人参考设计

• 与宇树科技、Sharpa合作推出

• 首款基于Jetson Thor和Isaac GR00T开放开发平台构建的开放式人形机器人参考设计

💡 市场影响分析

PC产业革命：英伟达正式进军PC处理器市场，直接挑战英特尔和AMD垄断地位，PC产业链迎来历史性变局。Windows PC将从应用入口转向个人AI平台。

Agentic AI元年确立：黄仁勋明确智能体架构五大核心组件：模型(model)、线束(harness)、工具(tools)、技能(skills)、运行时(runtime)。智能体成为新的应用形态，计算底座重新设计。

Token经济学验证：Token成为盈利单位，AI工厂成为GDP生成器。1吉瓦AI工厂起步价200-300亿美元，全球科技巨头正在疯狂建设AI基础设施。

台湾半导体供应链狂欢：英伟达计划每年在台投资约1500亿美元，建设台湾总部预计2030年投入使用。

📌 关键金句

"有人说AI会让程序员失业。纯属无稽之谈。工程师数量在增加。因为每个工程师能创造三倍产出，企业当然想招更多。"

"芯片便宜不代表你赚了，芯片贵不代表你亏了。选错架构的代价，从未如此高昂。"

"30年来我们所学的一切精华，都凝聚在这一块芯片中。"(指RTX Spark)

人民日报、《求是》双发文定调未来产业，六大核心赛道明确

❤️ S级催化 2026-06-01 发布
📋 事件概述

6月1日，两大央媒同步释放重磅信号，明确未来产业发展方向。人民日报发文《加快前瞻布局和发展未来产业》，《求是》杂志同时强调新质生产力引领高质量发展，共同明确六大核心赛道。

🎯 六大未来产业核心赛道

1. 量子科技 - 量子计算、量子通信、量子精密测量

2. 生物制造 - 合成生物学、生物基材料、生物制药

3. 氢能与核聚变能 - 绿氢制备、核聚变商业化、储能技术

4. 脑机接口 - 神经科学、脑机交互、神经假体

5. 具身智能 - 人形机器人、通用机器人、智能体AI

6. 第六代移动通信(6G) - 太赫兹通信、卫星互联网、通感一体

💡 市场影响分析

政策底彻底夯实：两大权威媒体同日发声，标志着未来产业已上升至国家战略层面，政策支持力度将持续加码。

人形机器人赛道确认：具身智能首次被纳入未来产业六大核心赛道，宇树科技IPO过会成为重要印证，机器人产业链迎来政策与资本双重催化。

科技成长主线延续：虽然今日科技板块出现调整，但长期发展逻辑未变，六大未来产业将成为"十五五"期间科技创新的核心方向。

四家上市公司同日进入退市整理期，退市常态化趋势加速

💜 A级催化 2026-06-01 正式实施
📋 事件概述

根据上交所审核结果及公司公告披露，*ST国化(600636)、*ST华嵘(600421)、*ST熊猫(600599)、*ST岩石(600696)四家上市公司股票于6月1日起正式进入15个交易日的退市整理期。其中退市华嵘开盘暴跌超90%。

🔍 四家退市公司概况

退市华嵘(600421)：原武汉国药，2025年扣非净利润亏损，营收低于3亿元。曾试图通过"AI政务智能体"项目保壳被监管问询后全额调减收入。

退市熊猫(600599)："烟花第一股"，曾转型互联网金融。2023年彻底退出类金融业务回归烟花主业，但公司治理失控风险累积。

退市国化：以文化教育为主业。2026年1月预告营收3.32-3.57亿释放摘帽信号，最终实际仅2.96亿，叠加内控否定意见触发退市。

退市岩石："白酒退市第一股"。2025年净利润为负且营收低于3亿元，财务报告被出具保留意见，内控被出具否定意见。

⚠️ 风险警示

退市常态化加速：A股资本市场持续深化退市制度改革，压缩壳资源炒作空间，坚决出清劣质上市公司。投资者需坚决规避ST板块、问题股及信披违规公司。

持仓提示：*ST建艺虽今日相对抗跌，但需持续关注摘帽进展，严格执行止损纪律（12.5元止损位）。

来源：红星资本局、东方财富网

智微智能拟定增募资28.7亿元，加码智算中心建设

💜 A级催化 2026-06-01 盘后公告
📋 事件概述

智微智能(001339)6月1日公告，公司拟向特定对象发行股票募资不超过28.7亿元，扣除发行费用后用于智算中心建设及运营项目、补充流动资金及偿还银行贷款。

这是继多家AI企业之后，又一家上市公司大手笔加码算力基础设施。AI算力需求持续爆发，算力产业链（服务器、液冷、光模块、IDC）仍处于高景气周期。虽然今日科技板块出现调整，但产业发展逻辑未变，调整后优质标的仍具投资价值。

智翔金泰双抗产品GR1803授权药友制药，合作金额最高超18亿元

💜 A级催化 2026-06-01 公告
📋 事件概述

智翔金泰公告，公司与上海复星医药控股公司药友制药就GR1803项目签署许可协议。GR1803注射液是一种双特异性抗体，可同时结合BCMA和CD3抗原，从而将细胞毒性T细胞定向至表达BCMA的细胞。根据协议，首付款及里程碑款总金额至高18.2亿元。

💡 市场影响分析

大额合作落地验证管线价值，兑现创新研发收益，助力公司现金流改善。创新药产业链在医保谈判新规（预申报机制缩短准入周期）支持下，有望迎来估值修复。

• 深证成指：报15340.36点，下跌1.51%

• 创业板指：下跌2.15%

• 科创100：报1829.99点，下跌3.34%

🔥 板块轮动特征

领涨板块：煤炭(+5.53%)、传媒、美容护理、AI应用端

领跌板块：CPO概念、半导体、存储芯片、PCB

📌 市场风格解读

今日市场呈现典型的"高低切换"特征：前期涨幅巨大的科技赛道（CPO、半导体、存储）集体回调，而低位价值板块（煤炭、电力）逆势走强。这并非行情反转信号，而是机构半年调仓+指数样本股调整导致的正常轮动。

北向资金延续净流入态势，说明外资仍看好A股中长期价值。缩量调整意味着场内资金分歧加大，而非恐慌出逃。

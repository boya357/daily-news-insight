6G产业链深度研究报告

通感一体·空天地海·太赫兹通信 — 下一代通信革命的投资全景图

🕒 发布时间：2026年6月6日 12:34

🎯 核心观点

2026年是6G从技术储备转向产业爆发的关键元年。政策层面写入政府工作报告，标准制定进入攻坚期，12城试验网落地，龙头企业订单已开始兑现。叠加光通信材料涨价、卫星互联网组网加速、AI+通信融合三大催化，6G概念股正迎来业绩+估值双升的黄金窗口。

📡一、行业发展现状与政策环境

6G即第六代移动通信技术，其核心目标是从"万物互联"迈向"万物智联"，实现通信、感知、计算、AI与安全的深度融合。当前全球6G正处于技术标准与产业构建的关键阶段。

1.1 政策东风：国家战略背书，资金持续加码

2026年，6G被正式写入政府工作报告及"十五五"规划纲要，标志着这一技术从前瞻概念正式迈入国家战略核心赛道。6月4日，工信部印发《关于组织开展6G创新发展部省协同试点专项行动的通知》，明确到2029年形成一批自主创新的6G技术方案。

  • 顶层设计定型：从"十四五"技术储备到"十五五"产业培育，形成"中央+地方"协同政策体系
  • 资金投入明确：三大运营商2026年6G试验网投入超200亿元，重点用于基站建设、星地融合
  • 频谱资源先行：我国率先划分6425-7125MHz频段用于6G，解决核心资源瓶颈

1.2 技术突破：核心专利+工程化落地双领先

我国6G核心专利占比超40%，中国移动主导3GPP、ITU等国际标准制定。关键技术量产取得突破：太赫兹通信、空天地一体化、通感一体等核心技术完成300余项验证；1.6T光模块、空芯光纤、毫米波天线已实现量产突破。

1.3 商用时间表清晰

2026年试验网验证 → 2028-2029年预商用 → 2030年正式商用 → 2035年全球用户达35亿

🔬二、核心技术架构：三大技术支柱

6G不是简单的网速升级，而是全域通信基建的重构。三大核心技术方向构成6G的技术底座：通感一体化、空天地海一体化、太赫兹通信。

2.1 通感一体化（ISAC）：给网络装上"眼睛"

通感一体化是6G最具革命性的技术方向之一，被ITU列为6G三大核心场景之首。其核心思想是让通信基站同时具备感知能力，通过分析无线电波的反射，实现对周围环境的"视觉"感知。

技术原理：基站发射的无线信号碰到周围物体后反射，基站通过分析反射波的时间、角度和频率变化，就能像蝙蝠一样"看到"周围环境——探测物体位置、速度、方向，甚至识别物体类型。

核心优势：不占用额外频谱资源、不受天气光照影响、覆盖范围广、成本远低于传统雷达+摄像头方案。

典型应用：低空经济无人机管控、智慧交通车流量监测、工业智造安全监控、智慧安防人员定位、智能驾驶环境感知。

2.2 空天地海一体化：全域覆盖的立体网络

6G的第二大核心愿景是实现从平面覆盖到"全域覆盖"的空间拓展，构建空、天、地、海一体化的立体网络架构。

四层网络架构：

  • 天基层：高轨(GEO)+中轨(MEO)+低轨(LEO)卫星星座，全球覆盖、应急备份
  • 空基层：高空平台站(HAPS)、无人机、系留气球，灵活部署、热点增强
  • 地基层：宏蜂窝+微蜂窝+皮蜂窝+飞蜂窝，大容量、高速率、低时延
  • 海基层：水下声学节点、海面浮标、船舶基站、海底光缆，海洋覆盖

2.3 太赫兹通信：超高速传输的终极方案

太赫兹波(0.1~10THz)被普遍认为是6G通信的核心承载频段之一，也是6G实现Tbps级峰值速率的关键技术路径。

技术进展：

  • 2026年2月，北大光无线融合通信系统单通道达400Gbps，刷新世界纪录
  • 2026年5月，日本德岛大学在560GHz频段实现112Gbps无线传输
  • 华为天罡T1太赫兹终端：0.1THz频段，100米距离20Gbps稳定传输
  • 中兴通讯光子太赫兹全息通信：单波长10-200Gbps超高速传输

🏭三、产业链全景：五大细分赛道全解析

6G产业链覆盖上游核心芯片、中游设备制造、下游应用场景，以及卫星互联网、太赫兹等特色赛道。整条产业链预计将带动超万亿级别的投资机会。

3.1 上游：核心芯片——国产替代的核心壁垒

芯片是6G产业链最上游、技术壁垒最高的环节，也是国产替代的重中之重。

光芯片：源杰科技（激光器光芯片龙头）、长光华芯（半导体激光芯片）、光库科技（铌酸锂调制器）

射频芯片：卓胜微（射频前端龙头）、国博电子（相控阵T/R芯片）、唯捷创芯（手机射频PA）、雷电微力（毫米波相控阵）

高频PCB/覆铜板：深南电路（通信PCB龙头）、沪电股份（基站电路板）、生益科技（覆铜板龙头）

3.2 中游：光通信传输——6G带宽扩容最先受益

光通信是6G建设的"卖铲人"，也是短期业绩最先兑现的环节。6G网络对光纤、光模块、光器件需求是5G的3倍以上。

高速光模块：中际旭创（全球龙头，1.6T市占55-60%）、新易盛（海外云厂商核心供货商）、光迅科技（光芯片+光模块一体化）、天孚通信（光器件封装龙头）

光纤光缆：亨通光电（海缆全球市占15%）、长飞光纤（光纤光缆龙头）、烽火通信（光通信全产业链）

3.3 中游：主设备商——网络建设的核心载体

中兴通讯：6G标准必要专利全球前三，太赫兹专利全球第二，国内试验网设备供货占比超60%。大唐移动：TD-SCDMA技术传承，5G/6G技术积累深厚。信科移动：IMT-2030推进组核心成员，星地融合专利超1500项。

3.4 特色赛道：卫星互联网——空天地一体化核心枢纽

6G实现"全域覆盖"必须依赖卫星网络。我国低轨卫星组网加速，卫星直连手机市场2027年将达300亿元。

运营环节：中国卫通（国内唯一商用卫星运营商）、中国星网（低轨卫星互联网主体）

制造环节：中国卫星（卫星制造龙头）、铖昌科技（太赫兹射频组件）、盛路通信（太赫兹天线）

3.5 特色赛道：太赫兹与射频前端

信科移动（全球首款太赫兹6G测试仪）、创远信科（太赫兹测试仪器）、硕贝德（毫米波天线）、盛路通信（太赫兹天线）、天银机电（太赫兹射频SIP芯片）

🥧 6G产业链结构预测

🏆四、核心标的深度分析

从技术壁垒、业绩弹性、确定性三个维度，筛选6G产业链最具投资价值的核心标的。

4.1 中军龙头：中兴通讯（000063）

核心逻辑：6G主设备龙头，专利与标准话语权最强，全面受益产业爆发。

核心优势：6G标准必要专利全球前三，累计1.32万+件专利，太赫兹专利全球第二（2800+件）；深度参与ITU/3GPP国际标准制定；国内试验网设备供货占比超60%；GigaMIMO超大阵列技术容量较5G-A提升10倍。

业绩测算：短期(2026-2027)试验兑现期，6G相关营收约89亿；中期(2028-2029)预商用爬坡，2029年6G营收占比突破20%；长期(2030+)全面商用，复刻5G超级周期。

4.2 光模块龙头：中际旭创（300308）

核心逻辑：全球高速光模块龙头，AI算力+6G双轮驱动。

核心优势：800G光模块全球市占35%+，1.6T市占55-60%，绝对龙头地位；3.2T光模块2026年底送样验证；深度参与6G光传输标准制定；北美云厂商核心供应商。

4.3 卫星运营龙头：中国卫通（601698）

核心逻辑：高轨通信垄断平台，牌照+频轨壁垒稳固，6G空天地一体化核心受益者。

核心优势：国内唯一商用通信卫星运营牌照，亚洲第二、世界第六大固定通信卫星运营商；在轨20颗卫星，33个全球地面站；申报24颗MEO中轨卫星，从单一高轨向"高轨+中轨"协同组网转型。

4.4 太赫兹龙头：信科移动（688387）

核心逻辑：IMT-2030推进组核心成员，太赫兹测试与星地融合技术领先。

核心优势：星地融合专利超1500项；全球首款太赫兹频段6G测试仪量产；2026年有望斩获20亿低空通信订单；大唐电信集团旗下，央企背景。

4.5 光通信全产业链：烽火通信（600498）

核心逻辑：全球唯一光通信全产业链企业，深度参与6G试验网建设。

核心优势：光纤光缆+光设备+光器件全产业链布局；1.6T光模块完成测试；三大运营商核心供货商，订单确定性强；海缆业务快速增长。

⏱️五、投资节奏与催化剂

6G产业发展分为三个明确的阶段，每个阶段有不同的投资主线和催化剂。

5.1 三阶段投资时钟

第一阶段：试验兑现期（2026-2027）
核心特征：政策频出、技术验证、试验网建设
投资主线：主题投资为主，关注弹性大的小票和概念股
重点标的：信科移动、盛路通信、硕贝德、创远信科
催化剂：工信部试点政策、试验网招标、技术突破新闻

第二阶段：预商用爬坡期（2028-2029）
核心特征：标准冻结、运营商集采、业绩开始兑现
投资主线：业绩驱动，关注有实际订单的龙头企业
重点标的：中兴通讯、中际旭创、光迅科技、烽火通信
催化剂：3GPP标准冻结、运营商6G集采、供应链业绩爆发

第三阶段：全面商用期（2030+）
核心特征：大规模建网、应用爆发、产业链成熟
投资主线：价值投资，关注龙头份额和应用创新
重点标的：中兴通讯、中际旭创、中国卫通、运营商
催化剂：全国性商用部署、新应用场景爆发、海外市场拓展

⚠️ 风险提示

⚠️技术研发不及预期：6G多项核心技术仍处于实验室阶段，太赫兹、空天地融合等技术的工程化落地难度大
⚠️商用化节奏不确定：6G标准制定、频谱规划、网络建设是复杂系统工程，商用节奏可能整体后移
⚠️行业竞争加剧：全球各国都在加快6G布局，国际竞争激烈，国内企业可能面临技术路线选择、专利纠纷等风险
⚠️估值回调风险：部分6G概念股短期涨幅较大，估值可能偏高，若业绩兑现不及预期存在回调风险

核心观点：6G正处于从0到1的关键窗口期，2026年是产业爆发元年。

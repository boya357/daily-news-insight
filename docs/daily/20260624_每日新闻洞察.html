政策

三部门发布稳外资15条新政，支持外资企业A股上市

商务部、发改委、财政部联合印发《利用外资固稳促优行动方案》，15条举措落地。金融业持续放宽准入，允许外资参与国债期货、基金投顾业务；生物医药扩大开放，放开外商独资医院试点；支持外资参与硬科技、新基建项目，符合条件可直接A股上市融资。

政策

央行单日净投放750亿，半年末资金面无虞

6月23日央行开展5245亿元7天逆回购操作，单日净投放750亿元，同时收紧短端利率波动区间。每年6月底银行半年度考核往年资金利率容易飙升，今年央行提前持续放水，市场不存在系统性缺钱风险。

政策

《金融法（草案）》首次提请审议，金融监管顶层立法突破

《中华人民共和国金融法（草案）》提请十四届全国人大常委会第二十三次会议首次审议，是我国金融领域管总的基础性法律，涵盖金融监管体制、金融机构治理、金融消费者保护等方面。

国际

孙正义反驳马斯克：太空数据中心"没意义"，AI竞赛在地球决胜

孙正义在软银股东大会上直言，太空数据中心构想"意义不大"，认为发射费用、在轨维护及通信延迟等挑战远超其能源优势，AI胜负仍取决于地球算力。同时两位顶级宏观投资人警告AI泡沫，美股最快Q3见顶跌幅30-50%。

📝 每日总结与操作策略

【市场研判】 昨日A股遭遇"黑色星期二"，创业板指大跌3.84%，上证指数失守4100点关口，两市成交3.47万亿缩量回调。 外围市场暴跌是主要导火索：韩国股市暴跌近10%触发熔断，美股科技股集体重挫，费城半导体指数大跌近8%，美光科技暴跌超13%。 市场担忧存储芯片涨价周期见顶、AI泡沫风险、美联储鹰派政策三重压力叠加，全球风险资产全面承压。 但需注意的是，A股昨日涨跌个股几乎各半（2763涨 vs 2642跌），说明指数下跌主要由权重板块拖累，而非全面普跌。 医药生物、银行等防御性板块逆势上涨，显示资金有高低切换迹象。 操作上建议保持谨慎，控制仓位在5成以下，等待情绪充分释放后再考虑布局。

【核心主线】 1. 存储芯片：短期受海外龙头大跌冲击，情绪承压；但AI驱动的供需缺口长期逻辑未变，国产替代空间广阔，回调后仍是重点布局方向，关注国内有真实产能和订单的龙头标的； 2. AI算力硬件：高位调整压力显现，但光模块、液冷等细分赛道订单饱满、业绩确定性高，PCB降价传闻已被辟谣，实际是加价急单供不应求，逢低可关注业绩确定性强的龙头； 3. 人形机器人：商业化进程加速，三季度催化剂密集（特斯拉Optimus V3量产、世界机器人大会），事件驱动机会明确，可逢低布局核心零部件标的； 4. 创新药/CXO：政策利好（稳外资扩大医疗开放）叠加估值底部，板块配置价值凸显，可适度配置作为防御性品种。

【操作策略】 当前全球市场处于高波动期，A股也面临外部情绪冲击与内部调仓压力，操作上不宜盲目抄底，建议： 1. 仓位控制在5成以下，保持现金灵活性，应对市场波动； 2. 高位科技股（纯题材炒作、无业绩支撑）逢高减仓，规避回调风险； 3. 适度配置防御性板块（医药、银行、公用事业）对冲市场波动； 4. 关注半年报业绩超预期的优质标的，业绩确定性是当前市场核心锚点； 5. 严格执行止损纪律，个股跌破关键支撑位及时减仓控制风险。 等待情绪充分释放、市场企稳后，可重点布局有真实业绩支撑的硬核科技赛道。

【持仓策略】 铜冠铜箔：存储封装铜箔龙头，受益于AI算力与存储芯片需求爆发，长期逻辑不变，但短期受板块情绪影响可能回调，逢高可适当减仓锁定部分利润，保留底仓观察； 雅克科技：存储/HBM核心材料标的，基本面扎实，长期受益于存储芯片扩产，可继续持有，回调可逢低加仓； 英维克：液冷散热龙头，AI算力基础设施核心受益标的，短期破位后关注反弹力度，若无法有效收复关键均线考虑减仓； *ST建艺：摘帽预期标的，事件驱动型，控制仓位在5%以内，关注后续进展。

💰 美光FY26净利850亿美元创历史新高 Q4单季377亿同比+1078%
美光科技公布2026财年全年业绩，净利润849.69亿美元创半导体行业历史纪录：
核心财务：
  • 全年营收1331.88亿美元，同比+256%
  • 全年净利润849.69亿美元，去年同期85.39亿
  • 毛利率81%，去年同期40%，前年22%
  • 每股收益74.33美元，去年同期7.59美元
  • Q4单季营收542亿同比+380%，净利377亿同比+1078%
分产品：
  • DRAM营收1006.8亿美元，占比76%
  • NAND营收317.9亿美元，占比24%
  • 云/HBM业务430.85亿，数据中心375.92亿
关键进展：1γ DRAM节点为业界首个EUV DRAM节点，Q4已成为出货量最大节点；HBM需求持续供不应求。

来源：美光科技10-K年报、证券之星、21世纪经济报道
🔒 美光回购计划扩至350亿美元 年内股价涨260%

🚀 长鑫4F²架构重大突破 年底推新一代DDR5 RDIMM
第四届集成芯片和芯粒大会上，长鑫科技总裁曹堪宇宣布DRAM下一代核心架构4F²取得重大突破：
技术突破：
  • 从主流6F²架构升级到4F²，单位面积存储密度提升30%-50%
  • 自研VSG垂直包围栅晶体管，解决漏电与短沟道效应
  • 同步完成字线金属化、位线成型、结激活等核心工艺
  • 预计2026年底推出融合4F²架构+混合键合的新一代DDR5 RDIMM
战略意义：首款落地产品选服务器内存DDR5 RDIMM，直面最高难度市场。目前全球服务器DRAM被三星/SK海力士/美光三家垄断，长鑫用下一代架构弯道超车意图明显。
挑战：4F²架构无法沿用原有产线，改造投入巨大；服务器内存认证周期长（2-3年）。

来源：证券日报、企业上市公众号
📈 华强北内存条一年涨超300% AI需求虹吸产能
深圳华强北内存价格持续暴涨，AI算力需求对上游产能虹吸效应明显：
  • DDR4 16G：去年最低100多元 → 现在最低600多元，涨幅超300%
  • DDR5 16G：最便宜200多元 → 现在最低1400元以上
  • 金士顿DDR3：去年9月218元 → 目前499元，涨幅129%
  • 金百达DDR5：5月底价2399元 → 最新3499元，涨幅45.9%
根本原因：AI服务器内存需求量是普通服务器的8-10倍，全球约70%先进存储产能被AI吞噬，三巨头持续将产能转向利润更高的HBM，消费级DRAM供给被严重挤压。
趋势判断：供应链消息称成熟制程DRAM四季度仍将"稳步涨价"，HBM4价格2027年预计涨近3倍。

来源：36氪、深圳广电、界面新闻

📋 中共中央国务院重磅发布《关于发展新质生产力的意见》
中共中央、国务院印发《关于发展新质生产力的意见》，部署19项重点举措：
五大方面：
  • 大力推进科技创新
  • 推动科技创新和产业创新深度融合
  • 着力推进发展方式创新
  • 扎实推进体制机制创新
  • 深化人才工作机制创新
核心原则：坚持创新主导、改革为要、因地制宜、先立后破，坚持高技术、高效能、高质量。以科技创新为引领，以全要素生产率大幅提升为核心标志，推动技术革命性突破、生产要素创新性配置、产业深度转型升级。
投资启示：新质生产力相关赛道（AI、半导体、高端制造、新能源、生物医药等）有望持续获得政策支持，科技成长主线逻辑进一步强化。

来源：证券时报、新华社

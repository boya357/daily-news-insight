🛢️ 油价暴涨布油突破117美元 创五个多月新高 通胀担忧重燃
中东地缘风险持续叠加供应担忧，国际油价周五大幅飙升：
油价数据：
  • WTI 12月原油期货收涨 3.82% 报103.27美元/桶，全周累涨4.29%
  • 布伦特12月原油期货收涨 3.14% 报116.72美元/桶，全周累涨6.24%
  • 布油盘中一度冲向117美元，创五个多月新高，单周涨幅创六周最佳
  • 石油巨头股价集体刷新历史新高：埃克森美孚+1.39%、雪佛龙+1.46%、壳牌+1.63%
通胀担忧升温：
  • 美国10月综合PMI初值57.6，企业售价涨幅创四年高位（2022年8月以来最高）
  • 10年期美债收益率回升至4.99%，日内升约4个基点，脱离近一个月低位
  • 制造业PMI升至56.0创53个月新高，油价、原材料及运输成本上涨加剧通胀压力
  • 美联储10月27-28日议息会议在即，市场定价维持利率不变，但降息预期延后
对A股影响：油价上涨推升通胀预期，可能压制全球科技股估值，但利好能源板块。A股能源链（石油、煤炭、油服）有望受益。

来源：财联社、华尔街见闻、Trading Economics

☁️ AWS容量2027年底前基本售罄 AI基础设施需求远超预期
亚马逊CEO安迪·贾西周五释放重磅信号，云计算需求持续爆发：
核心信息：
  • AWS的云计算容量在2027年底前已基本售罄，大量订单已排至2028年
  • 受人工智能基础设施需求不断增长的影响，需求远超市场预期
  • 亚马逊正在努力快速扩展基础设施，以满足AI实验室和企业源源不断的需求
市场意义：
  • 直接驳斥AI泡沫论：云厂商容量售罄说明AI需求真实存在且持续增长
  • 上游全产业链受益：芯片、存储、光模块、液冷、电力等基础设施需求确定性极高
  • 供给约束成瓶颈：算力供给无法满足需求，算力价格有支撑，相关企业业绩有保障
对A股的映射：
  • 英维克（液冷）：算力扩张直接受益，液冷是高密度算力中心刚需
  • 铜冠铜箔：AI服务器PCB铜箔需求随算力扩张持续增长
  • 雅克科技：半导体材料需求随晶圆厂扩产而增长
  • 光通信/光模块：算力互联需求持续爆发
来源：中证报、华尔街见闻
📡 SpaceX进军电信市场 美国三大运营商股价集体暴跌
SpaceX计划在美国各地获取至少8万个通信基站，引发电信板块地震：

  • SpaceX旗下星链已拥有超千万用户，正在从卫星通信向地面通信延伸
  • 传统电信运营商面临颠覆性竞争压力，估值逻辑被重估

🏛️ 二十届五中全会今日召开 聚焦'十五五'规划与高质量发展
中国共产党第二十届中央委员会第五次全体会议今日至29日在北京召开：
会议核心议题：
  • 审议《中共中央关于制定国民经济和社会发展第十五个五年规划的建议》
  • 研究部署'十五五'时期经济社会发展目标任务
  • 聚焦高质量发展、新质生产力、科技创新等核心方向
  • 深化改革扩大开放，推进中国式现代化建设
市场预期：
  • 科技自立自强：半导体、人工智能、先进制造等战略新兴产业有望获得更多政策支持
  • 扩大内需：消费、基建投资等稳增长措施预期加强
  • 绿色转型：新能源、碳中和相关产业持续受益
  • 会议期间通常政策面偏暖，对市场情绪有正面支撑作用
对持仓的意义：
  • 英维克：绿色算力、算电协同是政策重点支持方向
  • 雅克科技：半导体材料国产化属于科技自立自强核心领域
  • 铜冠铜箔：高端铜箔进口替代符合产业升级方向
来源：新华社、第一财经
📊 存储芯片Q3业绩大爆发 德明利净利同比增2903%
多家科技公司发布三季度业绩，存储芯片板块业绩炸裂：
核心公司业绩：
  • 德明利(001309)：Q3净利润同比增长2903%，环比增长2%，存储超级周期持续兑现
  • 天齐锂业(002466)：Q3净利润同比增长1324%，环比下降42%
  • 寒武纪(688256)：Q3净利润同比增长148%，环比增长8%
  • 光迅科技(002281)：Q3净利润同比增长103%，光通信景气度高
  • 华盛锂电：Q3净利润同比增长801%，环比增长148%
  • 紫金矿业：Q3净利润同比增长25.97%
行业趋势：
  • 存储芯片从价格上涨阶段进入业绩全面兑现阶段
  • AI算力、光通信、半导体设备等赛道业绩普遍超预期
  • 上游材料和设备企业业绩弹性最大
  • 野村证券：存储芯片短缺局面将持续至2028年，板块估值被严重低估
对持仓的意义：
  • 雅克科技：存储材料需求爆发，HBM前驱体+光刻胶双轮驱动
  • 铜冠铜箔：AI服务器+存储扩产带动高端铜箔需求
  • 英维克：算力中心建设加速，液冷散热需求持续增长
来源：公司公告、财联社、中国证券报
📈 A股指数编制方案修订今日实施 单一个股权重上限15%
上交所修订上证系列综合指数编制方案，今日起正式实施：
修订内容：
  • 增加单个样本权重不超过15%的权重上限规则
  • 将风险警示证券剔除时间从"实施日次月第二个星期五的下一交易日"调整为"公告日次月第二个星期五的下一交易日"
  • 涉及指数：上证指数、上证A股指数、上证流通指数、科创综指及衍生指数
市场影响：
  • 权重股影响：权重超过15%的大市值个股可能面临被动调仓减仓压力
  • 指数更均衡：降低单一个股对指数的影响，提升指数代表性和稳定性
  • ST股风险：风险警示股剔除提前，减少ST股对指数的拖累
今日其他重要事件：
  • 央行开展7000亿元1年期MLF操作，保持银行体系流动性充裕
  • 北交所无价格涨跌幅限制股票大宗交易价格新规实施
  • 百度被纳入恒生港股通新经济指数等3只指数生效
  • CPE 2026国际算电展在上海举办（10/26-28）
来源：上交所、财联社、第一财经

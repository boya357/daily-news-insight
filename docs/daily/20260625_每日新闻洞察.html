📰 重要新闻汇总

政策

央行5000亿MLF加码投放，净投放2000亿稳半年末资金面

6月25日央行开展5000亿元1年期MLF操作，当月净投放2000亿元，维稳半年末流动性。MLF政策利率维持2.95%不变，连续多月按兵不动。央行采用"收短放长"调控思路，回收短期逆回购资金，投放中长期MLF资金，优化银行负债结构。市场分析认为，下半年若经济复苏节奏放缓，存在下调MLF利率的可能性。

政策

九部门联合发布汽车后市场新政，万亿级市场全面松绑

商务部等九部门联合印发《关于培育壮大汽车后市场消费若干措施的通知》，涵盖汽车改装、房车露营、经典老车、维修保险、汽车赛事、汽车租赁六大领域。新政首次建立汽车改装分级分类管理制度，放开房车露营限制，支持经典车交易。据测算全球汽车后市场规模已突破万亿美元，国内新能源车保有量快速扩容带动售后需求爆发。

行业

长电科技78亿扩产先进封测，落子上海临港

封测龙头长电科技公告拟投资78亿元在上海临港建设高端先进封测工厂，聚焦2.5D/3D堆叠、HBM3e高带宽内存封装、Chiplet芯粒集成、混合键合、CPO光电共封装五大前沿技术。项目分两期建设，一期计划2028年下半年投产。摩根大通将长电科技目标价从45元翻倍上调至110元，公司AI相关销售额占比已升至21%。

行业

存储芯片超级周期：DRAM价格涨4.5倍，HBM产能缺口超50%

DRAM价格从2025年三季度到2026年二季度累计上涨约4.5倍。TrendForce数据显示，AI与数据中心需求持续加剧全球存储器供需失衡，HBM产能缺口达50%-60%。三大原厂已将70%新增产能倾斜至HBM，但供应紧张局面预计延续至2028年。SK海力士市值首次超越三星，成为韩国股市新市值王。

行业

长江存储NAND全球份额跃升至13%，增速领跑行业

Counterpoint最新数据显示，长江存储全球NAND闪存市占率从去年同期8%攀升至13%，跃升全球第三。长江存储自研Xtacking架构实现294层3D NAND稳定量产，良率突破90%。武汉第三座晶圆厂预计2026年底投产，同时规划新建两座全新NAND工厂，远期总产能将实现翻倍。

公司

美光科技盘后发布财报，存储景气度成市场焦点

美光科技将于6月24日美股盘后发布2026财年第三季度财报。市场普遍预期营收345-355亿美元，调整后每股收益约19.7-20.5美元，较公司自身指引高出约5%。市场重点关注HBM订单情况、毛利率水平及资本开支计划。此前公司披露2026财年全年HBM产能已全部售罄，订单能见度延伸至2027年以后。

国际

夏季达沃斯论坛收官，AI创新与经济增长成核心议题

2026夏季达沃斯论坛于6月23日至25日在大连举办，来自全球90多个国家和地区1700多位嘉宾参会。论坛聚焦经济增长、技术创新、可持续发展等议题，AI创新与合作成为核心讨论话题。多国领导人及企业CEO参与对话，探讨全球经济前景与技术发展趋势。

📝 每日总结与操作策略

【市场研判】 昨日A股探底回升，创业板指跌0.85%，上证指数收平，两市成交额超2.2万亿。 隔夜美股走势分化，道指涨0.35%，纳指连续第三日下跌0.43%，芯片股继续回调但跌幅收窄。 大宗商品集体跳水，黄金跌超3%、原油跌近4%，美元指数创13个月新高。 今日关注焦点：美光科技盘后财报、央行MLF操作、夏季达沃斯论坛收官。 操作上建议保持谨慎，仓位控制在5-6成，重点关注业绩确定性强的优质标的，避开纯题材炒作。

【核心主线】 1. 存储芯片：行业超级周期确立，DRAM价格涨4.5倍，HBM产能缺口超50%。 国产替代加速，长江存储份额快速提升。短期受海外板块回调影响承压，但中长期逻辑未变， 回调后仍是重点布局方向，关注国内有真实产能和订单的龙头标的； 2. 先进封装：长电科技78亿扩产印证行业高景气， AI时代先进封装成为核心瓶颈，2.5D/3D、HBM、Chiplet等技术加速迭代， 国产封测龙头迎来价值重估，关注技术布局领先、产能扩张明确的标的； 3. AI算力硬件：高位震荡整固，业绩确定性成为核心锚点。 光模块、液冷等细分赛道订单饱满、业绩确定性高，逢低可关注龙头标的； 4. 汽车后市场：九部门新政超预期，万亿市场全面松绑， 汽车改装、房车露营、维修保险等多赛道受益，关注相关受益标的； 5. 防御性配置：半年末市场波动加剧， 适度配置医药、消费等防御性板块对冲市场波动。

【操作策略】 当前全球市场处于高波动期，A股也面临外部情绪冲击与内部调仓压力，操作上不宜盲目抄底，建议： 1. 仓位控制在5-6成，保持现金灵活性，应对市场波动； 2. 高位科技股（纯题材炒作、无业绩支撑）逢高减仓，规避回调风险； 3. 适度配置防御性板块（医药、公用事业）对冲市场波动； 4. 关注半年报业绩超预期的优质标的，业绩确定性是当前市场核心锚点； 5. 严格执行止损纪律，个股跌破关键支撑位及时减仓控制风险； 6. 存储、先进封装等硬核科技赛道中长期逻辑不变，回调后逢低布局。

【持仓策略】 铜冠铜箔：存储封装铜箔龙头，受益于AI算力与存储芯片需求爆发，长期逻辑不变。 短期受板块情绪影响可能震荡，逢高可适当减仓锁定部分利润，保留底仓观察，回调后可回补； 雅克科技：存储/HBM核心材料标的，基本面扎实，长期受益于存储芯片扩产。 业绩确定性强，估值合理，可继续持有，回调可逢低加仓； 英维克：液冷散热龙头，AI算力基础设施核心受益标的。 短期破位后关注反弹力度，若无法有效收复关键均线考虑减仓，等待更好的介入时机； *ST建艺：摘帽预期标的，事件驱动型，控制仓位在5%以内，关注后续进展。

教训#1：中报季"利好出尽"效应显著

三星1810%利润公布后暴跌、江波龙中报利好后高开低走，明牌利好往往是股价高点。 正确做法：买预期卖事实，在业绩公布前1-2周逐步兑现，不等到业绩公布当天才卖。 对于中报超预期的标的，等回调企稳后再考虑接回。

教训#2：费半大涨日，A股半导体不一定跟

费半大涨可能是"美股反弹"而非"产业逻辑强化"，A股半导体经常"高开低走"。 正确做法：不因为隔夜费半大涨就追高A股半导体，必须结合A股自身的量能和催化判断。 若开盘高开3%以上但量能不足，大概率是高开低走，应减仓而非追涨。

教训#3：ST股反弹=出货机会

多次在ST股下跌后抱有"反弹再卖"的幻想，结果越套越深。 正确做法：ST股一旦确定基本面恶化，任何反弹都是出货机会，坚决不抱幻想。 龙空龙策略的核心是"不参与下跌趋势"，ST股更应严格执行。

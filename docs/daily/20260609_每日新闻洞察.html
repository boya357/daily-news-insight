📝 今日总结

隔夜美股科技板块强力反弹，费城半导体指数大涨5.61%，显著缓解了上周五暴跌后的市场恐慌情绪。英伟达与SK海力士官宣多年深度合作伙伴关系，从技术研发到产能供应全面绑定，覆盖四大核心计算平台，进一步强化了存储超级周期的产业逻辑。黄仁勋明确表示存储短缺将持续数年，HBM供需缺口持续扩大，三大原厂产能全部售罄至2028年，产业链公司业绩确定性极强。国内方面，城市更新'十五五'规划重磅出台，预计带动约5万亿元投资规模，为稳增长提供新动力。电子布年内5轮涨价累计涨幅达100%，验证AI算力产业链上游材料环节持续高景气。人形机器人产业迎来量产拐点，特斯拉已向核心供应商下达量产订单，三季度产能将开启高速爬坡。操作上，今日市场有望迎来超跌修复行情，建议重点关注存储芯片、AI算力硬件等人气赛道的反弹机会。同时注意控制整体仓位，保留部分现金应对市场波动。持仓方面，铜冠铜箔直接受益存储超级周期延续强势，英维克短期承压但长期逻辑不变，*ST建艺关注摘帽进展。

🎯 明日计划

1. 仓位管理：建议将总仓位控制在6-7成左右，保留3-4成现金应对市场波动。 2. 持仓操作：英维克若跌破60元可考虑小幅加仓摊薄成本；铜冠铜箔继续持有，关注120元压力位；*ST建艺持有观察摘帽进展。 3. 重点关注：存储芯片板块反弹持续性，观察量能是否有效放大；北向资金流向，判断外资态度。 4. 风险规避：坚决回避近两个月涨幅过大、无业绩支撑的纯概念题材股，此类标的补跌风险仍存。 5. 长线布局：利用市场调整机会，逢低布局存储芯片、AI算力基础设施、人形机器人等确定性高的硬核科技方向。 6. 事件驱动：关注城市更新政策落地节奏，以及机器人产业催化事件带来的交易性机会。

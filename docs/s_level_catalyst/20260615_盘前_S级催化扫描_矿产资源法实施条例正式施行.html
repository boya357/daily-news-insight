S级催化

36种战略矿产全链条管控，资源板块迎价值重估

⚡ S级催化 - 矿产资源法实施条例正式施行
国务院令第839号《中华人民共和国矿产资源法实施条例》于2026年6月15日正式施行。 该条例将36种关键矿产纳入国家级战略性矿产资源目录，实行从开采到出口的全链条管控， 标志着我国矿产资源管理从"粗放开发"全面转向"安全优先、战略管控、高质量发展"的新阶段。 这是继2025年《矿产资源法》修订后最重要的配套行政法规， 将对有色、稀土、小金属等板块产生深远影响，相关资源品从"普通商品"升级为"国家安全资产"， 供给端制度性收紧，价值重估空间巨大。

🔍 催化事件详解

📚
事件背景
2026年5月9日，国务院第85次常务会议通过《中华人民共和国矿产资源法实施条例》， 自2026年6月15日起正式施行。《条例》共8章79条，是新修订《矿产资源法》的核心配套行政法规。 出台背景： 1. 全球地缘冲突加剧，关键矿产供应链安全成为大国博弈焦点 2. 新能源、半导体、AI等新兴产业对关键矿产需求呈指数级增长 3. 我国部分关键矿产对外依存度超过70%，供应链安全风险凸显 4. 过往矿业权管理不规范，地方无序扩产导致资源浪费和价格波动 核心变化： - 首次以行政法规形式确立战略性矿产目录法律地位 - 矿业权审批权限全面上收，地方政府自主审批空间大幅压缩 - 建立"产品储备、产能储备、产地储备"三位一体储备体系 - 战略性矿产违法行为从重处罚，监管力度空前加强
🔥
触发因素
直接触发因素： 1. 6月15日条例正式生效，36种战略矿产进入全链条管控新阶段 市场催化逻辑： 1. 供给收缩：开采审批权上收+总量控制，新增产能受限，供给弹性大幅降低 2. 价值重估：从"周期商品"升级为"战略资产"，估值体系重构 3. 出口管制：关键矿产出口审查趋严，全球供给格局重塑 4. 战略收储：国家储备体系完善，刚性需求托底价格中枢 5. 龙头集中：行业门槛提高，合规龙头企业份额持续提升 市场反应： 6月12日有色金属板块单日主力净流入140.67亿元，创历史峰值， 洛阳钼业、铜陵有色、北方稀土等龙头股获资金大幅抢筹， 市场已提前反应政策预期，但正式落地后的长期影响远未充分定价。

⚠️ 重要风险提示
政策执行力度不及预期：部分配套细则出台进度可能慢于市场预期；宏观经济下行风险：经济增速放缓可能影响工业金属需求；海外矿山增产超预期：海外矿山投产进度超预期可能缓解供给紧张；短期情绪过热回调：部分个股短期涨幅较大，存在利好兑现回调风险；汇率波动风险：美元走强可能压制大宗商品价格表现

🎯 投资策略建议

投资策略：逢低布局，长期持有，优选龙头 配置思路： 1. 核心配置（50%仓位）：稀土永磁+铜铝龙头，业绩确定性强，估值修复空间大 2. 弹性配置（30%仓位）：小金属（钨/钼/锗/镓），供给收缩弹性最大 3. 成长配置（20%仓位）：能源金属（锂/钴/镍），新能源需求+供给收缩共振 操作建议： - 短期（1-3个月）：关注政策细则落地节奏，6月15日正式施行后观察市场反应 - 中期（3-6个月）：中报业绩验证，优选具备真实业绩弹性的标的 - 长期（6-12个月）：战略资源估值体系重构，龙头企业价值重估 重点关注： - 自有矿权比例高、资源储量大的龙头企业 - 深加工能力强、技术壁垒高的细分领域龙头 - 受益于出口管制、全球定价权提升的品种

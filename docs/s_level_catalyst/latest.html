S级催化

2026.10.22 · 盘前S级催化

⚡ S级催化 - AI算力需求再确认：SpaceX超智能营收暴增830% + Meta上调资本开支 + 半导体全线暴涨
隔夜美股半导体板块全线暴涨，费城半导体指数涨1.97%，成分股29涨1跌。核心驱动来自三重超预期信号：①SpaceX Q3超智能业务营收75.6亿美元，同比暴增830%、环比增195%，上市后首次季度盈利；②Meta Q3营收646亿美元（+26%）超预期，Q4指引730-760亿美元，2026年资本开支下限从1300亿上调至1350亿美元；③英伟达GTC柏林大会发布DSX POD模块化AI工厂，部署周期从6个月缩短至14天，100%液冷设计。三重信号共同确认AI算力需求处于加速扩张期，存储、设备、液冷全产业链受益。

🔍 催化事件详解

📚
事件背景
10月21日A股市场冲高回落，创业板指跌1.62%创年内新低，宁德时代重挫12%拖累指数。算力硬件板块分化，存储芯片概念震荡反弹，CPO、端侧AI、物理AI等局部活跃。市场此前对AI算力需求持续性存在分歧，对冲基金大幅减仓科技股，市场情绪偏谨慎。隔夜美股科技股的强势表现有望修复A股科技板块情绪。
🔥
触发因素
四大催化共振：①SpaceX Q3超智能营收同比+830%至75.6亿美元，马斯克称AI计算需求远超供给；②Meta Q3超预期+上调全年资本开支下限50亿美元至1350-1450亿；③超微电脑Q1初步营收185-195亿美元，大幅超预期的152亿，涨9.55%；④英伟达GTC柏林发布DSX POD AI工厂，液冷+模块化+14天快速部署，2027年初全球交付。

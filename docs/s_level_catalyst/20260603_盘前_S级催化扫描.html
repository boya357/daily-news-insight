🔴 S级重大催化事件

S级

国资国企改革方案(2026-2029年)正式发布

来源：国资委 · 6月2日全国视频会议

🏛️

📌 核心政策要点

  • • 市值管理硬约束：将市值管理纳入央企负责人年度考核指标，权重不低于20%
  • • 破净央企限期整改：长期破净、估值低于行业平均水平的央企面临管理层调整压力
  • • 战新产业集中：推动国有资本向战略性新兴产业集中，提升国企整体盈利能力
  • • 统一大市场建设：带头打破地方保护和市场分割，降低物流成本
  • • 时间节点明确：所有央企和地方国企需在6月底前制定完成改革方案

🎯 受益板块与标的

低估值央企蓝筹

中特估主线回归：能源、电力、基建、交运等破净央企估值修复预期最强

战新产业转型

布局AI算力、先进封装、人形机器人、6G等方向的央企将获资源倾斜

S级

《求是》定调六大未来产业 + 中央财政千亿专项

来源：《求是》2026年第11期 · 6月2日

🚀

📌 顶层设计核心要点

  • • 六大赛道明确：量子科技、生物制造、氢能与核聚变能、脑机接口、具身智能、第六代移动通信(6G)
  • • 千亿专项资金：中央财政每年安排1000亿元专项资金支持六大未来产业
  • • 地方专项债配套：允许地方政府发行专项债用于未来产业基础设施建设
  • • 全国一盘棋布局：31个省份"十五五"规划已全部出齐，未来产业路线图悉数公布

🟡 A级重要催化事件

A级

上海全球资产管理中心建设意见发布

来源：上海市政府 · 6月2日

💰

核心亮点

  • • 规模目标：2030年上海资产管理规模达到55万亿元，占全国1/3
  • • 长线资金入市：推动社保基金、保险资金、年金等加大A股权益配置
  • • 金融衍生品扩容：加快LNG期货期权上市，推进电力期货、算力期货研发
  • • 科创企业融资：优先支持硬科技企业上市和并购重组

市场影响

港股科技板块已率先异动，恒生科技指数单日大涨超4.7%。券商自营、期货公司经纪业务直接受益，科创赛道估值有望迎来修复。

S级催化

2026.09.10 · 盘前S级催化

⚡ S级催化 - 存储超级周期再深化：韩企库存告急+SK海力士创新高
隔夜美股三大指数集体收跌（道指-0.77%、纳指-0.64%、标普-0.48%），但存储板块逆势爆发：SK海力士大涨7.05%创历史新高，美光+2.75%，闪迪+1.51%，费城半导体指数+0.37%。韩国KB证券最新报告称，三星电子与SK海力士可售存储芯片库存已降至不足10天供货量，2027年或迎史上最严重供给紧缺。叠加工信部十五五算力网规划、国产芯片适配加速，存储产业链迎来产业逻辑+政策催化双重共振。

🔍 催化事件详解

📚
事件背景
全球AI基础设施投资正以空前速度扩张，2027年全球头部云厂商AI投资预计达1.3万亿美元（同比+60%）。存储芯片在AI基建投资中的占比将从2025年的14%升至2026年的40%、2027年的57%。HBM4单颗产品所需晶圆面积约为传统DRAM的三倍，进一步加剧产能紧张。三星与SK海力士库存降至10天以下，行业正从"供需紧平衡"走向"历史性短缺"。尽管板块前期大幅回调（SK海力士较高点跌近40%），但基本面持续向好，盈利有望连续三年创历史新高。
🔥
触发因素
1. SK海力士+7%创历史新高：9月9日美股SK海力士ADR大涨7.05%，盘中刷新历史新高，存储涨价逻辑获海外资金确认
2. KB证券：库存不足10天：三星/SK海力士可售库存已降至10天以下，2027年DRAM/NAND需求超供给10个百分点以上
3. 工信部双重磅政策：十五五算力网规划（万卡/十万卡智算集群+国产芯片适配）+ AI中小企业创业支持计划
4. 阿斯麦High NA扩产：与台积电/三星/英特尔推进下一代EUV，2030年起大规模量产，长期利好半导体设备
5. 雅克科技机构调研：韩国UP Chemical满产，中韩双基地扩产，国海证券首予买入评级（目标PE 48x）

*ST建艺 (002789) 立即清仓

🎯 投资策略建议

整体判断：存储超级周期产业逻辑获得海外市场验证（SK海力士创新高+韩企库存告急），叠加国内算力网政策催化，科技成长板块有望迎来阶段性反弹窗口。但需警惕油价上涨+美债收益率走高带来的宏观压制。

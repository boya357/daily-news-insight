L1 · 数据来源层

数据采集

多源异构数据接入，确保数据全面性和时效性

东方财富API 新浪财经 韭研公社 财联社 TheElec 科创板日报 Skill 引擎
L2 · 数据生产层

分析计算

数据清洗、指标计算、评分模型、智能分析

数据采集脚本 Skill 集成 三维评分 业绩监控 持仓分析 情绪分析
L3 · 数据存储层

持久化存储

单一数据源原则 (SSOT)，所有页面从统一数据读取

行情数据 持仓数据 分析结果 业绩预告 题材分类 JSON 格式
L4 · 内容生成层

报告生成器

模板化生成，确保风格统一、结构一致

日报 盘中快报 盘后速递 周复盘 产业链 个股分析 持仓预警
L5 · 页面展示层

前端呈现

深色玻璃态风格，响应式设计，交互友好

报告列表 个股详情 仪表盘 悬浮卡片 GitHub Pages Tailwind CSS
L6 · 调度通知层

自动化运维

定时触发、自动部署、实时推送

日历任务 企业微信 Git 部署 全自动 免运维

🏗️ 核心设计原则

📦 三层分离架构

数据生产 → 数据存储 → 页面展示，各层独立演进，互不干扰

🎯 单一数据源 (SSOT)

所有配置、路径、数据统一从 config.py 和 data/ 目录读取，杜绝不一致

🔌 插件化 Skill 集成

新 Skill 通过 bridge 层接入，不侵入现有系统，接一个成一个

⚡ 全自动化流水线

定时触发 → 数据采集 → 分析计算 → 生成报告 → 部署推送 → 通知用户

## 二、影响强度评估（IMPS模型）

> IMPS = Impact Multiplier by Phase & Scale
> **公式**：题材影响强度 = I级 × M级 × S级

### 2.1 I级催化剂评级（四要素评定）

```
I级 = f(供需变化程度, 受益范围广度, 逻辑可验证性, 预期差大小)
```

| 评级 | 供需变化 | 受益范围 | 验证性 | 预期差 |
|:-----|:---------|:---------|:-------|:-------|
| I-5 | 根本性改变 | 全产业链 | 已验证 | 市场未关注 |
| I-4 | 不可逆断裂 | 多环节 | 部分验证 | 部分关注 |
| I-3 | 加速扩张 | 单环节 | 逻辑推导 | 部分关注 |
| I-2 | 边际改善 | 个股 | 待验证 | 已定价 |
| I-1 | 纯情绪 | 无实质 | 无 | 已过度定价 |

### 2.2 M级传导倍数

| 产业链特征 | 倍数 | 案例 |
|:-----------|:-----|:-----|
| 短链条（1-2级） | 1-2x | 氦气涨价→华特气体（1级传导，弹性最大） |
| 中链条（3-4级） | 2-4x | 铜价涨→铜箔→覆铜板（中游弹性最大） |
| 长链条（5+级） | 3-6x | AI算力→芯片→服务器→PCB（PCB是瓶颈放大） |

**关键规律**：
- 上行周期：中游（覆铜板）是利润放大器
- 下行周期：下游（PCB）有议价滞后优势
- 瓶颈环节：产能有限+认证周期长=弹性最大

### 2.3 S级情绪系数

| 情绪状态 | 系数 | 特征 |
|:---------|:-----|:-----|
| 冰点反转期 | 3-5x | 涨停<20家，出现破局股 |
| 主升共振期 | 1.5-3x | 主线明确，板块轮动健康 |
| 高位震荡期 | 0.8-1.5x | 龙头分歧，补涨活跃 |
| 退潮杀跌期 | 0.3-0.8x | 亏钱效应蔓延 |

### 2.4 综合评估公式

```
综合强度 = I级 × M级 × S级

判定标准：
- ≥15：S级题材，满仓龙头
- 8-15：A级题材，半仓参与
- 4-8：B级题材，轻仓试探
- <4：C级题材，观望为主
```

## 三、时间维度分析（TVRC模型）

> TVRC = Timing, Velocity, Range, Cycle

### 3.1 时间节奏四阶段

| 阶段 | 特征 | 最优操作 |
|:-----|:-----|:---------|
| 预反应期 | 产业链信号，少数资金潜伏 | 低吸布局，最佳性价比 |
| 爆发期 | 龙头涨停，板块共振 | 首板/二板确认，果断介入 |
| 发酵期 | 龙头连板，梯队扩散 | 持有龙头，分歧日加仓 |
| 衰退期 | 跟风掉队，量能萎缩 | 分批止盈，空仓等待 |

### 3.2 五大时间锚点

| 锚点 | 操作意义 |
|:-----|:---------|
| T-5~T-1 | 预反应窗口，提前布局 |
| T+0~T+1 | 爆发确认，追涨窗口 |
| T+3~T+5 | 分歧验证，生死窗口 |
| T+7~T+10 | 二次催化，二波决策 |
| T+15~T+30 | 衰退预警，全部止盈 |

## 四、预判推理流程

### Step 1: 信号采集→IMPS强度评估

```
发现异常信号
├── 产业链异动（涨价/缺货/产能/订单）
├── 资金异动（北向/融资/ETF/龙虎榜）
├── 政策/事件异动（新闻联播/官网）
└── 技术异动（突破/背离/倍量上影线）

→ 评估I级（催化剂强度）
→ 评估M级（传导倍数）
→ 评估S级（情绪系数）
→ 计算综合强度
```

### Step 2: 逻辑推导→产业链定位

```
本质分析 → 产业链推导 → 业绩弹性计算 → 时间判断

血统鉴定三标准：
| 标准 | 要求 | 权重 |
|:-----|:-----|:-----|
| 题材匹配度 | ≥90% | 40% |
| 唯一性/稀缺性 | 市占率≥30% | 30% |
| 信息验证 | 公告+研报+媒体 | 30% |

总分<80分视为血统不纯，直接剔除
```

### Step 3: 标的筛选→龙头确认

```
血统鉴定 → 业绩验证 → 资金验证 → 位置评估

四大识别信号：
1. 空间龙：5日涨幅>30%或翻倍
2. 时间龙：题材首次爆发第一个涨停
3. 技术面：上涨放量+回调缩量，量比>2
4. 情绪指标：百度指数/股吧热度暴增

二板定龙头标准：
1. 属于市场主流题材
2. 带动板块≥5只跟风
3. 放量换手（超首板1.2倍）
4. 10点半前封板，封单≥流通市值1%
5. 基本面无重大利空
```

### Step 4: 时机判断→TVRC节奏定位

```
判断题材类型 → 确定时间节奏 → 匹配矩阵定位

强度×时间决策：
- 脉冲型：快进快出
- 主升型：持有龙头做主升
- 超级周期：底仓+波段
- 短炒型：轻仓快做
```

## 五、龙头识别与操作体系

### 5.1 龙头四大识别信号

| 信号类型 | 龙头特征 | 跟风股特征 |
|:---------|:---------|:-----------|
| 涨停时间 | 9:30-10:00首板 | 尾盘涨停或次日补涨 |
| 封单强度 | ≥流通市值1% | 封单小，频繁开板 |
| 带动效应 | ≥3只跟风涨停 | 无联动，仅自身上涨 |
| 龙虎榜 | 机构+顶级游资共买 | 单一游资或散户主导 |

### 5.2 情绪周期操作策略

| 周期 | 信号 | 策略 |
|:-----|:-----|:-----|
| 冰点期 | 涨停<20家，连板高度2-3板 | 空仓/极小仓位，关注破局股 |
| 复苏期 | 破局股出现，涨停增多 | 试错新题材，仓位逐步提升 |
| 高潮期 | 连板高度7板+，涨停>80家 | 持股龙头，享受溢价 |
| 退潮期 | 高位股亏钱效应 | 空仓，回避中高位股 |

### 5.3 买点/卖点判断

**五类买点**：
| 类型 | 描述 | 风险 |
|:-----|:-----|:-----|
| 首板放量突破 | 长期横盘后首板，换手>10% | 中 |
| 二板缩量确认 | 缩量确认强势地位 | 低 |
| 分歧转一致 | 炸板后回封时加仓 | 中 |
| 龙头接力 | 3-4板借助合力推高 | 高 |
| 龙回头 | 强势整理期间低吸 | 中 |

**卖点判断**：
- 断板即卖：首次无法涨停，至少卖出一半
- 不涨停就卖：加速后无法封板
- 爆量不封板：天量无法封板，多空分歧巨大
- 板块退潮：核心股跌停，梯队瓦解即减仓
- 破5日线：趋势龙头以5日线为生命线

**封单成交比**：
| 比值 | 含义 | 操作 |
|:-----|:-----|:-----|
| >10 | 主力极强 | 持有，大概率连板 |
| 3-10 | 多头明显 | 冲高卖出或做T |
| <1 | 资金不足 | 果断卖出 |

### 5.4 伪龙头排除法

| 特征 | 风险等级 |
|:-----|:---------|
| 尾盘涨停（非早盘主动） | 高 |
| 板块唯一涨停 | 高 |
| 利好兑现后涨停 | 高 |
| 拉萨天团主导 | 高 |
| 巨量炸板后不回封 | 高 |

## 七、历史案例验证

### 7.1 成功案例（累计12个）

**锂矿涨价（2026-04-28~30）** ✅
- IMPS = I-4 × M=1.5 × S=2x = 12 → A级脉冲型
- 龙头：融捷股份5天3板、永杉锂业3连板、德方纳米20cm
- 血统鉴定：纯正（宜春云母矿60%产能+碳酸锂涨价37.5%）
- 教训：涨价题材"供需缺口+价格可监测+业绩兑现快"三要素

- 教训：政策题材需"政策级别×业绩验证×资金背书"三合一

### 7.2 失败/部分成功案例（累计5个）

**小米MiMo-V2.5（2026-04-23）** ⚠️
- 结果：⚠️ 部分成功（海光/寒武纪小涨）
- 教训：小米不是A股公司→传导链条间接→机构认可度一般
- **核心**：A股公司直接受益 > 间接受益；链条越短，确定性越高

### 9.2 龙头三阶段铁律

```
首板看快慢 → 谁先板，谁占先机
二板看强度 → 谁最强，谁是龙
三板看辨识度 → 谁最有人气，谁走成总龙
```

**首板六硬指标**：

6. 股性活（历史常涨停连板）

**二板定龙标准**：
- 高开最强（板块内开得最高）
- 拉升最猛（秒板、快速板）
- 烂板能回封（炸板不怕，回封坚决）
- 带节奏（它一封，板块立刻跟风）

### 9.3 题材预判四字诀（大、频、新、近）

## 九、龙头股预判核心方法论（2026-05-07学习更新）

> 来源：雪球/淘股吧/东方财富等游资实战经验整理

### 9.1 游资选股三大底层密码

**密码1：血统筛查——正宗性是龙头的第一生命线**

```
量化筛查标准（非主观判断）：
1. 题材匹配度≥90%：必须是题材核心受益标的
   计算：核心业务占比×政策关联度×行业地位权重
   
2. 唯一性/稀缺性：板块内同类标的不超过3家，或细分领域市占率≥30%

3. 信息验证三重奏：
   - 公司公告明确提及相关业务（权重40%）
   - 行业研报将其列为核心标的（权重30%）
   - 权威财经媒体报道其行业地位（权重30%）
   总分<80分，视为血统不纯，直接剔除
```

**密码2：板块共振——没有小弟簇拥的龙头，都是伪龙**

```
量化共振标准：
1. 竞价抢筹率：9:20-9:25，候选池内≥3只票出现单笔≥1000手的抢筹单
   且抢筹量占流通盘比例≥0.05%

2. 板块涨停预期：首板次日，板块内涨停预期≥5家

3. 资金集中度：候选池前3名标的竞价资金占板块总竞价≥60%

竞价盯盘三判断：
- 量能判断：竞价量≥昨日成交量的5%
- 价格判断：高开≥3%且无大幅波动
- 联动判断：候选池内标的是否同步异动
```

**密码3：资金投票——抢筹金额才是龙头的终极身份证**

```
量化抢筹标准：
1. 绝对金额门槛：
   - 流通盘<50亿：9:20-9:25抢筹金额≥3000万
   - 流通盘≥50亿：抢筹金额≥5000万

2. 相对强度标准：
   - 抢筹金额排名必须进入板块前五
   - 个股抢筹金额占板块总抢筹≥20%（龙头气质）
   - ≥30%则是超级龙头信号

3. 速度验证：开盘后首个涨速≥5%/分钟，且能快速封板（<10分钟）
```

### 9.2 题材炒作三大逻辑

| 逻辑类型 | 核心特征 | 炒作节奏 | 代表案例 |
|:---------|:---------|:---------|:---------|
| **涨价逻辑** | 价格可监测+供需缺口+业绩兑现快 | 快起快落，T+3~T+5生死窗口 | 锂矿、铜箔、氦气、存储 |
| **技术突破逻辑** | 国产替代+商业化验证+业绩拐点 | 慢热持久，二波机会在商业化验证期 | DeepSeek V4、国产GPU |
| **政策催化逻辑** | 顶层设计+业绩验证+资金背书三合一 | 持续性强，以季度计算 | 半导体国产替代、AI算力 |

**核心规律**：
- 涨价题材：供需缺口+价格可监测+业绩兑现快三要素缺一不可
- 技术题材：A股公司直接受益 > 间接受益；链条越短，确定性越高
- 政策题材：政策级别×业绩验证×资金背书三合一才能持续

### 9.3 情绪周期六阶段量化标准

| 阶段 | 信号指标 | 仓位策略 |
|:-----|:---------|:---------|
| **启动试错** | 最高连板≤3板，零星新题材出现 | 2成以内 |

### 11.1 龙头股识别11个方法论

| **9.看历史股性** | 过往有领涨记录 | 历史类似题材中曾领涨 |
| **10.看市值与流通盘** | 中等市值为主 | 流通盘50-300亿最佳 |
| **11.看情绪锚定** | 成为市场风向标 | 股吧热度/券商点评共识形成 |

### 11.2 新周期龙头四大演变特征（2024年后）

### 11.3 集合竞价涨停前预判三步法

```
第一步：9:25调出涨幅榜，量比前30加自选
第二步：按换手率排序，删<2%的股票
第三步：按涨幅排序，只留2%-5%区间
```

**集合竞价四大信号识别**：

| 信号类型 | 特征 | 含义 |
|:---------|:-----|:-----|
| **强势抢筹型** | 9:20后价格持续上移，红色量能柱密集 | 主力真实抢筹，开盘可能快速封板 |
| **缓慢上攻型** | 竞价逐步抬高，9:23-9:24突破 | 多头力量增强，具备涨停潜力 |
| **一字板型** | 红色柱子密集，成交量极低 | 开盘即封涨停，但买入机会少 |

### 11.4 游资选股三板斧（新/大/强）

```
第一板斧：题材定生死，只做"新、大、强"主线
第二板斧：资金辨真假，只认"主动抢筹"真龙
第三板斧：位置定节奏，根据K线阶段匹配策略
```

**题材三标准**：
- **新**：刚出来的新政策/事件/技术，无历史套牢盘
- **大**：国家级/行业级大题材，非小公司小利好
- **强**：有赚钱效应，板块集体动（≥3只涨停）

**资金三信号辨真假**：
1. 早盘竞价高开4%-8%（最强区间）
2. 大单净流入持续翻红
3. 龙虎榜机构+知名游资共同出现

### 11.5 三大题材类型深度挖掘方法

#### 涨价型题材
```
三要素验证：
1. 供需缺口真实存在（非预期）
2. 价格可实时监测
3. 业绩兑现速度快（Q1/Q2立即反应）
```

**涨价题材操作铁律**：
- T+3~T+5是生死窗口
- 涨幅超30%后禁止追高
- 核心标的：直接受益+业务占比≥30%

#### 技术突破型题材
```
七种挖掘策略：
1. 成本骤降路径：追踪算力/生成/自动化成本曲线
2. 旧行业低效改造：找重复性高、数据结构化的环节
3. 供给侧能力外溢：高能力域→低渗透场景
4. 政策试点扩散：试点城市/项目复制阶段最佳
5. 产业链迁移：判断利润最高环节向哪迁移
6. 组织能力缺口：技术翻译层/集成服务机会
7. 下沉市场机会：大公司看不上的市场更易突破
```

**技术突破题材判断信号**：
- 专利增长率>30%
- 龙头企业研发费用率>15%
- 政策补贴下降+成本同步下降的黄金交叉

#### 政策催化型题材
```
政策解读四步法：
1. 盯最高级别：政治局>国常会>部委>地方
2. 首次出现的关键词必须重视
3. 配套资金规模是硬指标
4. 落地时间节点明确度
```

**政策题材时间窗口**：
- 两会前（1-2月）：政策预期炒作
- 政治局会议（4/7/10/12月）：边际变化捕捉
- 中央经济工作会议（12月）：定调来年方向

### 11.1 龙头识别十一维度（量化标准）

| 维度 | 龙头特征 | 量化标准 | 反面案例 |
|:-----|:---------|:---------|:---------|
| **1.启动速度** | 板块内率先涨停 | 9:30-10:00首板，封单占流通盘≥0.8% | 午后涨停、跟风补涨 |
| **2.连板强度** | 涨停数量领先 | 连续涨停≥3板，中途回调不破前一日涨停价 | 1-2板后滞涨 |
| **3.板块带动性** | 领涨板块，下跌抗跌 | 涨停时板块≥30%个股跟风；大盘跌2%时跌幅≤1% | 孤立行情、无板块联动 |
| **4.资金集中度** | 主力持续净流入 | 大单买入占比≥60%，连续多日净流入 | 单一资金独食 |
| **5.题材关联度** | 直接受益核心题材 | 业务直接关联≥90%，非边缘标的 | 蹭热点、无实质关联 |
| **6.市场关注度** | 成交量放大 | 量比≥2，换手率5%-20%，研报/媒体热度高 | 成交量低迷、无人问津 |
| **7.抗跌修复力** | 回调少，反弹快 | 大盘跌时跌幅小于板块均值50%；1-2日收复失地 | 跌幅比板块更深 |
| **8.技术形态** | 突破关键阻力位 | 突破年线/新高/平台，均线多头排列，回调不破5日线 | 跌破均线、均线杂乱 |
| **9.历史股性** | 过往有领涨记录 | 近1-2年曾多次连板/成妖，历史涨停频率高 | 常年不涨停、冷门股 |
| **10.市值适中** | 中等市值为主 | 流通盘50亿-200亿，股价中低价位 | 流通盘过小或过大 |
| **11.情绪锚定** | 市场风向标 | 成为板块情绪核心，被资金共识认可 | 无辨识度、无人讨论 |

**综合判定**：满足≥7个维度可视为潜在龙头；满足≥9个维度为高确定性龙头

### 11.2 题材炒作五维分析框架

```
     催化剂（新/大/硬）
          ↓
    ┌─────┼─────┐
    ↓     ↓     ↓
  资金  情绪  标的
  (钱)  (人)  (股)
    ↓     ↓     ↓
板块效应 氛围感 正宗度
梯队完整 赚钱效应 筹码干净
量价配合 风险偏好 低位低价
```

**催化剂三要素**：
- **新**：前所未有新概念，无套牢盘，易形成一致预期
- **大**：千亿万亿市场规模，支撑大行情
- **硬**：硬核逻辑支撑，政策/技术/业绩验证

**资金认同三信号**：
- 板块效应：批量涨停，涨停潮出现
- 梯队完整：龙头+中军+跟风，结构健康
- 龙虎榜验证：知名游资席位大笔买入

**情绪氛围四指标**：
- 市场趋势：上升/震荡市成功率高于单边下跌
- 赚钱效应：连板股不断涌现，断板后不闷杀
- 风险偏好：资金追逐高弹性标的
- 板块轮动：主线清晰，资金集中

**标的纯粹三标准**：
- 逻辑正宗：一眼能看懂为什么涨
- 盘子轻：流通市值<50亿，股价<10元
- 筹码干净：无机构重仓、无减持、无天量解禁

### 11.3 题材炒作四阶段规律

| 阶段 | 特征 | 散户行为 | 正确做法 | 操作仓位 |
|:-----|:-----|:---------|:---------|:---------|

| **退潮下跌期** | 龙头跌停，跟风暴跌 | 套牢死守 | 清仓离场 | 0成 |

**核心规律**：主力在潜伏启动期建仓，散户在高潮期接盘

|:-----|:---------|:---------|
| **第一招：题材为王** | 紧跟主线题材，不碰冷门 | 只做政策/产业/事件核心方向 |
| **第二招：早盘封板** | 早盘板是金，午盘板是银，尾盘板是铜 | 9:30-10:30封板最佳 |
| **第三招：量价配合** | 放量突破，无量涨停易炸板 | 量比≥3，放量封板 |
| **第四招：封单充足** | 封单金额是安全垫 | 流通盘50亿封单需≥2.5亿，万手大单为主 |
| **第五招：分时流畅** | 直线拉升无回调，走势干净利落 | 不碰分时上蹿下跳的烂板 |
| **第六招：板块联动** | 有小弟助攻才是真龙 | 龙头封板后≥3只跟风涨停 |
| **第七招：股性活跃** | 历史常涨停，波动幅度大 | 排除常年不涨停的冷门股 |
| **第八招：弱转强** | 烂板次日高开，快速拉升回封 | 资金承接力极强，往往连板 |
| **第九招：规避庄股** | 高位减持、监管预警不碰 | 大股东减持=主力出货信号 |
| **第十招：仓位管控** | 分仓操作，单票≤20% | 不满仓梭哈，分散风险 |
| **第十一招：竞价预判** | 高手赢在集合竞价 | 高开3%-5%+竞价量≥昨日5% |
| **第十二招：及时止盈** | 不贪不恋，断板就走 | 冲高无力果断卖出 |

**打板核心禁忌**：
- 不打直线秒封板
- 不打无量涨停（换手<3%）
- 不打尾盘偷袭板（14:30后）
- 不打烂板（反复开板）
- 不打无板块效应的孤立涨停

### 11.6 涨停板战法精细化体系

**情绪周期量化标准**：

| 周期 | 涨停家数 | 连板高度 | 晋级率 | 仓位策略 |
|:-----|:---------|:---------|:-------|:---------|
| **冰点期** | <20家 | 2-3板 | <30% | 空仓/极小仓位 |
| **复苏期** | 20-50家 | 3-5板 | 30-50% | 2-3成试错 |
| **高潮期** | >80家 | 7板+ | >50% | 5-7成龙头 |
| **退潮期** | 减少 | 下降 | <30% | 清仓空仓 |

**五大量化指标**：
1. 市场最高连板高度
2. 连板个股晋级成功率
3. 每日涨停/跌停家数对比
4. 开盘竞价题材强弱与助攻力度
5. 前期老龙头的分时强弱反馈

**买点精细分类**：

| 买点类型 | 适用场景 | 操作要点 |
|:---------|:---------|:---------|
| **首板放量突破** | 长期横盘后启动 | 换手>10%，突破关键位置 |
| **二板缩量确认** | 确认强势地位 | 缩量说明抛压轻 |
| **分歧转一致** | 高位震荡首次分歧 | 回封瞬间挂单介入 |
| **弱转强** | 前一日烂板，次日高开 | 水下2-3%观察，放量翻红时介入 |
| **龙回头** | 强势整理期间低吸 | 回调至5/10日线低吸 |
| **A板反弹** | 龙头4板+后首个下跌反弹 | 角度30度或急跌反弹最佳 |

**卖点八大信号**：
1. 高位跌停潮出现
2. 无新题材分流，主线资金出逃
3. 老龙头连续大跌
4. 跟风股批量跌停
5. 缩量一字板后首次开板
6. 爆量滞涨/多次炸板不回封
7. 跌破5日均线
8. 连续加速后高位放量大阴线

**卖点优先级**：周期结束卖点 > 龙头自身卖点 > 盈亏比/时间节点卖点

### 11.7 盘面推理能力训练方法

**五维市场理解**：
1. **预期理解**：理解市场博弈的预期、阶段、核心
2. **板块联动**：理解个股联动、资金流入流出变化、资金迁移方向
3. **逻辑外推**：结合盘面和信息面，客观推理，不主观臆测
4. **级别判断**：公司/行业/中美全球共振三个维度，决定核心高度
5. **行为揣摩**：理解交易者心态，决定策略调整

**题材五主体视角**：
1. 专业媒体机构视角
2. 交易圈子视角
3. 卖方机构视角
4. 产业玩家视角
5. 股民视角

**时间维度三问**：
1. 市场建立的是什么预期？
2. 什么预期会改变二级市场的观点？
3. 未来会发生什么事件，关键催化点有哪些？

### 11.8 涨价题材专项预判技巧

**涨价题材炒作三步法**：
1. **判断驱动力度**
   - 需求拐点：业绩爆发增长，推动力最强
   - 产业格局：产能缺口、利润持续兑现
   - 情绪资金：决定短期爆发力

2. **选股只选最纯**
   - 有色：选资源储量最大的
   - 化工：选产量/业绩弹性最大的龙头
   - 原材料：选产能集中、不可替代的

3. **死盯产品价格**
   - 常用平台：上海有色网、生意社、卓创资讯、百川盈孚
   - 价格是核心，涨则板块动，跌则股价快跌

**涨价题材核心规律**：
- 供需缺口+价格可监测+业绩兑现快三要素缺一不可
- 行情见顶信号：政策转向、需求证伪、流动性收紧
- 风控铁律：高位破位就止损；行业疯狂扩产必小心

**涨价行情三阶段**：
- 预期驱动（行情初期）
- 现实数据落地（行情中期）
- 库存消耗/价格冲顶（行情后期）

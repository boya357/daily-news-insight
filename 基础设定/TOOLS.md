# 工具使用指南

## 核心脚本
- **simple_push.py**：企业微信推送（`python3 simple_push.py "标题" "URL"`）
- **md_to_html.py**：Markdown转HTML

## 推理模型（IMPS×TVRC）
| IMPS | 预期涨幅 | 节奏 |
|------|----------|------|
| I-5 | +50-200% | 涨价型1-5天 |
| I-4 | +25-100% | 技术型5-15天 |
| I-3 | +15-50% | 政策型3-10天 |

**关键规则**：T+0不追脉冲、T+3~T+5龙头生死窗口、二板定龙头、不买3-4板中位股

## ⚠️ 数据验证铁律
**任何数据必须反复验证后才能写入报告，绝对不能凭记忆或未经核实直接引用！**

- **GitHub Pages**：`https://boya357.github.io/daily-news-insight/{分类}/{日期}.html`

## 日报生成规范

### 新UI设计规范
**沉浸光影风格**：
- 紫色渐变背景：`linear-gradient(135deg, #667eea 0%, #764ba2 100%)`
- 大图标+脉冲动画、深阴影
- **列表页**：简洁卡片式，浅色背景+毛玻璃导航栏

### 深度广度标准

**S级催化必须包含：**
1. 催化来源（具体出处和日期）
2. 量化数据（市场规模、份额、价格弹性）
3. 竞争格局（龙头/跟随者/替代品对比）
4. A股映射（≥5只核心标的，含业务关联度、受益逻辑、弹性测算）
5. IMPS强度评估
6. TVRC节奏（催化窗口期、爆发期、消退期）
7. 产业链全景（上中下游受益环节）

**必选数据板块：** 指数涨跌（A股+美股）、板块资金流向、外资动向、持仓标的跟踪

### 自动更新机制
生成日报后**必须**更新对应的latest.html列表页

## 明日催化剂报告规范

### IMPS评级标准
| 级别 | IMPS值 | 说明 |
|------|--------|------|
| S级 | ≥15 | 重大催化，重点关注 |
| A级 | 8-15 | 重要催化，建议关注 |
| B级 | 3-8 | 一般催化 |
| C级 | <3 | 小幅催化 |

### 完整度标准
- ✅ 利好催化 + **利空催化**（不能只有利好！）
- ✅ 核心标的表格（含代码、评级、逻辑）
- ✅ 盘面回顾数据 + 明确操作建议

### 配色
- 背景：`#f8fafc`，卡片：`#ffffff`（浅色清新）

## Git同步流程（2026-05-21确认）

**⚠️ GitHub Pages从main分支的docs/目录部署！**

**工作目录**：`cd /app/data/所有对话/主对话`

**推送流程**：
```bash
git add docs/目标目录/
git commit -m "说明"
git push origin main
```

**⚠️ 安全检查**：
1. 操作前必须 `pwd` 确认在正确目录
2. 确认 `docs/` 目录存在
3. 确认 `latest.html` 是列表页（不是内容页）
4. 只 `git add` 要修改的目录，绝不 `git add -A` 全量
5. **禁止在MEMORY.md中存储GitHub Token明文**

## 错误教训库
| 日期 | 问题 | 教训 |
|------|------|------|
| 2026-05-24 | 周末速递只有企业微信推送，没有网页版 | 用户反馈后才创建网页版。**所有报告类型（每日/盘中/盘后/周末速递）必须同时生成网页版并推送给用户** |
| 2026-05-23 | HTML表格在小屏幕上溢出页面 | 表格列数较多时未设置响应式样式 | 必须添加`.card { overflow-x: auto }`和表格`word-wrap: break-word` |
| 2026-05-23 | *ST建艺止损位显示为"摘星预期" | 日程任务自动更新仪表盘时，数据字段映射错误 | 生成报告前必须检查HTML结构，确认每个字段正确显示 |
| 2026-05-23 | 日程rrule.byday不包含dtstart导致创建失败 | dtstart必须是rrule.byday中的一个日期 |
| 2026-05-22 | 日程任务自动添加川润股份到持仓 | **严禁自动添加标的**，只使用USER.md明确列出的持仓 |
| 2026-05-22 | Webhook URL环境变量未设置 | Webhook URL必须写死到脚本中，不能依赖环境变量 |
| 2026-05-22 | 推送格式为markdown | 必须使用news卡片格式 |
| 2026-05-22 | latest.html是跳转页而非列表页 | latest.html必须是列表页，显示所有历史报告 |
| 2026-05-21 | 废弃子目录干扰 | 操作前必须 `pwd` + `ls docs/` |
| 2026-05-21 | 用内容页覆盖 `latest.html` | `latest.html` 永远是列表页 |
| 2026-05-21 | GitHub检测Token明文拒绝推送 | 禁止在文本文件存Token |
| 2026-05-20 | HTML表格溢出 | 必须加`overflow-x: auto` |

## 日历任务更新规则
- 有range_rule的任务：更新时必须同时提供`time_range`和`dtstart`
- 重复日程：只改dtstart不会改变后续实例时间，需同时提供新rrule

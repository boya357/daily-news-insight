# markdown-it H标签正则替换避坑经验

## 问题现象
使用markdown-it渲染Markdown得到HTML后，用贪婪正则批量给所有h1-h6标签添加class属性时，会导致所有闭合标签`</h2>`/`</h3>`等全部被清空，渲染后标题结构完全破坏。

## 根因
正则`re.sub(r'<h2>(.*?)</h2>', ..., html, flags=re.S)`的贪婪模式会一次性匹配从第一个`<h2>`到最后一个`</h2>`的全部内容，导致所有中间的闭合标签被替换删除。

## 修复方案
改用逐次匹配的遍历方式处理：先把所有标签匹配结果全部提取出来，逐个替换，不要使用单行全局正则替换，即可完全避免该问题。

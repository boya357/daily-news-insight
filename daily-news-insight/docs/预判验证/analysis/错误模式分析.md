# 错误模式分析

## 概述
记录预判失败原因，识别重复犯错模式。

---

## 已识别错误模式

### 模式 #1：时机偏差
- **描述**：时间窗口过短，被短期波动干扰
- **教训**：S级催化需要更长发酵时间

### 模式 #2：幅度高估
- **描述**：预期涨幅过大
- **教训**：理性评估，合理预期

### 模式 #3：产业链遗漏
- **描述**：只关注龙头，忽视上下游联动
- **教训**：建立完整产业链标的池

### 模式 #4：忽视量能
- **描述**：忽略资金配合
- **教训**：量价配合是核心

### 模式 #5：概念混淆
- **描述**：把消息当实质催化
- **教训**：区分事件与实质利好

---

## 预判前必查清单

1. ✅ 是否有实质利好（非单纯消息）
2. ✅ 资金是否配合
3. ✅ 时间窗口是否充足
4. ✅ 产业链联动逻辑是否清晰
5. ✅ 是否有潜在利空对冲

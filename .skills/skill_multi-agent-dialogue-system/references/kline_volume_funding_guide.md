## 模块概述

### 为什么需要这个模块？

游资短线分析的核心是**量价时空**四个维度，其中：
- **K线形态**：判断趋势、支撑压力、突破确认
- **量价关系**：验证趋势健康度、识别背离信号
- **资金博弈**：洞察主力意图、判断筹码稳定性

这三个维度结合起来，才能形成完整的技术面分析体系。

### 模块位置

在回答专家的输出中，这个模块位于：
- **情绪周期判断** 之后
- **技术面分析** 之前

## K线形态分析

### 分析维度

| 技术指标 | 说明 | 判断标准 |
|:--------:|------|----------|
| 🔍 趋势强弱 | 判断当前趋势方向和强度 | 🟢 上升趋势 / 🟡 震荡 / 🔴 下降趋势 |
| 🎯 突破/回踩 | 是否突破关键位或回踩确认 | 🟢 已突破 / 🟡 回踩中 / 🔴 未突破 |
| 📊 支撑压力 | 关键支撑位和压力位 | 🟢 支撑有效 / 🟡 中等 / 🔴 支撑失效 |
| 📐 均线结构 | 均线排列情况 | 🟢 多头排列 / 🟡 粘合 / 🔴 空头排列 |

### 详细说明

#### 1. 趋势强弱
- **判断依据**：
  - 近期高点和低点是否逐步抬高（上升趋势）
  - 均线方向（5日、10日、20日、30日）
  - 股价相对位置（相对前期高点/低点）
- **示例描述**：
  - "上升趋势，3连板确立强势地位，短期多头趋势明确"
  - "震荡趋势，在10-12元区间横盘整理，方向待选择"

#### 2. 突破/回踩
- **判断依据**：
  - 是否突破前期高点、平台整理、重要均线
  - 突破时是否放量
  - 回踩时是否守住关键位
- **示例描述**：
  - "已突破前期高点12.5元，当前处于突破后加速阶段"
  - "回踩确认中，考验10元支撑位有效性"

#### 3. 支撑压力
- **判断依据**：
  - 前期高点/低点
  - 重要均线（5日、10日、20日、30日、60日）
  - 平台整理区域
  - 缺口位置
- **示例描述**：
  - "支撑位：11.8元（5日线），压力位：15元（前高套牢区）"
  - "强支撑在10元（30日线），压力在12.5元（前期平台）"

#### 4. 均线结构
- **判断依据**：
  - 均线排列顺序（多头：5日&gt;10日&gt;20日&gt;30日）
  - 均线方向（向上/向下/走平）
  - 均线间距（发散/粘合）
- **示例描述**：
  - "5日、10日、20日均线呈多头排列，30日线向上拐头"
  - "均线粘合，方向待选择，等待突破信号"

## 量价关系分析

### 分析维度

| 量价指标 | 说明 | 判断标准 |
|:--------:|------|----------|
| 🔥 放量/缩量 | 成交量变化情况 | 🟢 放量健康 / 🟡 正常 / 🔴 异常放量 |
| 📈 量增价涨 | 量价配合情况 | 🟢 健康 / 🟡 一般 / 🔴 不配合 |
| ⚠️ 量价背离 | 是否出现背离 | 🟢 无背离 / 🟡 潜在背离 / 🔴 明显背离 |
| 🔄 换手健康度 | 换手率是否合理 | 🟢 健康 / 🟡 偏高 / 🔴 过高 |

### 详细说明

#### 1. 放量/缩量
- **判断依据**：
  - 相比昨日成交量变化幅度（&gt;30%为明显放量）
  - 相比5日平均成交量变化
  - 涨停板的放量/缩量意义不同
- **示例描述**：
  - "今日成交量较昨日放大35%，换手28%，属于放量涨停"
  - "缩量上涨，量能较昨日减少20%，需警惕"

#### 2. 量增价涨
- **判断依据**：
  - 价格上涨时成交量是否同步放大
  - 价格下跌时成交量是否萎缩
  - 量价配合的健康度
- **示例描述**：
  - "量增价涨，量价配合良好，资金入场明显"
  - "量缩价涨，量价背离，需警惕回调风险"

#### 3. 量价背离
- **判断依据**：
  - **顶背离**：价格创新高，成交量未创新高
  - **底背离**：价格创新低，成交量未创新低
  - 背离的级别（15分钟/30分钟/60分钟/日线）
- **示例描述**：
  - "暂无明显量价背离，趋势健康"
  - "出现顶背离信号，价格新高但量能未跟进"

#### 4. 换手健康度
- **判断依据**：
  - 换手率区间：
    - &lt;5%：过低，交投清淡
    - 5%-15%：正常，健康
    - 15%-30%：偏高，活跃
    - &gt;30%：过高，需警惕
  - 结合股价位置判断（高位/低位）
- **示例描述**：
  - "换手率28%，处于偏高区间，需警惕资金分歧"
  - "换手率12%，处于健康区间，量价配合良好"

## 资金博弈分析

### 分析维度

| 资金维度 | 说明 | 判断标准 |
|:--------:|------|----------|
| 🏛️ 主力资金动向 | 主力资金流入流出 | 🟢 净流入 / 🟡 中性 / 🔴 净流出 |
| 🎯 筹码结构 | 筹码分布情况 | 🟢 集中 / 🟡 分散 / 🔴 混乱 |
| 📉 抛压与承接 | 抛压承接力量对比 | 🟢 承接强 / 🟡 中等 / 🔴 抛压大 |
| 🔗 板块联动 | 板块效应强弱 | 🟢 强 / 🟡 中等 / 🔴 弱 |

### 详细说明

#### 1. 主力资金动向
- **判断依据**：
  - 主力资金净流入/净流出金额
  - 大单买入/卖出情况
  - 主力资金连续流入天数
- **示例描述**：
  - "主力资金净流入2.8亿，大单买入明显，主力做多意图明确"
  - "主力资金净流出1.5亿，大单卖出较多，需警惕"

#### 2. 筹码结构
- **判断依据**：
  - 筹码集中度（高位/低位）
  - 关键价位的筹码分布
  - 套牢盘/获利盘比例
- **示例描述**：
  - "筹码相对分散，12-13元区间有一定套牢盘，需消化"
  - "筹码高度集中在10-11元区间，拉升压力小"

#### 3. 抛压与承接
- **判断依据**：
  - 上档抛压（卖一至卖五）
  - 下档承接（买一至买五）
  - 盘中大单砸盘/接盘情况
  - 撤单情况
- **示例描述**：
  - "抛压约35%，承接约65%，承接力量较强但抛压也不小"
  - "抛压沉重，承接不足，需等待抛压释放"

#### 4. 板块联动
- **判断依据**：
  - 板块内其他股票表现
  - 龙头股对板块的带动效应
  - 板块整体涨跌幅
  - 板块资金流向
- **示例描述**：
  - "影视板块联动效应较强，万达电影、光线传媒等跟风上涨"
  - "板块效应较弱，只有个股行情，持续性存疑"

## 使用要点

1. **必须结合【🔥 当下最热资讯】**：所有分析都要结合搜索到的最新资讯
2. **数据要具体**：换手率、主力资金金额、支撑压力位等都要有具体数据
3. **逻辑要清晰**：每个表格后面都要有2-3句话的深度分析
4. **状态要准确**：🟢/🟡/🔴的判断要符合实际情况
5. **位置要正确**：这个模块位于情绪周期判断之后，技术面分析之前
6. **⚠️ 词汇调整要求**：
   - "操作建议" → **"操作策略分析"**
   - "明确建议" → **"策略分析"**
   - "操作时机" → **"观察窗口"**
   - "打板" → **"涨停关注"**
   - "低吸" → **"回落关注"**
   - "追高" → **"冲高关注"**
   - "推荐" → **"值得关注"**
   - "不推荐" → **"谨慎关注"**
   - "成功概率" → **"市场认可度"**

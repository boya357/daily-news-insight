## 核心概念

### 什么是游资
游资是指在股市中进行短线投机的资金，通常由大户、私募、机构等组成。游资的特点是：
- **快速进出**：持仓时间短，通常1-3天
- **追逐热点**：紧跟市场最热题材和龙头股
- **高杠杆**：使用融资融券等工具放大收益
- **快进快出**：不恋战，见好就收

### 短线操作原则
1. **紧跟龙头**：只做龙头股，不做跟风股
2. **题材为王**：选择市场最热的题材
3. **情绪先行**：把握市场情绪周期
4. **资金流向**：关注龙虎榜和主力资金动向
5. **快速止损**：严格执行止损纪律

## 市场情绪周期

### 冰点期（启动前）
- **特征**：涨停家数少于20家，跌停家数较多
- **操作**：空仓观望，等待机会
- **机会**：寻找逆势抗跌的个股，准备埋伏

### 启动期（发酵中）
- **特征**：涨停家数20-30家，出现新题材
- **操作**：小仓位试错，关注龙头
- **机会**：介入新题材龙头，打板确认

### 高潮期（高潮中）
- **特征**：涨停家数30-50家，题材全面爆发
- **操作**：重仓出击，追涨龙头
- **机会**：龙头连板，补涨股跟进

### 分化期（分化中）
- **特征**：涨停家数30-50家，但板块分化严重
- **操作**：降低仓位，聚焦核心
- **机会**：龙头继续，跟风股分化

### 退潮期（衰退中）
- **特征**：涨停家数少于30家，龙头炸板
- **操作**：清仓观望，锁定利润
- **风险**：高位股补跌，炸板潮

## 操作策略

### 打板（追涨停）
- **适用场景**：龙头股首次涨停，题材确认
- **操作要点**：
  - 在涨停价买入，确保能够成交
  - 关注封单量和换手率
  - 确认龙头地位（涨停时间最早、封单最大）
- **成功率**：60-70%
- **风险**：炸板（涨停后打开）

### 低吸（回调买入）
- **适用场景**：龙头股回调，5日线或10日线支撑
- **操作要点**：
  - 等待回调到支撑位（5日、10日、20日线）
  - 观察成交量是否萎缩
  - 确认题材未退潮
- **成功率**：50-60%
- **风险**：继续下跌，破位

### 追高（追涨买入）
- **适用场景**：龙头股加速上涨，突破前高
- **操作要点**：
  - 确认龙头已经确立
  - 观察成交量和换手率
  - 避免高位接盘
- **成功率**：40-50%
- **风险**：高位被套

### 反包（反弹买入）
- **适用场景**：龙头股跌停后次日反弹
- **操作要点**：
  - 确认题材未退潮
  - 观察次日竞价和开盘
  - 确认资金回流
- **成功率**：30-40%
- **风险**：继续下跌

### 核按钮（跌停卖出）
- **适用场景**：龙头股跌停，题材退潮
- **操作要点**：
  - 严格执行止损纪律
  - 在跌停价卖出
  - 不抱幻想，果断离场
- **成功率**：100%（止损）
- **风险**：错过反弹（但规避更大风险）

## 风险控制

### 止损纪律
1. **亏损5%**：减仓50%
2. **亏损8%**：清仓离场
3. **跌破5日线**：减仓50%
4. **跌破10日线**：清仓离场

### 仓位管理
- **冰点期**：空仓或10%以下
- **启动期**：20-30%仓位
- **高潮期**：50-80%仓位
- **分化期**：30-50%仓位
- **退潮期**：10%以下或空仓

### 避免错误
1. **不追高接盘**：避免在高位追涨
2. **不抄底**：不盲目抄底跌停股
3. **不重仓单股**：单股仓位不超过30%
4. **不满仓操作**：始终保持20%现金
5. **不恋战**：快进快出，不恋战

## 游资术语词典

### 连板相关
- **连板**：连续涨停
- **龙头**：连板高度最高、最先涨停的股票
- **梯队**：同一题材中不同连板高度的股票群体
- **补涨**：题材扩散后，跟涨的股票
- **卡位**：后来居上，取代龙头地位

### 资金相关
- **龙虎榜**：每日资金交易明细，显示买入卖出前五名席位
- **游资**：进行短线投机的资金
- **主力**：机构、大户等大资金
- **席位**：券商营业部或机构名称
- **封单**：涨停价上的买单

### 情绪相关
- **情绪**：市场整体热度和情绪状态
- **冰点**：市场情绪最低迷时
- **高潮**：市场情绪最高涨时
- **分化**：市场情绪分化，个股表现不一
- **退潮**：题材炒作结束，情绪回落

### 操作相关
- **打板**：在涨停价买入
- **炸板**：涨停后打开
- **低吸**：回调到支撑位买入
- **追高**：在上涨过程中追涨买入
- **反包**：跌停后次日反弹
- **核按钮**：跌停价卖出
- **割肉**：亏损卖出
- **锁仓**：持有股票不卖出

### 技术相关
- **5日线**：5日移动平均线，短期支撑位
- **10日线**：10日移动平均线，中期支撑位
- **20日线**：20日移动平均线，长期支撑位
- **换手率**：成交量/流通股本，反映交易活跃度
- **涨停家数**：当日涨停股票数量

### 市场相关
- **题材**：具有共同概念或主题的股票群体
- **概念**：市场炒作的主题或热点
- **热点**：市场最关注的题材
- **板块**：同一行业的股票群体

## 每日操作流程

### 早盘（9:30-10:00）
1. **观察集合竞价**：看哪些股票高开
2. **确认龙头**：最先涨停的股票
3. **判断情绪**：涨停家数和跌停家数
4. **决定操作**：是否打板龙头

### 盘中（10:00-14:30）
1. **监控盘面**：观察涨停板数量
2. **关注资金**：龙虎榜实时数据
3. **调整仓位**：根据市场情绪调整
4. **寻找机会**：补涨股机会

### 尾盘（14:30-15:00）
1. **回顾全天**：总结今日表现
2. **准备次日**：预测明日机会
3. **制定计划**：次日操作策略
4. **复盘记录**：记录操作和感悟

## 常见错误

### 错误1：追高被套
- **表现**：在龙头股高位追涨买入
- **原因**：贪婪，忽视风险
- **对策**：严格执行止损纪律

### 错误2：抄底失败
- **表现**：在跌停股抄底
- **原因**：抄底心理，希望反弹
- **对策**：不抄底，等待确认

### 错误3：满仓操作
- **表现**：全仓买入一只股票
- **原因**：贪婪，希望最大化收益
- **对策**：分散仓位，单股不超过30%

### 错误4：不止损
- **表现**：亏损后不止损，死扛
- **原因**：不愿承认错误，心存幻想
- **对策**：严格执行止损纪律

### 错误5：恋战不撤
- **表现**：赚钱后不愿卖出，继续持有
- **原因**：贪婪，希望赚更多
- **对策**：快进快出，不恋战

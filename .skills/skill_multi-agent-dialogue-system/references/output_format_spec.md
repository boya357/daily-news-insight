## 提问者格式

### 整体结构

```
---

🔥 核心问题
[你的核心问题，1-2句话]

📊 关键关注点
• [关注点1]
• [关注点2]
• [关注点3]
• [关注点4]
• [关注点5]

💡 思考逻辑
1. [思考1]
2. [思考2]
3. [思考3]
4. [思考4]
5. [思考5]

⚠️ 风险提示
• [风险1]
• [风险2]
• [风险3]
---
```

### 详细说明

#### 🔥 核心问题
- **位置**：开头
- **格式**：标题 + 内容
- **长度**：1-2句话
- **要求**：直击核心，提出最关键的问题

#### 📊 关键关注点
- **位置**：核心问题之后
- **格式**：标题 + 项目符号列表
- **数量**：4-6个
- **内容**：涵盖题材、连板、资金、情绪、操作等维度

#### 💡 思考逻辑
- **位置**：关键关注点之后
- **格式**：标题 + 编号列表
- **数量**：4-6个
- **内容**：深度思考的问题，引导后续分析

#### ⚠️ 风险提示
- **位置**：最后
- **格式**：标题 + 项目符号列表
- **数量**：3-4个
- **内容**：需要警惕的风险点

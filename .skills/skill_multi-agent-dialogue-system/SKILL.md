# 多Agent对话系统

## 任务目标
- 本Skill用于：通过三个专业化角色（提问者、回答专家、总结者）的协作，生成高质量、结构化的游资短线分析报告
- 能力包含：题材分析、连板梯队、情绪周期判断、技术面分析、资金面解读、操作建议、风险控制
- 触发条件：用户需要分析股票、题材、龙虎榜，或进行短线交易决策时

## 前置准备
无特殊前置准备，直接使用即可。

## 操作步骤
- 标准流程：
  0. **强制联网搜索（第一步！）**：在开始任何分析之前，**必须先进行联网搜索**！
     - 搜索内容：当前分析对象的最新新闻、资讯热度、市场反应、相关数据、最新股价走势
     - **重点识别**：个股当前是否涨停？当前连板高度？最近几天的走势？
     - 搜索关键词：[股票名/题材名] + "最新消息"、"新闻"、"热度"、"数据"、"龙虎榜"、"股价走势"
     - 搜索时间范围：最近3天内的最新信息
     - **重要**：没有搜索数据，不要开始分析！所有分析必须基于搜索到的客观事实，避免主观臆断
  0.5 **专门搜索最新相关资讯（第二步！）**：在完成第一步搜索后，**必须再开启一个专门搜索最新相关资讯的动作**！
     - 搜索内容：专门搜索与分析对象相关的最新资讯、新闻报道、行业动态、**催化因素**、**为什么连板**、**为什么上涨**
     - 搜索关键词：
       - [股票名/题材名] + "最新资讯"、"相关新闻"、"行业动态"、"市场分析"
       - **新增关键词**：[股票名/题材名] + "催化因素"、"为什么连板"、"为什么上涨"、"上涨原因"、"涨停原因"
       - **连板梯队搜索**：[板块名/题材名] + "连板梯队"、"龙头股"、"概念股"、"相关股票"
     - 搜索时间范围：最近1-7天内的资讯（催化因素可能需要更长时间范围）
     - **资讯筛选**：专门找关联度最高、最有价值的资讯，**特别关注催化因素和上涨原因**，固定收集5条最佳资讯
     - **重要**：这是独立于第一步的第二次搜索动作！专门用于找到催化因素和连板原因！
  1. **提问者**：首先阅读 [references/example_output.md](references/example_output.md) 中的【提问者】示例，然后按照该格式输出提问内容
     - 包含：🔥 核心问题、📊 关键关注点、💡 思考逻辑、⚠️ 风险提示
     - 参考 [references/output_format_spec.md](references/output_format_spec.md) 中的格式规范
     - **必须基于搜索到的最新信息**提出问题
  2. **回答专家**：阅读 [references/example_output.md](references/example_output.md) 中的【回答专家】示例，然后**根据个股实际状态**输出完整分析
     - **关键判断**：根据搜索结果判断个股当前是否涨停？如果是涨停票，包含打板相关分析；如果是非涨停票，调整操作建议内容
     - **⚠️ 词汇调整要求（强制执行！）**：
       - "操作建议" → **"操作策略分析"**
       - "明确建议" → **"策略分析"**
       - "操作时机" → **"观察窗口"**
       - "打板" → **"涨停关注"**
       - "低吸" → **"回落关注"**
       - "追高" → **"冲高关注"**
       - "推荐" → **"值得关注"**
       - "不推荐" → **"谨慎关注"**
       - "成功概率" → **"市场认可度"**
     - **⚠️ 连板梯队表述修正（强制执行！）**：
       - 只有2板及以上才能叫"连板"
       - 1板的叫"首板"或"涨停"，绝对不能叫"连板"！
       - 表格表头用"涨停高度"而不是"连板高度"
     - **催化因素重点要求**：在【热点题材分析】的【催化因素】部分，**必须明确说明"为什么上涨"、"为什么连板"的具体原因**，这些原因必须来自搜索到的新闻和资讯！
     - **连板梯队重点要求**：在【连板梯队分析】部分，**必须基于搜索到的资讯**，完整列出整个板块的连板梯队，**不能疏漏**！要说明每个股票为什么在梯队中！
       - **表述修正**：只有2板及以上才能叫"连板"，首板的叫"首板"或"涨停"，不要叫"连板"
     - **新增要求**：在【热点题材分析】下面，新增【🔥 当下最热资讯】部分，固定输出5条关联度最高、最有价值的资讯，杂毛资讯不要
     - **表格格式要求**：【🔥 当下最热资讯】表格必须包含以下列：序号、热度、资讯标题、来源、时间、关联度、**对信息的整理分析**（新增列！）
     - **⚠️ 新增通用模块【K线与量价资金博弈分析】（必须包含！强制执行！绝对不能省略！）**：
       - **位置**：位于【情绪周期判断】之后，【技术面分析】之前
       - **必须包含三个子模块，每个子模块都要有表格 + 引用块逻辑说明**：
         1. **K线形态**：趋势强弱、突破/回踩、支撑压力、均线结构
         2. **量价关系**：放量/缩量、量增价涨、量价背离、换手健康度
         3. **资金博弈**：主力资金动向、筹码结构、抛压与承接、板块联动对资金的影响
       - **每个子模块都要有表格 + 引用块逻辑说明！**
       - **详细参考**：[references/kline_volume_funding_guide.md](references/kline_volume_funding_guide.md)
     - 包含：多维度分析（题材、连板、情绪、**K线与量价资金博弈**、技术、资金）、**操作策略分析**、风险控制
     - 每个维度都要有表格、引用块、进度条等结构化内容
     - 参考 [references/trading_knowledge_base.md](references/trading_knowledge_base.md) 中的专业知识
     - **所有分析必须引用搜索到的具体数据和新闻**，避免主观分析
  3. **总结者**：最后阅读 [references/example_output.md](references/example_output.md) 中的【总结者】示例，输出最终总结
     - 包含：核心观点一句话总结、维度覆盖检查、题材与情绪分析、技术与资金分析、连板梯队、操作建议总结、风险控制、数据来源验证、最终结论
     - 是对回答专家内容的提炼和升华
     - **数据来源必须明确标注搜索到的来源和时间**
     - **总结者也需要根据个股实际状态调整内容**，不要包含不符合实际状态的建议

- 注意事项：
  - **⚠️ 个股状态判断（强制执行）**：
    - **涨停票**：如果个股当前涨停，操作建议可以包含打板、连板高度等内容
    - **非涨停票**：如果个股没有涨停，**必须**调整操作建议，不要包含打板、连板高度等不相关内容，改为低吸、追涨、波段等建议
  - 始终严格遵循 [references/example_output.md](references/example_output.md) 中的输出格式
  - 使用 [references/output_format_spec.md](references/output_format_spec.md) 中的格式规范
  - 内容质量要达到示例中的专业水平
  - 智能体直接生成所有内容，不需要调用脚本

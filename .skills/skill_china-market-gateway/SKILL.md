# 中国金融市场数据网关

## 何时使用本技能

当需要以下操作时使用本技能：

- **股票数据**：查询A股（沪深交易所）或港股实时价格、历史行情
- **基金信息**：获取基金净值、估值、基金经理等详细信息
- **宏观数据**：查询GDP、CPI、PPI、PMI等经济指标
- **财经资讯**：搜索特定公司或行业的最新新闻
- **市场分析**：需要中国资本市场的基础数据支持

**典型触发场景**：
- "帮我查一下贵州茅台今天的股价"
- "最近CPI数据是多少"
- "腾讯在港股的表现如何"
- "有没有关于新能源汽车行业的最新消息"

## 核心功能概览

本技能通过 Python 程序访问多个中国金融数据源，提供统一的数据获取接口：

| 数据类型 | 数据源 | 覆盖范围 |
|---------|--------|---------|
| 股票行情 | 新浪财经、腾讯财经、东方财富 | A股、港股、指数 |
| 基金数据 | 天天基金网 (东方财富) | 公募基金净值、估值 |
| 经济指标 | 东方财富数据中心 | GDP、CPI、PPI、PMI |
| 财经新闻 | 财联社 (CLS) | 市场快讯、行业新闻 |
| 股票分析 | 百度股市通 | 个股分析页面 |

## 股票代码格式

中国市场使用特定的股票代码前缀：

- **沪市A股**：`sh` + 6位数字（如 `sh600519` 贵州茅台）
- **深市A股**：`sz` + 6位数字（如 `sz000001` 平安银行）
- **港股**：`hk` + 5位数字（如 `hk00700` 腾讯控股）

### 常用股票代码示例

| 公司名称 | A股代码 | 港股代码 | 行业 |
|---------|---------|---------|------|
| 贵州茅台 | sh600519 | - | 白酒 |
| 腾讯控股 | - | hk00700 | 互联网 |
| 阿里巴巴 | sh688988 | hk09988 | 电商 |
| 美团 | - | hk03690 | 本地生活 |
| 中国平安 | sh601318 | hk02318 | 保险 |
| 比亚迪 | sz002594 | hk01211 | 新能源汽车 |

**重要提示**：
- 港股代码必须是5位数字，不足需补零（如 `700` → `hk00700`）
- 部分公司同时在A股和港股上市，代码不同但对应同一家公司

## 常见问题处理

### 数据返回为空

如果股票代码查询无数据，可能原因：

1. **格式错误**：港股代码不足5位（使用 `hk00700` 而非 `hk700`）
2. **股票停牌**：当日未交易
3. **代码失效**：股票已退市或更名
4. **网络限制**：境外访问受限，需配置代理

参考故障排查指南：
```
阅读 references/troubleshooting.md
```

### 代理配置

境外访问中国金融网站时，建议配置代理：

```python
data = YuanData(proxy="http://your-proxy:port")
```

### 时区与交易时间

- **时区**：中国标准时间 (UTC+8)
- **交易时间**：
  - 上午：9:30 - 11:30
  - 下午：13:00 - 15:00
  - 午间休市：11:30 - 13:00

**提示**：在非交易时间查询，得到的是最近一个交易日的收盘数据。

## 注意事项

1. **数据时效性**：实时行情有1-3分钟延迟，非交易时间显示收盘价
2. **访问频率**：避免短时间内大量请求，建议每次请求间隔0.1-0.5秒
3. **数据准确性**：数据来自公开网站爬取，仅供参考，不构成投资建议
4. **货币单位**：A股价格单位为人民币(CNY)，港股为港币(HKD)
5. **合规使用**：遵守数据源网站的使用条款，仅用于个人研究学习

# 基金数据API参考

## 数据源

**天天基金网**（东方财富旗下）- 中国最大的基金销售平台

- 数据更新频率：交易日盘中每1分钟更新估值
- 官方净值：每日收盘后更新（通常晚上8点左右）

## 基本用法

```python
from scripts.yuan_data import get_fund_nav

# 查询基金净值
fund = get_fund_nav("161039")
print(f"{fund['name']}")
print(f"单位净值: {fund['nav']} ({fund['nav_date']})")
print(f"估算净值: {fund['estimated_nav']}")
print(f"估算增长: {fund['growth_rate']:.2f}%")
```

## 返回数据字段

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| `code` | str | 基金代码 | "161039" |
| `name` | str | 基金名称 | "富国沪港深价值精选混合" |
| `nav` | float | 单位净值 | 1.8250 |
| `nav_date` | str | 净值日期 | "2026-02-11" |
| `estimated_nav` | float | 估算净值 | 1.8320 |
| `estimated_time` | str | 估值时间 | "2026-02-12 14:30" |
| `growth_rate` | float | 估算增长率(%) | 0.38 |

## 数据说明

### 单位净值 (NAV)

- 基金公司每日收盘后计算的官方净值
- T日净值通常在T日晚间公布
- 作为申购赎回的基准价格

### 估算净值

- 盘中根据持仓股票实时计算
- **仅供参考**，不作为交易价格
- 仓位透明的指数基金估值较准确
- 主动管理基金由于持仓不透明估值误差较大

## 高级用法

### 批量查询多只基金

```python
from scripts.yuan_data import YuanData
import time

data = YuanData()
fund_codes = ["161039", "110022", "161725"]

for code in fund_codes:
    fund = data.fund.get_quote(code)
    if fund:
        print(f"{fund['name']}: {fund['nav']} ({fund['growth_rate']:+.2f}%)")
    time.sleep(0.2)
```

### 判断基金涨跌

```python
fund = get_fund_nav("161039")
if fund:
    if fund['growth_rate'] > 0:
        print(f"📈 今日预计上涨 {fund['growth_rate']:.2f}%")
    elif fund['growth_rate'] < 0:
        print(f"📉 今日预计下跌 {fund['growth_rate']:.2f}%")
    else:
        print("持平")
```

## 错误处理

```python
fund = get_fund_nav("999999")  # 无效代码
if fund is None:
    print("基金不存在或查询失败")
```

可能原因：
1. 基金代码错误
2. 基金已清盘
3. 网络连接问题
4. 数据源接口变更

## 注意事项

1. **估值时效性**：
   - 交易时间内（9:30-15:00）：估值每分钟更新
   - 非交易时间：显示上一交易日净值

2. **QDII基金**：
   - 投资海外市场的基金
   - T+2日才公布净值（比普通基金延迟一天）
   - 估值参考价值较低

3. **净值更新时间**：
   - 大部分基金：当日20:00左右
   - 部分基金：次日早晨更新
   - QDII基金：T+2日

4. **节假日**：
   - 周末及法定节假日不更新
   - 港股通基金在港股休市时可能不更新

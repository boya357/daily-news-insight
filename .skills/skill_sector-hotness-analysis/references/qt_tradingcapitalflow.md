# 股票交易资金流向（qt_tradingcapitalflow）

## 表基本信息


- **数据更新频率**：日更新
- **业务唯一性字段**：innercode、TradingDate、QuoteType、ValueRange

## 业务说明

### 数据定义
展示每个交易日在深沪交易所交易的股票，在不同单笔成交金额区间的累计主买、主卖金额及成交量情况。

#### 核心概念
- **流入量（金额）**：主动买成交，即在买盘上成交的外盘成交量（金额）
- **流出量（金额）**：主动卖成交，即在卖盘上成交的内盘成交量（金额）

### 数据范围与来源
- **数据范围**：2008-09 起至今
- **信息来源**：基于交易所行情数据衍生计算
- **说明**：本数据仅包括二级市场股票交易产生的资金流向数据，不含大宗交易产生的资金流向；大宗交易资金流向数据可参考"股东股权变动（LC_ShareTransfer）"表（TranMode = '11'）

## 字段备注说明

### 注1：内部编码（innercode）
与"证券主表（SecuMain）"中的"证券内部编码（innercode）"关联，得到证券的交易代码、简称等。

### 注2：行情类别（QuoteType）
该字段固定以下常量：
- `1` - Level1行情

### 注3：单笔成交金额区间（ValueRange）
该字段固定以下常量：
- `1` - [0, 5w]
- `2` - [5w, 30w]
- `3` - [30w, 100w]
- `4` - [100w, +∞)

# 第三步：梳理政策时间线

1. 使用搜索工具，详细地分步骤搜索以下信息并梳理政策的时间线：
- 中央相关主管单位出具意见征求稿或者思路文件
- 地方政府出具的试点方案政策等
- 中央重要经济工作会议和规划会议文件当中的提及情况
- 偏向落地性的政策文件：与预算和资金挂钩的政策文件，包括中央和地方。
- 近期是否会有即将发生的相关的会议能提出与该板块有关的政策？
2. 基于以上内容，梳理政策的完整时间线，并重点分析相关政策的可落地程度：
- 完整时间线
- 政策的可落地程度随着时间如何变化
- 在中央与地方之间如何联动
- 在重要规划文件中多次提及时，用词的详细对比分析所体现出的态度变化与力度变化
3. 回复用户政策分析一句话总结，并告知下一步将进行产业分析

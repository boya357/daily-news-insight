[ 注1 ]	总市值（TotalMV）= 当日收盘价*最新总股本
[ 注2 ]	公司总市值（TotalMV2）=A股收盘价*A股合计+B股收盘价*B股合计*人民币外汇牌价+H股收盘价*H股合计*人民币外汇牌价＋每股净资产*(总股本-A股合计-B股合计-H股合计)
[ 注3 ]	A股：A/B股总市值（TotalASMV）=A股收盘价*A股合计；B股：A/B股总市值（TotalASMV）=B股收盘价*B股合计*人民币外汇牌价
[ 注4 ]	A股：A/B股流通市值（NegotiableMV）=A股收盘价*流通A股；B股：A/B股流通市值（NegotiableMV）=B股收盘价*流通B股*人民币外汇牌价
[ 注5 ]	静态市盈率（PELYR）＝总市值/去年净利润。其中，总市值计算同注1。
[ 注6 ]	滚动市盈率（PE）＝总市值/最近四个季度的净利润之和。其中，总市值计算同注1。
[ 注7 ]	扣非后滚动市盈率（PETTMCut）＝总市值/最近四个季度扣除非经常性损益后的净利润之和。其中，总市值计算同注1。
[ 注8 ]	动态市盈率_季度外推（ForwardPEQA）=总市值/(最新报告期净利润×S)，S根据不同的报告期参数自动选择，一季度：S＝4；半年度：S＝2；三季度S＝4/3；年度：S＝1。其中，总市值计算同注1。
[ 注9 ]	动态市盈率_历史占比（ForwardPEHR）=总市值/(最新报告期净利润/近三年同期和对应年报净利润占比的均值)。其中，总市值计算同注1。

[ 注11 ]滚动市盈率/营业收入三年复合增长率（PETTMToORRate）=市盈率TTM/{POWER[1+(本期营业收入TTM-基期营业收入TTM)/ABS(基期营业收入TTM),1/3]-1}； 注意： 基期指三年前同期； 若【基期营业收入TTM】为0或空，则PETTMToORRate为空； 若【本期营业收入TTM】小于0且【本期营业收入TTM】小于等于【基期营业...更多
[ 注12 ]市净率MRQ（PB）＝股票市值/最新定报净资产。其中，股票市值计算同注1；净资产为最新定期报告公布的净资产。
[ 注13 ]	市净率LF（PBLF）＝股票市值/最新公告净资产。其中，股票市值计算同注1；净资产为最新公告公布的净资产。
[ 注14 ]	静态市现率(经营现金流)（PCF）＝总市值/去年经营现金流量净额。其中，总市值计算同注1。
[ 注15 ]	滚动市现率(经营现金流)（PCFTTM）＝总市值/最近四个季度的经营现金流量净额。其中，总市值计算同注1。
[ 注16 ]	动态市现率(经营现金流)_季度外推（ForwardPCFQA）=总市值/(最新报告期经营现金流量净额×S)，S根据不同的报告期参数自动选择，一季度：S＝4；半年度：S＝2；三季度S＝4/3；年度：S＝1。其中，总市值计算同注1。
[ 注17 ]	动态市现率(经营现金流)_历史占比（ForwardPCFHR）=总市值/(最新报告期经营现金流量净额/近三年同期和对应年报经营现金流量净额占比的均值)。其中，总市值计算同注1。
[ 注18 ]	静态市现率(现金流净额)（PCFS）＝总市值/去年现金及现金等价物净增加额。其中，总市值计算同注1。
[ 注19 ]	滚动市现率(现金流净额)（PCFSTTM）＝总市值/最近四个季度现金及现金等价物净增加额。其中，总市值计算同注1。
[ 注20 ]	动态市现率(现金流净额)_季度外推（ForwardPCFSQA）=总市值/(最新报告期现金及现金等价物净增加额×S)，S根据不同的报告期参数自动选择，一季度：S＝4；半年度：S＝2；三季度S＝4/3；年度：S＝1。其中，总市值计算同注1。
[ 注21 ]	动态市现率(现金流净额)_历史占比（ForwardPCFSHR）=总市值/(最新报告期现金及现金等价物净增加额/近三年同期和对应年报现金及现金等价物净增加额占比的均值)。其中，总市值计算同注1。
[ 注22 ]	静态市销率（PS）＝总市值/去年营业收入。其中，总市值计算同注1。
[ 注23 ]	滚动市销率（PSTTM）＝总市值/最近四个季度的营业收入之和。其中，总市值计算同注1。
[ 注24 ]	动态市销率_季度外推（ForwardPSQA）=总市值/(最新报告期营业收入×S)，S根据不同的报告期参数自动选择，一季度：S＝4；半年度：S＝2；三季度S＝4/3；年度：S＝1。其中，总市值计算同注1。
[ 注25 ]	动态市销率_历史占比（ForwardPSHR）=总市值/(最新报告期营业收入/近三年同期和对应年报营业收入占比的均值)。其中，总市值计算同注1。
[ 注26 ]	静态股息率（DividendRatioLYR）＝(去年公司派现合计/总市值)*100。总市值计算同注3；该指标统计公司实际除权除息发生在去年期间的派现合计。
[ 注27 ]	静态股息率(报告期)（DividendRatioLYR2）＝(去年公司派现合计/总市值)*100。总市值计算同注3；该指标统计公司报告期截止日期发生在去年期间的派现合计。
[ 注28 ]	滚动股息率（DividendRatio）＝(近12个月公司派现合计/总市值)*100。其中，总市值计算同注3；该指标统计公司实际除权除息发生在近12个月期间且分红截止日期区间时长在12个月以内的派现合计。
[ 注29 ]	滚动股息率(报告期)（DividendRatio2）＝(近12个月公司派现合计/总市值)*100。其中，总市值计算同注3；该指标统计公司报告期截止日期发生在近12个月期间的派现合计。
[ 注30 ]	企业价值(含货币资金)（EnterpriseValueW）＝公司总市值+负债合计-无息流动负债-无息非流动负债。其中，公司总市值计算同注2。
[ 注31 ]	企业价值(剔除货币资金)（EnterpriseValueN）＝公司总市值+负债合计-无息流动负债-无息非流动负债-货币资金。其中，公司总市值计算同注2。
[ 注32 ]	企业价值倍数(剔除货币资金)（EVToEBITDA）=企业价值(剔除货币资金)/去年息税折旧摊销前利润。其中，企业价值(剔除货币资金)计算同注30。
[ 注33 ]	企业价值(剔除货币资金)/营业收入（EVToOR）=企业价值(剔除货币资金)/去年营业收入。其中，企业价值(剔除货币资金)计算同注30。
[ 注34 ]	企业价值(剔除货币资金)/企业自由现金流（EVToFCFF）=企业价值(剔除货币资金)/去年企业自由现金流量。其中，企业价值(剔除货币资金)计算同注30。
[ 注35 ]	企业价值(剔除货币资金)/经营现金流（EVToCFO）=企业价值(剔除货币资金)/去年经营现金流量净额。其中，企业价值(剔除货币资金)计算同注30。
[ 注36 ]	企业价值(剔除货币资金)/毛利（EVToGP）=企业价值(剔除货币资金)/去年毛利润。其中，企业价值(剔除货币资金)计算同注30。
[ 注37 ]	企业价值(剔除货币资金)/(EBITDA+研发费用)（EVToEBITDARANDD）=企业价值(剔除货币资金)/(去年息税折旧摊销前利润+去年研发费用)。其中，企业价值(剔除货币资金)计算同注30。
[ 注38 ]	总市值/研发支出前利润（PER）=总市值/(去年净利润+去年研发费用)。其中，总市值计算同注1。
[ 注39 ]	总市值/研发费用（TotalMVToRANDD）=总市值/去年研发费用。其中，总市值计算同注1。
[ 注40 ]	总市值/总负债（MarketValueToDebt1）=总市值/最新报告期总负债。其中，总市值计算同注1。
[ 注41 ]	公司总市值/总负债（MarketValueToDebt2）=公司总市值/最新报告期总负债。其中，公司总市值计算同注2。
[ 注42 ]	总负债/总资产市值（DebtToAssetValue1）=最新报告期总负债/(最新报告期总负债+总市值)。其中，总市值计算同注1。
[ 注43 ]	总负债/公司总资产市值（DebtToAssetValue2）=最新报告期总负债/(最新报告期总负债+公司总市值)。其中，公司总市值计算同注2。
[ 注44 ]	市场附加价值(MVA)(元)（MVA）=公司总市值-最新报告期净资产。其中，公司总市值计算同注2。
[ 注45 ]	流通盘市场附加价值(元)（FloatMVA）=公司流通市值-公司流通资产总值。其中，公司流通市值=A股收盘价*流通A股+B股收盘价*流通B股*人民币外汇牌价+H股收盘价*流通H股*人民币外汇牌价；公司流通资产总值=每股净资产*(流通A股+流通B股+流通H股)。

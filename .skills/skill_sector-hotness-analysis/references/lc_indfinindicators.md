# lc_indfinindicators 行业财务指标表

**表说明：**
1. **内容说明：** 本表为精选行业财务指标相关数据，反映不同行业分级标准下，各行业的成长能力、偿债能力、盈利能力和现金获取能力等。本表数据多采用整体法进行计算（如计算增长率时，采用（行业内所有公司的当期总值 - 上期总值）/ 上期总值，而非行业内公司增长率的算术平均值），且部分比例类指标对金融类公司不适用（如流动比例、速动比例、毛利率等）。该指标体系计算逻辑详见备注说明。
2. **数据范围：** A股财报，业绩快报、股本结构、分红等数据，2014年至今。
3. **信息来源：** 公告披露，聚源计算。
4. **更新频率：** 日更新。

**业务唯一性：** IndustryNum, SectorCode, InfoPubDate, EndDate, DataMark

### 备注说明

*   **[注1]** 行业内部编码(IndustryNum)与(CT_IndustryType)表中的IndustryNum字段关联。令IndustryNum=IndustryNum，得到行业内部编码的具体描述。
*   **[注2]** 行业划分标准(Standard)与(CT_SystemConst)表中的DM字段关联。令LB=1081 AND DM IN (41)，得到行业划分标准的具体描述：41-申万行业分类2021版。
*   **[注3]** 统计类型(StatType)，该字段固定以下常量：1-整体法剔除负值。
*   **[注4]** 统计板块(SectorCode)，该字段固定以下常量：5-沪、深及北交所市场。
*   **[注5]** 数据标志(DataMark)，该字段固定以下常量：1-完整财报，2-最新财报预期，9-财报更正。
*   **[注6]** 为行业内公司营业收入TTM总值，行业均值可用该值除以上市证券数量。
*   **[注7]** 为行业内归属母公司的净利润TTM总值，行业均值可用该值除以上市证券数量。
*   **[注8]** 采用整体法进行计算：(行业内所有公司当期归母净利润总值 - 其上期同期净利润总值) / 其上期同期净利润总值。(若有公司未披露当期或上期同期净利润，则剔除该样本)
*   **[注9]** ∑(个股归母净利润 / 个股期末总股本) / 证券数。
*   **[注10]** ∑归母净利润 * 2 / ∑(归母权益MRQ + 期初归母股东权益)。
*   **[注11]** ∑归母净利润 / ∑归母股东权益MRQ。
*   **[注12]** ∑归母净利润TTM / ∑归母股东权益MRQ。
*   **[注13]** ∑扣非归母净利润 * 2 / ∑(归母权益MRQ + 期初归母股东权益)。
*   **[注14]** ∑扣非归母净利润 / ∑归母股东权益MRQ。
*   **[注15]** ∑净利润 * 2 / ∑(总资产 + 期初总资产)。
*   **[注16]** ∑净利润 / ∑期末总资产。
*   **[注17]** ∑净利润TTM / ∑期末总资产。
*   **[注18]** ∑毛利润 / ∑营业收入，金融企业不适用。
*   **[注19]** ∑毛利润TTM / ∑营业收入TTM，金融企业不适用。
*   **[注20]** ∑净利润 / ∑营业收入。
*   **[注21]** ∑净利润TTM / ∑营业收入TTM。
*   **[注22]** ∑扣非净利润 / ∑营业收入。
*   **[注23]** ∑财务费用TTM / ∑营业收入TTM，金融企业不适用。
*   **[注24]** ∑销售费用 / ∑营业总收入，金融企业不适用。
*   **[注25]** ∑销售费用TTM / ∑营业总收入TTM，金融企业不适用。
*   **[注26]** ∑销售期间费用 / ∑营业收入，销售期间费用 = 销售费用 + 管理费用 + 财务费用 + 研发费用，金融企业不适用。
*   **[注27]** ∑营业总成本 / ∑营业总收入，金融企业不适用。
*   **[注28]** ∑息税前利润 * (1 - 有效税率) * 2 / ∑(期末全部投入资本 + 期初全部投入资本)，金融企业不适用。
*   **[注29]** ∑流动资产 / ∑流动负债，金融企业不适用。
*   **[注30]** ∑(流动资产 - 存货) / ∑流动负债，金融企业不适用。
*   **[注31]** ∑息税前利润 / ∑利息费用，金融企业不适用。
*   **[注32]** ∑经营活动产生的现金流量净额 / ∑利息费用，金融企业不适用。
*   **[注33]** (∑归母净利润 - ∑上年同期归母净利润) / |∑上年同期归母净利润|。
*   **[注34]** (∑毛利润 - ∑上年同期毛利润) / |∑上年同期毛利润|，金融企业不适用。
*   **[注35]** ∑营业成本 * 2 / ∑(存货 + 期初存货)，金融企业不适用。
*   **[注36]** 360 / 存货周转率。期末存货 = ∑营业成本 * 2 / ∑(存货 + 期初存货)，金融企业不适用。
*   **[注37]** ∑营业收入 * 2 / ∑(应收账款 + 期初应收账款)，金融企业不适用。
*   **[注38]** 360 / 应收账款周转率。应收账款周转率 = ∑营业收入 * 2 / ∑(应收账款 + 期初应收账款)，金融企业不适用。
*   **[注39]** ∑营业收入 * 2 / ∑(应收票据 + 期初应收票据 + 应收账款 + 应收账款 + 应收款项融资 + 其他应收款合计 + 应收款项总额)，金融企业不适用。
*   **[注40]** ∑营业总收入 * 2 / ∑(总资产 + 期初总资产)，金融企业不适用。
*   **[注41]** ∑经营现金净流量 / ∑营业总收入，金融企业、金融企业专用收入。
*   **[注42]** ∑期末总负债 / ∑期末总资产。
*   **[注43]** (∑归母股东权益 - (无形资产 + 开发支出 + 商誉 + 长期待摊费用 + 递延所得税资产)) / 总资产，金融企业不适用。
*   **[注44]** ∑(交易性金融资产 + 可供出售金融资产 + 持有至到期投资 + 长期股权投资 + 债权投资 + 其他债权投资 + 其他权益工具投资) / 所有者权益合计。

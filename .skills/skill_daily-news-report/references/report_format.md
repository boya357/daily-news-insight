## 概览

本文档定义了每日技术新闻报告的格式规范，确保报告内容的一致性和可读性。

**核心要求**: 报告内容必须全部使用中文！

**适用场景**: 当智能体生成每日新闻报告时，必须严格遵循本规范定义的格式。

## Markdown格式定义

### 报告头部

报告必须以以下格式开头（全中文）：

```markdown
# 每日技术新闻（YYYY-MM-DD）

> 今日从 N 个源精选，包含 M 条高质量内容
> 生成耗时：X 分钟 | 版本：v4.0
>
> **警告**：[可选] 未检测到子代理 'worker'，运行在通用模式...
```

**字段说明**:
- `YYYY-MM-DD`: 报告日期，如 `2025-02-17`
- `N`: 数据源数量
- `M`: 高质量条目数量
- `X`: 生成耗时（分钟）

### 新闻条目格式

每个新闻条目必须遵循以下结构（全中文）：

```markdown
## 序号. 标题

- **摘要**：2-4行概述内容
- **要点**：
  1. 要点一
  2. 要点二
  3. 要点三
- **来源**：[链接文字](URL)
- **关键词**：`关键词1` `关键词2` `关键词3`
- **评分**：⭐⭐⭐⭐⭐ (5/5)

---
```

**字段说明**:
- `序号`: 从1开始的序号
- `标题`: 新闻标题（必须中文）
- `摘要`: 2-4行摘要，概述新闻核心内容（必须中文）
- `要点`: 最多3个要点，每个要点独立成行（必须中文）
- `来源`: 原文链接，必须使用Markdown链接格式
- `关键词`: 3-5个关键词，使用反引号包裹（可中英文混合）
- `评分`: 质量评分，1-5星，使用⭐符号表示

### 分隔符

每个新闻条目之间使用三个横线分隔：

```markdown
---
```

### 报告尾部

报告必须以以下格式结尾（全中文）：

```markdown
---

*由每日技术新闻报告生成器创建*
*数据源：源1、源2、源3...*
```

## 验证规则

### 必需字段验证

| 字段 | 验证规则 | 错误示例 |
|------|---------|---------|
| 标题 | 必须包含日期 | `# 每日技术新闻` ❌ |
| 摘要 | 必须以 `- **摘要**：` 开头 | `摘要：xxx` ❌ |
| 要点 | 必须以数字列表形式 | `- 要点一` ❌ |
| 链接 | 必须是有效的Markdown链接 | `来源：https://...` ❌ |
| 关键词 | 必须使用反引号包裹 | `关键词：AI, ML` ❌ |
| 评分 | 必须使用⭐符号 | `评分：5/5` ❌ |

### 全中文验证

| 内容类型 | 验证规则 | 说明 |
|---------|---------|------|
| 标题 | 必须中文 | 专业术语可保留英文 |
| 摘要 | 必须中文 | 技术名词可保留英文 |
| 要点 | 必须中文 | 代码片段可保留英文 |
| 关键词 | 可中英文混合 | 技术关键词可用英文 |
| 标签文字 | 必须中文 | 如"摘要"、"要点"等 |

### 格式验证

1. **分隔符一致性**: 所有新闻条目之间必须使用 `---` 分隔
2. **序号连续性**: 序号必须从1开始连续递增
3. **链接有效性**: 所有链接必须以 `http://` 或 `https://` 开头
4. **关键词数量**: 每条新闻应有3-5个关键词
5. **要点数量**: 每条新闻应有1-3个要点

### 质量阈值

- **最低评分**: 评分低于3星的条目不应出现在报告中
- **摘要长度**: 摘要应在50-200字符之间
- **标题长度**: 标题应在10-100字符之间

## HTML输出说明

智能体应使用 `scripts/generate_html.py` 脚本将Markdown报告转换为HTML，生成的HTML页面具有以下特性：

### 视觉设计

1. **配色方案**: 蓝紫色渐变（现代科技感）
2. **字体**: 思源黑体（Noto Sans SC），中文显示效果优秀
3. **布局**: 卡片式设计，圆角阴影，层次分明
4. **动画**: 平滑过渡效果，提升交互体验

### 交互功能

1. **响应式设计**: 适配桌面和移动设备
2. **下载功能**: 提供MD和HTML格式的一键下载按钮
3. **链接优化**: 在新标签页打开外部链接
4. **滚动条美化**: 自定义滚动条样式

### 调用示例

```bash
python scripts/generate_html.py -i ./daily-news/2025-02-17/news-report.md -o ./daily-news/2025-02-17/news-report.html -d 2025-02-17 -t "每日技术新闻"
```

### 参数说明

- `-i, --input`: 输入的Markdown文件路径
- `-o, --output`: 输出的HTML文件路径
- `-d, --date`: 报告日期（YYYY-MM-DD格式）
- `-t, --title`: 页面标题（可选，默认为"每日技术新闻"）

## 全中文翻译指南

### 专业术语处理

| 英文术语 | 中文翻译 | 备注 |
|---------|---------|------|
| AI | AI | 可保留英文 |
| GPT-5 | GPT-5 | 型号名称保留 |
| API | API | 技术术语保留 |
| Open Source | 开源 | 必须翻译 |
| Machine Learning | 机器学习 | 必须翻译 |
| Deep Learning | 深度学习 | 必须翻译 |
| Natural Language Processing | 自然语言处理 | 必须翻译 |

### 翻译原则

1. **准确性**: 确保翻译准确传达原文含义
2. **可读性**: 中文表达要自然流畅
3. **专业性**: 技术术语使用行业通用译法
4. **一致性**: 同一术语全文翻译保持一致

# 错误模式分析

## 概述
本文档记录预判失败的具体原因，识别重复犯错的模式。

---

## 失败案例记录

### 案例 #1：P003 低空经济催化（2026-05-23验证）
| 字段 | 内容 |
|------|------|
| 预判ID | PRED_20260520_003 |
| 预判类型 | ⚡ A级机会 |
| 预判内容 | 世界无人机大会(5/21-23)催化，低空经济上涨10-15% |
| 实际结果 | 中无人机下跌4.34%，光威复材下跌2.52%，雷科防务下跌9.4% |
| 失败模式 | 概念混淆 + 忽视量能 + 时机偏差 |
| 核心教训 | 行业常规会议非实质性催化，需评估事件影响力等级 |

## 已识别错误模式

### 模式 #1：时机偏差
| 字段 | 内容 |
|------|------|
| 模式名称 | 时机偏差 |
| 描述 | 预判时间窗口过短，被短期波动干扰，或催化事件发生在窗口后半段 |
| 典型案例 | P003（无人机大会发生在验证窗口第2-3天） |
| 教训 | S级催化需要更长发酵时间；窗口应覆盖事件前后完整周期 |

### 模式 #2：幅度高估
| 字段 | 内容 |
|------|------|
| 模式名称 | 幅度高估 |
| 描述 | 预期涨幅过大，实际涨幅不足 |
| 典型案例 | - |
| 教训 | 理性评估，合理预期 |

### 模式 #3：产业链遗漏
| 字段 | 内容 |
|------|------|
| 模式名称 | 产业链遗漏 |
| 描述 | 只关注龙头标的，忽视上下游联动 |
| 典型案例 | - |
| 教训 | 建立完整产业链标的池 |

### 模式 #4：忽视量能
| 字段 | 内容 |
|------|------|
| 模式名称 | 忽视量能 |
| 描述 | 忽略资金配合的重要性，缺乏主力资金持续流入 |
| 典型案例 | P003（雷科防务主力连续两日净流出超2亿元） |
| 教训 | 量价配合是核心指标，无资金配合的催化需谨慎 |

### 模式 #5：概念混淆
| 字段 | 内容 |
|------|------|
| 模式名称 | 概念混淆 |
| 描述 | 把常规消息/行业会议当实质催化，高估市场影响力 |
| 典型案例 | P003（世界无人机大会是年度常规行业会议） |
| 教训 | 建立催化影响力评级体系：S级（政策/重磅业绩）>A级（重大事件）>B级（常规会议） |

---

## 教训总结

### 预判前必查清单
1. ✅ 是否有实质利好（非单纯消息/常规会议）
2. ✅ 催化事件影响力评级（S/A/B级）
3. ✅ 资金是否配合（主力净流入/量能放大）
4. ✅ 时间窗口是否充足（覆盖事件前后）
5. ✅ 产业链联动逻辑是否清晰
6. ✅ 是否有潜在利空对冲

### 准确率提升要点
1. 宁可不预判，不乱预判
2. 区分"可能"与"必然"
3. 重视资金流向
4. 关注量能配合
5. 建立催化事件影响力评级体系

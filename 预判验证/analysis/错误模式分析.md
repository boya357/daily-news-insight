# 错误模式分析

## 概述
本文档记录预判失败的具体原因，识别重复犯错的模式。

---

## 已识别错误模式

### 模式 #1：时机偏差
| 字段 | 内容 |
|------|------|
| 模式名称 | 时机偏差 |
| 描述 | 预判时间窗口过短，被短期波动干扰 |
| 典型案例 | - |
| 教训 | S级催化需要更长发酵时间 |

### 模式 #2：幅度高估
| 字段 | 内容 |
|------|------|
| 模式名称 | 幅度高估 |
| 描述 | 预期涨幅过大，实际涨幅不足 |
| 典型案例 | - |
| 教训 | 理性评估，合理预期 |

### 模式 #3：产业链遗漏
| 字段 | 内容 |
|------|------|
| 模式名称 | 产业链遗漏 |
| 描述 | 只关注龙头标的，忽视上下游联动 |
| 典型案例 | - |
| 教训 | 建立完整产业链标的池 |

### 模式 #4：忽视量能
| 字段 | 内容 |
|------|------|
| 模式名称 | 忽视量能 |
| 描述 | 忽略资金配合的重要性 |
| 典型案例 | - |
| 教训 | 量价配合是核心指标 |

### 模式 #5：概念混淆
| 字段 | 内容 |
|------|------|
| 模式名称 | 概念混淆 |
| 描述 | 把消息当实质催化，高估影响 |
| 典型案例 | - |
| 教训 | 区分事件催化与实质利好 |

---

## 教训总结

### 预判前必查清单
1. ✅ 是否有实质利好（非单纯消息）
2. ✅ 资金是否配合
3. ✅ 时间窗口是否充足
4. ✅ 产业链联动逻辑是否清晰
5. ✅ 是否有潜在利空对冲

### 准确率提升要点
1. 宁可不预判，不乱预判
2. 区分"可能"与"必然"
3. 重视资金流向
4. 关注量能配合

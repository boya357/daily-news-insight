# 预判验证记录

## 概述
本文档记录每次推送中的预判内容，用于后续验证和准确率统计。

## 记录规范
- **文件命名**：`YYYYMMDD_预判记录.md`
- **来源报告**：记录是哪份报告产生的预判
- **标的代码**：使用标准股票代码格式
- **验证时间**：T+N后自动验证

---

## 字段说明

| 字段 | 说明 | 示例 |
|------|------|------|
| 预判ID | 唯一标识 | PRED_20260520_001 |
| 预判类型 | S级催化/A级机会/风险预警 | S级催化 |
| 预判内容 | 具体的预判描述 | 存储产业链将迎来反弹 |
| 预判标的 | 相关股票 | 长鑫存储、兆易创新 |
| 预判时间 | 预判发布时间 | 2026-05-20 |
| 预期兑现时间 | T+N | T+3 (5/23) |
| 验证状态 | 待验证/已兑现/未兑现 | 待验证 |
| 兑现幅度 | 实际涨跌幅 | - |

## 常见错误模式

1. **过度乐观**：预判涨幅过大，实际涨幅不足
2. **时机偏差**：预判时间窗口过短，被短期波动干扰
3. **忽视风险**：只关注利好，忽视利空因素
4. **产业链遗漏**：只关注龙头，忽视上下游联动

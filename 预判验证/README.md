# 预判验证闭环系统

## 系统概述

**核心目标**：记录每一次预判，T+N后验证是否兑现，真正实现投资决策的闭环进化。

---

## 工作流程

```
┌─────────────────────────────────────────────────────────────┐
│  Step 1: 预判记录                                          │
│  每次推送报告时，自动提取预判内容并记录                      │
│  保存到: docs/预判验证/YYYYMMDD_预判记录.md                │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  Step 2: 验证触发                                          │
│  T+N天后自动检查预判标的涨跌幅                              │
│  日历任务驱动，确保按时验证                                  │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  Step 3: 结果回写                                          │
│  将验证结果写入预判记录，更新准确率统计                      │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  Step 4: 模式分析                                          │
│  找出成功预判的共同特征                                    │
│  识别失败预判的错误模式                                      │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  Step 5: 逻辑优化                                          │
│  基于分析结果优化推理逻辑                                    │
│  避免重复犯错                                                │
└─────────────────────────────────────────────────────────────┘
```

## 文件结构

```
docs/

    ├── _config/              # 配置文件
    │   └── 验证规则.md       # 不同类型预判的验证标准
    ├── records/              # 预判记录
    │   └── YYYYMMDD_预判记录.md
    ├── verification/         # 验证结果
    │   └── YYYYMMDD_验证报告.md
    ├── statistics/          # 准确率统计
    │   └── 准确率统计.md
    └── analysis/            # 模式分析
        └── 错误模式分析.md
```

## 预判类型与验证规则

### S级催化
- **预期涨幅**：≥15% 
- **验证窗口**：T+5
- **兑现标准**：最高涨幅达到预期80%

### A级机会
- **预期涨幅**：8-15%
- **验证窗口**：T+3
- **兑现标准**：最高涨幅达到预期80%

### B级机会
- **预期涨幅**：4-8%
- **验证窗口**：T+2
- **兑现标准**：最高涨幅达到预期80%

### 风险预警
- **预期跌幅**：≥5%
- **验证窗口**：T+3
- **兑现标准**：最大跌幅达到预期80%

## 准确率评级

| 评级 | 准确率 | 说明 |
|------|--------|------|
| 🏆 S级分析师 | ≥80% | 顶级预判能力 |
| 🥇 A级分析师 | 60-80% | 优秀 |
| 🥈 B级分析师 | 40-60% | 良好 |
| 🥉 C级分析师 | 20-40% | 需改进 |
| ❌ D级分析师 | <20% | 需重大优化 |

## 常见错误模式库

1. **时机偏差**：预判时间窗口过短
2. **幅度高估**：预期涨幅过大
3. **产业链遗漏**：只关注龙头
4. **忽视量能**：忽略资金配合
5. **概念混淆**：把消息当实质催化
